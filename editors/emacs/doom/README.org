#+TITLE: lang/beamlisp
#+SUBTITLE: beam-lisp — the language is the harness

beam-lisp in Doom: tree-sitter major mode, the language server, a warm REPL,
the codebase questions, and first-party literate documents.

Installed by =bl install doom= — which wrote this module, compiled the
tree-sitter grammar, and wired =(beamlisp +lsp +literate)= into =init.el=.
Re-run it to upgrade.

* Flags
- =+lsp= :: the language server (diagnostics, hover with the compiler's
  proof card, go-to-definition, inlay hints). Registers with lsp-mode; the
  vendored mode also registers eglot for =+eglot= setups.
- =+literate= :: polymode for =.bl.md= livebooks: markdown prose with
  tree-sitter beam-lisp cells. (=.bl.org= needs no flag — org is the host.)

* The command, resolved once
Every shell-out goes through =beamlisp--command=: inside the beam-lisp
checkout (a =mix.exs= naming =beam_lisp=) it is =mix bl= — the dev tree,
daemon-warm — everywhere else the installed =bl= binary.

* Keys (.bl)
| key   | does                                          |
|-------+-----------------------------------------------|
| , '   | open the warm REPL                            |
| , e e | send the top-level form to the REPL           |
| , e r | send the region                                |
| , e b | send the buffer                                |
| , r   | =bl run= this file (compilation buffer)        |
| , c   | =bl lsp check= — diagnostics + proven facts    |
| , i   | impact: what breaks if symbol-at-point changes |
| , a   | ask the codebase (completing-read)             |

* Literate documents
=.bl.md= :: cells are ```beam-lisp fences. =, e e= evaluates the cell at
point in the warm REPL; =, r= runs =bl doc run= and refreshes the buffer in
place (result spans update); =, ]= / =, [= jump between cells; imenu lists
sections and definitions together.

=.bl.org= :: org is the host. =C-c C-c= evaluates a =#+begin_src beam-lisp=
block (org-babel); =C-c '= edits it in =beamlisp-ts-mode=; =C-c C-v r= runs
the document; =C-c C-v ]= / =[= navigate cells.

* Maintenance
The elisp here is vendored from =editors/emacs/= in the beam-lisp checkout.
=bl install doom= refreshes it; =bl install doom --check= verifies the
installation.
