* What went in

334 non-merge commits since v2026.5. Three lines of work met here:

- *Main's native custody line*: attested SDK owners, native owned starts,
  reload reconciliation, queue families, Datom mutation turns. Mostly internal.
- *The runtime line driven by backdesk-booking* (`improve/backdesk-runtime`,
  merged as `c002a46f`): the app-facing features in the compiled changelog.
- *Release and latency work*: the SDK-inventory memo, bounded callback
  authentication, checkout VM reuse, and releasing from the qualified floor.

* Release blockers fixed on the way

- The runtime-line merge left nested `#()` literals (reader error) in
  `datom/conn.bl` and three tests, and dropped `claim-opts` in `proc.queue`.
  Fixed in `faf0196c`; FUP-166 tracks catching this class of merge damage.
- The kernel ABI check refused `:link`/`:rem` rows naming preloaded OTP modules
  (`7ac0c508`).
- Every `spawn` rebuilt the whole SDK inventory (3–9 s per call, twice per
  spawn). It is now remembered under an exact fingerprint (`1323e8a9`), and
  callback authentication checks cached per-module seed evidence (`de7386fa`).
  A seed superseded by a source-compiled unit no longer refuses the spawn.
- The owned-start table scanned all 4096 rows on every spawn once full; it
  now prunes in bounded steps.

* Release mechanics

CI no longer regenerates the compiler floor. `bl seed --check` must pass on
the committed floor, then `bl self-build --reuse-floor` packages exactly
those SHA-verified beams with source library tiers (`b1e3b0ce`).

Deliberately left out: the parked `wip/sdk-staged-type-compiler-inputs`
branch (per-component compiler inputs, SDK staged-type prelink). It changes
the compiler key and needs its own floor qualification.

** v2026.6 — commands reuse one VM, spawn is cheap again

**Commands answer from a warm VM.** `./bin/bl` in a checkout, and installed
drops that support it, run commands in one persistent VM per tree. Each request
keeps its own directory, arguments and environment. A source change restarts
the VM before the next request. The VM skips the dashboard, gateway and project
schedules, is memory-bounded under systemd, and stays up until `bl realm stop`.
`--cold` still gives a fresh VM.

**`spawn` is cheap again.** Starting a process no longer re-proves the whole
SDK, so test suites that spawn many processes no longer look hung.

**New in the language and libraries:**

- `conj` and `disj` are variadic, as in Clojure: `(conj [1] 2 3)`.
- `datom/eids-by` and `datom/group-eids`: attribute-value index reads for app
  code ("every entity whose :hotel/kind is work") without scanning.
- `datom/memo-by-basis`: compute a pure derivation once per immutable db value,
  shared across processes and bounded. It replaces hand-rolled process caches.
- `datom/pull` gains AVET/current-facet fast paths; `pull-many` batches plain
  patterns.
- `proc.sched` dynamic deadlines: an actor can derive deadlines from its state
  (`schedule-at`/`unschedule`), and outside code can `at!`/`cancel!` them.
  Polling ticks are no longer needed.
- `live` hiccup: a vector whose head is not a tag is a child group, so
  `(mapv row items)` works as children.
- `convey` accepts both arities.
- `bl.profile`: tprof call-time reported in Beam Lisp names. Release drops
  now carry the `tools` application.
- Lazy values remember clean results at every depth; `plain!` forces a plain
  value.

**Releases** package the qualified compiler floor: `bl self-build
--reuse-floor`.
