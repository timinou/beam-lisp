#+TITLE: An authority you can hold in your hand
#+STARTUP: showall

* What this page shows

A split app's server half is not a server you have to start to understand. It
is an ordinary BL value — the app — and one pure function over it:
=split.core/propose=. You can feed it proposals in a REPL and watch it decide.
The HTTP transport, the log and the browser are all built on top of that one
function; none of them decides anything.

Every cell below runs the real groceries app from
=research/js-actors/apps/groceries.bl=, natively, with no server.

* Load an app

An app file is a namespace. Loading it defines the app value — the
declaration, its contract and digest, and every role resolved to its
function.

#+begin_src beam-lisp :id load
(ns split-doc-2 (:require [split.core :as core] [split.wire :as wire]))
(BeamLisp.Env/add_search_path "research/js-actors/apps")
(BeamLisp.Loader/ensure_loaded "groceries")
(def app (BeamLisp.Compiler/eval_string "groceries/groceries"))

(println "name     " (:name app))
(println "digest   " (subs (:digest app) 0 16) "…")
(println "intents  " (sort (keys (:intents app))))
(println "snapshot " (get-in app [:contract :snapshot]))
#+end_src
#+RESULTS: load
: name      groceries
: digest    bbf37e375d12248c …
: intents   (:add-item :change-qty :clear-basket :remove-item :tick-item)
: snapshot  :basket
: :ok


* The first world

=core/initial= runs the app's =:server :init= and checks that its projection
satisfies the snapshot type. A world is the authority's whole memory:
state, revision, remembered nonces, history.

#+begin_src beam-lisp :id initial
(def w0 (core/initial app))
(def board0 (wire/wire-snapshot (:contract app) (:state w0)))
(println "revision" (:revision w0) "·" (count (:items board0)) "items")
(println "first item" (first (:items board0)))
#+end_src
#+RESULTS: initial
: revision 0 · 7 items
: first item {:id 1, :name "Oat milk", :qty 2, :aisle :dairy, :got false}
: :ok


* One decision

A proposal is what a browser sends, plus the person the transport stamped.
=propose= answers four things and changes nothing outside itself: the next
world, the answer for the proposer, the snapshot for everyone else (or nil),
and the commit for the log (or nil).

#+begin_src beam-lisp :id propose
(defn proposal [req rev nonce op args]
  {:request req :revision rev :digest (:digest app) :nonce nonce :actor nil :op op :args args})

(let [[w1 result snapshot commit] (core/propose app w0 (proposal 1 0 "doctab01:1" :tick-item {:id 3 :got true}))]
  (def w1 w1)
  (println "ok?      " (:ok result) "→ revision" (:revision result))
  (println "snapshot " (some? snapshot) "(goes to every open tab)")
  (println "commit   " (:op (:entry commit)) (:args commit) "(goes to the log first)"))
#+end_src
#+RESULTS: propose
: ok?       true → revision 1
: snapshot  true (goes to every open tab)
: commit    :tick-item {:id 3, :got true} (goes to the log first)
: :ok


* Every refusal is a value

Nothing a browser sends can crash the authority. A wrong revision, a failed
check, a malformed argument, a stale build — each is an answer, and none of
them publishes or logs anything.

#+begin_src beam-lisp :id refusals
(doseq [[label p] [["someone else committed first" (proposal 2 0 "doctab01:2" :remove-item {:id 1})]
                   ["the shared :check says no"   (proposal 3 1 "doctab01:3" :remove-item {:id 99})]
                   ["args outside their type"     (proposal 4 1 "doctab01:4" :change-qty {:id 1 :delta 5})]
                   ["an older build of the page"  (assoc (proposal 5 1 "doctab01:5" :clear-basket {}) :digest "0000")]
                   ["an op nobody declared"       (proposal 6 1 "doctab01:6" :drop-table {})]]]
  (let [[w r s c] (core/propose app w1 p)]
    (println (str label ": " (:reason r) " · published " (some? s) " · logged " (some? c)
                  " · revision still " (:revision w)))))
#+end_src
#+RESULTS: refusals
: someone else committed first: stale-revision · published false · logged false · revision still 1
: the shared :check says no: no-such-item · published false · logged false · revision still 1
: args outside their type: malformed-args · published false · logged false · revision still 1
: an older build of the page: client-outdated · published false · logged false · revision still 1
: an op nobody declared: unknown-intent · published false · logged false · revision still 1
: nil


* At most once

A tab that lost its answer sends the same proposal again, with the same
nonce. The authority remembers committed nonces and answers again without
committing twice — which is why a browser may always resend.

#+begin_src beam-lisp :id nonce
(let [again (proposal 7 1 "doctab01:1" :tick-item {:id 3 :got true})
      [w r s c] (core/propose app w1 again)]
  (println "ok" (:ok r) "· duplicate" (:duplicate r) "· revision" (:revision w) "· logged" (some? c)))
#+end_src
#+RESULTS: nonce
: ok true · duplicate true · revision 1 · logged false
: :ok


* A restart is a replay

The durable log keeps intents, not states. A restarted authority decides
every one of them again, with the same rules, before it serves anything —
and refuses to start if any of them no longer holds.

#+begin_src beam-lisp :id replay
(def log [(proposal 1 0 "doctab01:1" :tick-item {:id 3 :got true})
          (proposal 2 1 "doctab01:2" :add-item {:name "Eggs" :aisle :dairy})])

(let [pid (core/start app {:replay log})
      now (core/call pid [:current] :split/current 2000)]
  (println "replayed to revision" (:revision now) "·" (count (:items (:board now))) "items"))

(let [bad (conj log (proposal 3 7 "doctab01:3" :clear-basket {}))]
  (println "a log that no longer holds:"
           (try (core/start app {:replay bad}) :started (catch e (ex-message e)))))
#+end_src
#+RESULTS: replay
: replayed to revision 2 · 8 items
: a log that no longer holds: split: groceries log revision 7 does not replay: :stale-revision
: :ok


* Where this goes next

=split.web= wraps exactly this: it decodes a browser's JSON by the contract,
stamps the signed-in person, calls the authority, and streams each snapshot to
every open tab. =split.log= is the =:commit!= hook: it writes the commit to
datom on fjall and fsyncs before the authority answers. Serve all of it with

#+begin_example
bl serve research/split-beam/serve.bl -- groceries
#+end_example
