#+TITLE: One form
#+STARTUP: showall

* One form knows everything about your program

A beam-lisp program compiles to one intermediate form, bl-ANF. This series is
about a single idea: that form is where /every/ fact about the program lives —
its source position, what it proves, and who it calls — all on one structure,
read by every part of the compiler.

Read in order:

1. [[file:01-position-lives-in-the-ir.bl.org][Position lives in the IR]] — every node carries its full source span, so one
   position channel serves the backend's stack frames, the error printer's
   carets, and the engines' warnings.
2. [[file:02-summaries-see-across-calls.bl.org][Summaries see across calls]] — one pass builds a summary per function and a
   complete call graph (including higher-order calls), so a fact about a callee
   flows to every caller.
3. [[file:03-one-form-many-truths.bl.org][One form, many truths]] — position, proof, and call graph as one channel:
   inter-procedural type errors caught, and proofs that say honestly what they
   did and did not cover.
4. [[file:04-the-surface-walks-are-gone.bl.org][The surface walks are gone]] — the hard cutover: with position in the IR,
   the second (surface) walk each engine kept for line/column is deleted;
   termination and invariant-substitution now read one tree.

Every code block here runs. The =#+RESULTS:= under each is what the compiler
actually produces — re-run the file and the results stay identical.
