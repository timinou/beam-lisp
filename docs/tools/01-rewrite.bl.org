#+TITLE: 1 · Trivia-preserving rewrite
#+STARTUP: showall

* A fix that touches only what it fixes

=deodorant= finds code smells and rewrites them away. The rewrite used to go
through =pr-str=: the matched subform was re-printed from its parsed data, which
flattened it onto one line and dropped every comment inside it. So the sweep
that fixes one idiom would also silently reformat the code around it — unusable
across a whole file.

The fix reads position from the IR. Every reader node carries a full source span
={:line :col :end-line :end-col}=. A rewrite rule's capture variables bind to
whole sub-nodes, so instead of re-printing a capture, =fix-source-preserving=
slices its *original source bytes* out of the file and splices them into the new
skeleton. Only the rule's own fixed tokens are new text; everything else is
byte-identical.

* The contrast, on one multi-line smell

A =(if (not P) A nil)= whose =A= is a multi-line block with a comment:

#+begin_src beam-lisp :id contrast
(ns demo (:require [deodorant :as deo]))
(def src (str "(defn process [items]\n"
              "  (if (not (empty? items))\n"
              "    (do\n"
              "      ; keep the good ones\n"
              "      (filter good? items))\n"
              "    nil))"))
(def old  (deo/fix-source            (deo/all-rules) src))
(def new  (deo/fix-source-preserving (deo/all-rules) src))
(println (pr-str {:old-keeps-comment (some? (index-of (:source old) "keep the good ones"))
                  :new-keeps-comment (some? (index-of (:source new) "keep the good ones"))}))
#+end_src

#+RESULTS: contrast
: {:old-keeps-comment false, :new-keeps-comment true}
: :ok

Same rule, same match. The old fixer loses the comment (and collapses the =do=
block onto one line); the preserving fixer keeps both. The only bytes that
change are the =if=/=not= skeleton that became =when-not=.

* Every existing smell is preserved for free

There is no per-smell work. A smell is already ={:pattern :replacement :when?}=;
=span-rewrite/smell->rule= reads its pattern as a node tree and derives a
renderer from its replacement template, so a =?var= in the replacement renders as
the captured node's original bytes. The whole registry becomes trivia-safe at
once:

#+begin_src beam-lisp :id registry
(ns demo (:require [deodorant :as deo] [span-rewrite :as sr]))
(def rule (sr/smell->rule (first (deo/all-rules))))
(println (pr-str {:has-pattern (contains? rule :pattern)
                  :has-render  (contains? rule :render)}))
#+end_src

#+RESULTS: registry
: {:has-pattern true, :has-render true}
: :ok

* What stays true

- *The result is valid source.* =fix-source-preserving= re-parses before
  returning; it never emits broken code.
- *Only matched spans change.* Comments, blank lines, indentation, and every
  non-smell sibling are carried through byte-for-byte — measured on the engine
  files, where the comment count is identical before and after while the old
  fixer dropped ten-plus lines per file.
- *Guards ride through.* A smell's =:when= guard (for example, "only when the map
  keys are keyword literals") is honored by the bridged rule, so a rewrite that
  should not fire still does not.
