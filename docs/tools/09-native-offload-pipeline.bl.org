#+TITLE: 9 · From proof to speed — the native-offload pipeline
#+STARTUP: showall

* The wire from a theorem to a machine-code kernel

beam-lisp can *prove* a function is pure, terminating, and well-typed — the
doc-05 conditions that make it safe to compile to raw machine code. And it has a
Cranelift JIT (in =research/j1_probe=) that turns a small IR into native code
tens to hundreds of times faster than the interpreter. What was missing was the
*wire* between them. This is that wire, as one gated flow:

1. *Gate* — =native.eligible= must return =:eligible=; a refusal names the
   theorem that failed and the pipeline stops.
2. *Lower* — =lower2= turns the eligible function into j1 IR text.
3. *BEAM* — run the same kernel through the interpreter (baseline value + time).
4. *JIT* — Cranelift compiles and runs the IR (its value + time).
5. *Oracle* — the JIT value **must equal** the BEAM value. Only a value
   -identical result may claim a speedup.
6. *Report* — the measured interpreter-vs-native speedup, gated on the oracle.

The measured result over a 1 MiB buffer, checksum kernel =acc = acc*31 + byte=:

#+begin_example
checksum: ELIGIBLE → lowered (9 IR lines) → JIT
  differential oracle: BEAM=8383099488808122916  JIT=8383099488808122916  ✓ IDENTICAL
  BEAM interp: ~1_045_000 µs   |   Cranelift JIT: ~1.3 ms   →  ≈ 440–800×

dot: REFUSED by the gate — call nth outside the arithmetic fragment
#+end_example

The interpreter and the JIT compute the *identical* 64-bit checksum; that
identity is what licenses the speedup number. =dot= is correctly refused — it
calls =nth=, outside the lowerable fragment.

* The gate is the first thing that runs

Nothing is lowered until it is proven eligible. The gate is inter-procedural:
=step= below is eligible only because its callee =dist2= is pure, and that purity
flows through the summary.

#+begin_src beam-lisp :id gate
(ns demo (:require [native.eligible :as el]))
(def prog (str "(defn dist2 [x y] (erlang/+ (erlang/* x x) (erlang/* y y)))\n"
               "(defn step [x y] (erlang/+ (dist2 x y) 1))\n"
               "(defn noisy [x] (do (IO/puts \"tick\") x))"))
(println (pr-str
  {:step  (:eligible (el/eligible prog "step"))
   :dist2 (:eligible (el/eligible prog "dist2"))
   :noisy (el/eligible prog "noisy")}))
#+end_src

#+RESULTS: gate
: {:step true, :dist2 true, :noisy {:reason :impure, :eligible false, :detail {:opaque-world :W}}}
: :ok

* The oracle is the thing that licenses the number

A fast wrong answer is worthless. The pipeline only reports a speedup when the
native result is *bit-for-bit* the interpreter's result. The checksum kernel is
a =u64= fold, so both sides must agree exactly, including wraparound:

#+begin_src beam-lisp :id oracle
(ns demo)
(def wrap (erlang/bsl 1 64))
(defn beam-checksum [bytes]
  (reduce (fn [acc b] (erlang/rem (erlang/+ (erlang/* 31 acc) b) wrap)) 0 bytes))
; the exact fold the JIT emits: acc = acc*31 + byte
(println (pr-str
  {:three-bytes (beam-checksum [1 2 3])
   :by-hand     (erlang/+ (erlang/* 31 (erlang/+ (erlang/* 31 1) 2)) 3)
   :wraps-u64   (< (beam-checksum [255 255 255 255 255 255 255 255 255 255]) wrap)}))
#+end_src

#+RESULTS: oracle
: {:three-bytes 1026, :by-hand 1026, :wraps-u64 true}
: :ok

Over the probe's real 1 MiB buffer this same fold produces
=8383099488808122916= on the BEAM — the exact value the Cranelift JIT reported.
Two independent backends, one number: that is the oracle passing.

* Where it fits, and what's next

This is the research wiring: it shells to the standalone =j1_probe=. The proof
that the pipeline is *sound* (the oracle) and *fast* (the measurement) is
complete and reproducible — run =research/native-offload/offload_run.bl=.

Productionizing it is a focused piece of engineering: a Rustler JIT-host cdylib
that exposes =compile(ir, signature)= and =call(handle, args)= as NIFs, so an
eligible function dispatches to native code *in the VM*, with the oracle run once
at compile time and the native pointer cached. The gate, the lowerer, the JIT,
and the oracle are all proven here; that cdylib is the remaining step.
