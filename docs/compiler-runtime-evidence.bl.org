#+title: Read the evidence, keep the actor

* Start with a leaf
#+begin_src beam-lisp
(ns example)
(defn identity [value] value)
(defn increment [value] (erlang/+ value 1))
(defn unknown [callback value] (callback value))
#+end_src
Build with =bl js build example=. All three functions use the same actor callable
and frame machine. The compiler infers non-suspension for the first two; the
third stays unknown. No annotation is required. Unknown does not mean incorrect.
It means the stronger checked callback entry cannot rely on this property.

* Read the build, rather than sampling the compiler
=evidence.json= contains the compiler key, namespace source path and SHA-256,
fixed-point convergence, and per-definition non-suspension. Source-generation
identity belongs to this immutable build; live actor identity belongs to its
owner. They are different facts. Ordinary call sites also carry interned reader
spans and enclosing function/arity into logical stacks.

The proof uses =system.suspension= over checked ANF. Calls within the namespace
propagate evidence to a fixed point. A finite set of nonblocking BIFs is known;
foreign, higher-order and JavaScript calls are conservative. Native diagnostics
continue through =typed=/=system.js=, including namespace annotation, receiver,
conversion and numeric checks. Authored annotations cannot manufacture proof.
Purity, termination and deadline fields deliberately remain unknown here.

* Observations have effects too
=vm.observation/query= reads a bounded existing owner projection. It does not
advance the delivery sequence. =snapshot= additionally increments the captured
reader's sequence and stamps wall time. =system.footprint= classifies those as
read and write respectively. Neither grants authority to control a resource.

* Cancellation is tested against real owners
=proc.work-model-test= extracts transitions from the actual =proc.work= server
using =system.model=, then exercises both completion-before-cancel and
cancel-before-completion repeatedly against real processes. Existing ownership,
forced cancellation, history churn and publication-generation tests remain the
runtime gates. This is bounded model/property coverage, not a universal proof
of all scheduler interleavings. Dynamic liveness and authority stay enforced.

* Try the contracts
#+begin_src sh
./bin/bl test test/bl/js_evidence_test.bl test/bl/system/suspension_test.bl test/bl/proc/work_model_test.bl
./bin/bl test test/bl/js_actor_module_test.bl
#+end_src
The JS contract checks that inferred evidence stays on the ordinary callable,
accepts its proven identity leaf, and refuses an unknown higher-order callback.
