#+title: Portable baked-gensym recognition

* Implementation and benefit
The compiler recognizes baked macro names such as x__17__auto with a pure binary
parser. A compiled Regex value can carry a node-local reference on OTP 28 and
newer. Removing that compiler constant makes compiler evidence portable enough
to certify realm release packages without weakening the certificate.

The parser trims one optional terminal LF, checks the __auto suffix, locates the
last delimiter, checks nonempty ASCII digits, and returns a nonempty base without
LF. The last-delimiter step accounts for overlapping underscore runs: x___1__auto
has base x_. Byte offsets preserve Unicode, NUL and arbitrary binary contents.
Canonical __c names remain outside this grammar.

* Prototype evidence
The actual parser source is compiled in isolation on coherent checkout
9d4aefd337f4b59a017f56f4cd0664c241c46f16. The existing Regex is the oracle for
18,944 combinations covering empty names, overlapping delimiters, ASCII and
Unicode digits, Unicode bases, NUL, invalid UTF-8 bytes, CR and LF. All agree.

Eight alternating rounds of 1,000 calls per corpus report these per-call medians:
| Corpus | Regex wall us | Binary wall us | Regex reductions | Binary reductions |
| Ordinary names | 2.2265 | 0.914 | 79.5795 | 95.5795 |
| Baked names | 2.7375 | 2.864 | 108.570 | 193.602 |
| Mixed edge cases | 2.408 | 1.938 | 82.7715 | 122.224 |

Ordinary names improve by 2.44x in wall time; baked names take approximately 4.6%
longer. BEAM reductions increase. Regex work in its native engine is not fully
represented by that reduction counter. These are descriptive microbenchmarks on
a shared host, with no application-startup or CPU-saving claim.

The same prototype VM compiles the current upstream package authority probe,
temporarily removes the saved compiler Regex binding, loads trusted stage bodies,
and obtains a complete portable compiler certificate. The saved binding is
restored in finally. This demonstrates the certificate's refusal can be resolved
by removing node-local state while retaining its evidence requirements.

* Integrated acceptance
compiler_gensym_binary_test.bl applies the same exhaustive oracle to the actual
compiler binding. aot_reproducible_test.bl checks canonical macro hygiene and
serial/parallel build identity. Realm package tests validate real fresh-VM
certificate consumption. These run against the coordinated rebuilt floor.
bench/engineering-followups/gensym-binary.bl measures the actual integrated
binding and refuses a compiler retaining the Regex constant.

The rebuilt integrated floor cf579e2e passed all 18,949 parser assertions and
7 reproducible-AOT assertions on 2026-10-09. The integrated benchmark also
completed all 48 samples (8 alternating rounds, 1,000 calls per corpus/mode),
with matching checksums and the compiler Regex binding absent. Actual-floor
per-call medians, separately from the earlier source-compiled prototype:

| Corpus | Regex wall us | Binary wall us | Regex reductions | Binary reductions |
| ordinary | 1.2305000000000001 | 0.3835 | 79.58 | 95.5815 |
| baked | 1.608 | 1.5154999999999998 | 108.56899999999999 | 193.6015 |
| edge | 1.197 | 1.014 | 82.7185 | 114.9185 |

Wall results vary with scheduling and cache state on this shared host; the
exhaustive behavior equivalence and removal of node-local compiler state are
the acceptance properties. No whole-app startup reduction is inferred from
this microbenchmark. Realm package validation belongs to its separate receipt.
