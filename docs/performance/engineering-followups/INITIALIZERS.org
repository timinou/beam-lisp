#+title: Synchronous worker dependencies during initialization

* Contract
Loader.Server owns initialization order and partially published namespace state.
A synchronous worker callback can request a lazy dependency without acquiring
loader ownership. Loader.Server/worker_call supplies a callback wrapper carrying
an unforgeable, temporary causal alias. The real loader selectively services
that reference while its monitored proxy waits for the synchronous worker call.
Ordinary competing loader calls stay queued until the initializer completes.

datom.conn applies this automatically at its conveyed Agent boundary. App authors
can initialize a connection inside a library without arranging dependency warmup.
Other synchronous worker integrations can use the same generic API. The worker
callback must complete within the call; retained callbacks need a different lifetime.

* Ordering and lifetime
| State | Allowed transition | Authority |
| Initializing | Synchronous handoff | Real Loader.Server |
| Waiting for worker | Causal nested load | Matching handoff reference |
| Nested load | Nested synchronous handoff | Real Loader.Server, new reference |
| Worker completed | Resume initializer | Monitored proxy outcome |
| Owner or proxy gone | Refuse dependent load | Process monitors |

The owner closes the alias in finally, so stale delegated requests cannot leave
executable messages in its mailbox. Nested loads execute on the real loader process, preserving its partial namespace
cycle guard. Registered Env scopes are conveyed and restored. A worker never
receives the loader's ownership flag. A guardian stops a waiting proxy when the
loader dies, including a normal exit. Accepted Agent operations retain their own
admission and executable lifetime rules and are not killed by proxy cleanup.

* Validation plan
- Source-compiled isolated host probe: causal owner identity, partial state,
  competing-load exclusion, nested handoffs, exception cleanup and expired wrapper.
- Fresh VM: required library initializer opens/transacts/closes a datom connection;
  prove completion without priming the worker's dependency closure.
- Bounded reproduction: ordinary blocking Agent call stalls its nested loader
  request; cooperative handoff completes that same shape.
- Benchmark warm direct calls, ordinary calls through worker_call and initializer
  handoffs, reporting distributions and reductions. Startup deadlock avoidance is
  a liveness improvement, not a promise to reduce normal initialization time.

Results are recorded after executing these checks against the integrated host floor.

* Focused evidence
The source-compiled host probe and system.model transition extractor report 26
passing assertions across two files (receipt initializer-probe-5.log). The model
checks the actual selective receive has exactly three scoped transitions, with
no wildcard or unrelated-call arm. Native-floor integration and benchmarks are
separate acceptance steps.

* Public raise boundary
Public erlang:raise/3 consumes a built frame list. Compiler-generated raw catch
rethrows carry the semantic ANF operand :stack-format :raw; the descriptor
validator restricts that operand to erlang:raise/3 with three arguments. The
lowerer invokes the public BIF for ordinary source calls and emits raw_raise
only for the explicit internal representation. The reference interpreter uses
the same distinction. The fresh-child regression checks error, throw and exit
replay with exact frame preservation, plus unmatched typed-catch propagation.
