#+title: Runtime integration: implementation and evidence
#+status: In progress; checked against actual test receipts

* Endpoint ownership (committed)
Commit 389586f1. os.lease owns a local flock descriptor through a port whose
stdin closes when its BEAM owner/VM dies. vm.net takes separate startup and
listener-lifetime leases. It retains persistent lock inodes, rotates new bind
credentials, and keeps existing generation-fenced cleanup. Age cannot grant
ownership. Requires util-linux flock and POSIX sh/cat; unsupported hosts fail
closed. No application API/configuration change.
Validation: os_lease_test (10), net_start_test (26),
net_listener_ownership_test (14) assertions pass. Includes SIGSTOP and owner death.
This is a correctness improvement; no production latency ratio claimed yet.

* Definition collection and loader context (integration)
Env records names at successful definition publication while an AOT compilation
collector is bound. AOT emits selected definitions rather than enumerating an
inherited table; generated names are included. Entire compile/emission scope masks
parent collectors and restores them on success/failure. Loader search/fixed/load
roots become explicit Env conveyance fields, with worker restoration and legacy
missing-field clearing. Applications do not maintain function inventories.

* Application packaging (integration)
application.package discovers the entry's dependency closure, snapshots sources,
builds admitted units and retains source fallback for unsupported top-level forms.
An OS publication lease serializes package builders. Manifest identifies compiler,
ERTS/Elixir/native bytes, entry bytes, explicit roots and exact shipped file bytes.
Production loading validates it before initialization and uses its closed inventory;
development keeps lazy/async behavior. Package selection is an optional environment
variable in :loading. Release authenticity comes from trusted deployment, not the
manifest hash. Compile-time effects can run during building; use a release process.

* Realm admission (integration)
Literal zero-argument local defining macros can be recognized structurally without
running an arbitrary expansion. Only a single quoted def/defn is accepted at top
level, then the existing closed expression gate validates the resulting definition.
Effectful, parameterized, body/provider macros and unknown forms remain source-only.
Compiler/context/realm/source identity continue to fence actual cache reuse.

* Query reuse (integration)
Extend the existing bounded ordinary-query cache rather than install another cache.
The closed read plan includes all logical branches and negative attributes. Actual
scan work allows costly empty results to learn reuse. Nonempty cheap-query admission
retains its prior work criterion. Existing current-view, schema/store, committed
attribute and code-publication checks remain authoritative; unknown providers decline.
New negative-read cases passed 14 assertions; existing positive/performance regression
failures are being corrected and must pass before this batch is committed.

* Cancellation and code lifetime (integration)
proc.admission represents local owner plus monotonic deadline. Registered Env context
conveys it. Loader.Server checks before effects; acceptance clears it so nested shared
initialization drains. Explicit module leases fence retained callbacks against
retirement and third-generation publication. Owner death is reclaimed under the
module lock. Descriptor reload uses fenced publication without forced purge/delete;
vm.core delegates soft retirement to the same ownership boundary.

* Index economics (pending)
The previous three-request admission is not cost evidence. Integration must account
for measured scan/build/maintenance costs and bound writer occupancy. Native-store
experiments, including cases where the index loses, are required before enabling a
new automatic policy. No guessed universal break-even threshold is presented as
measured evidence.

* Measurement discipline
Research ratios are mechanism experiments, not full Knowledger startup/navigation
results. Integration must retain result parity and adversarial controls, record exact
commands and samples, and distinguish cold source, cold repair, warm repair and
prebuilt loading. The shared host and bootstrap refresh cost are reported separately.
