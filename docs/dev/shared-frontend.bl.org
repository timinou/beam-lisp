#+title: Shared services and speculative frontend compilation

* One owner for each service
=vm.service/acquire= reserves a realm service before acknowledging callers.
=value= and =lookup= read its initialized value through the same native actor
handshake. =apply!= sends an operation to that owner, serialized with stopping.
This is an in-process actor message, with ordinary BL values and no encoding.
The owner's environment remains authoritative.

Queued operations retain their callback code. Acceptance transfers ownership to
the service before execution. A disconnected or expired queued caller cannot
start its operation; an accepted operation drains with its owner even if the
caller disappears. Exceptions return to the caller without stopping the service.

* Cooperative speculative work
=proc.admission/check!= is a no-op without a request. A cancelled or expired
request throws a cancellation exception. Put checkpoints between compilation or
publication phases so private staging, environments and OS leases unwind through
=finally=. Do not kill a worker that may hold global compiler publication locks.

The existing ReloadWatcher accepts an optional =:on_change= callback for raw
file events, including removals and CSS. Omitting it preserves ordinary reload
behavior. Applications can debounce these events with =proc.tick= and compile
immutable candidates before offering explicit session navigation.

* Compiler evidence
The JS builder records =out/dependencies.json=: source bytes consumed, declared
requires, linked namespace edges, target contracts and checked-ANF cache choices.
It retains the common compiler and complete linking/native audits.

=BL_JS_CACHE=on= enables an experimental checked-ANF disk cache for the verified
finite lexical profile used by =vm.shared=. Custom checkers, ambient definitions
and unsupported macros decline reuse. Keys bind actual read bytes, compiler
executable authority and resolved namespace home. Products cannot retain live
references. Corrupt or incompatible entries compile normally.

This cache is off by default: two-function and hundred-function benchmarks on
the development machine were slower with validation than direct compilation.
A hit is not a performance result. Broader dependency tracking and a measured
crossover are prerequisites to making this profile automatic.

* Precompiled application admission
Application artifacts record their compile-time capability grant; installation
requires an exact match. Precompiled loading must not bypass a restricted source
compiler by importing a package compiled with broader host permissions.
Compiler authority also checks installed executable evidence and scoped
namespace generations. A live empty fork may reuse the same certificate;
nonzero overrides, dead scopes and changed backing code continue to refuse.
=BeamLisp.AOT/local_package_authority_report= explains conservative refusal.
