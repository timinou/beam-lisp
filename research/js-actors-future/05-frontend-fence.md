# Frontend placement: evidence before emission

This is an architecture assessment, not an implemented automatic partitioner. The present `research/js-actors` emitter builds a trusted BL subset for one JS runtime; `live.socket` renders on BEAM and `live/client.js` applies patches. A quoted-view prototype exercises a narrower route before relocating general view functions.

## Available evidence, and what it says

| Layer | Current entry / evidence | Useful for placement | Refusal boundary |
|---|---|---|---|
| Reader types | `priv/std/typed.bl` `check-source`, `check-source-with`, `hover`: tag sets, source-position warnings, seeded signatures, guard narrowing | Candidate value categories and diagnostics | Unknown callee → `any`, not a portable type proof; annotation is a claim. Anonymous `fn` bodies/captures are not typed transitively. |
| Source graph | `priv/build/source-graph.bl` `header*`, `references`, `closure`, `closure-hash`; `priv/std/codebase.bl` `index-source`, `reachable`, `impact` | Dependency facts and cache invalidation | `codebase/dependency-cone` now joins alias-qualified/referred calls across namespaces and reports `:undefined`/`:unresolved` edges; its legacy raw-name queries remain for callers. Only `defn`/`defn-` mint function entities. Computed-head calls now produce explicit unresolved edges, receive-bound names cannot become false static edges, and a missing root marks a cone incomplete. `:refer :all`, general dynamic dispatch and closure captures remain unresolved; a cone marked incomplete cannot authorize placement. Fact-schema changes invalidate both per-file and corpus memo keys. |
| Effects | `priv/lib/system/footprint.bl` `fp-anf`, `pure?`, `resources`; `system.summary/summarize`, `system.analyze/analyze`; `system.prove/prove-node` | ANF resource→mode footprint, call-flow fixpoint, termination and returns; proofs can travel in `:ann` | `analyze` still sees one source and only `defn`/`defn-`, but now unions **all** clauses' footprints/calls/returns, requires every clause to terminate, and includes later-clause flow. Unknown call → `:opaque-world`. `priv/std/effects.bl` is a reader-level rung shim, not an independent transitive placement gate: a `fn` value is `:pure` without evaluating its body. |
| Existing portability gate | `priv/lib/native/eligible.bl` `eligible` | Useful verdict shape: named refusal for footprint, termination, sorts or work | Its NIF scalar sorts/work constraints are **not** browser availability or wire safety. JS emitter's closed ABI audit in `research/js-actors/compiler.bl` is the actual final target check. |
| Oracle / Z3 | `priv/lib/oracle.bl` `ask`, `session`, `scoped`, `proven?`, `refuted?`, `undecided?`; `priv/lib/z3.bl` `prove-equiv`; `priv/lib/system/smt.bl` | Build-time symbolic equivalence over supported Int/Real/Bool/String, enum and length fragments | `:unsat` is positive evidence; `:sat` is a counterexample; `:unknown`/`:error` and `:untranslatable` are *not permission*. Native port needs pinned Z3 and runs on BEAM, never in the browser. General BL value codec/collection element semantics are outside today's SMT fragment. |
| Veritas | `priv/lib/veritas.bl` `for-all`, `exists`, `check`, `covers`, `faults` | Symbolic proof where translated, finite exhaustion where finite, bounded counterexamples and differential regression | `:proven` only for solver or finite exhaustion; `:witnessed` from sampling is not universal proof. Generator scope and translation must cover the claimed domain. |
| System models | `priv/lib/system/model.bl` `transitions`; `system.core/verify-process`, `footprint-in-caps?`; `system.knowledge` | Server `defserver` transitions, invariant and message-coverage checks, capability containment | `:complete false`, `:unmodelled`, `:undecided` or `:unchecked` refuse placement/bridge certification. The corpus explicitly declines many reactive machines. Neither purity nor process safety proves client data is authorized for disclosure. |

`system.smt` is the single ANF→SMT translator; `smt.bl` is its printer. Structural call topology belongs in codebase/datalog; footprint containment is BL set algebra, not a solver question. `native.eligible/eligible` is the closest existing template for a named, fail-closed verdict; the current JS compiler independently rejects unknown host/globals, unsupported operations and unsafe integer literals. The numeric gate only proves literal/let-derived safe `Number` paths. Exact bignum/decimal and a lossless general cross-runtime codec do not exist.

## A build-time cutover, in dependency order

1. **Normalize the call cone.** Resolve aliases and `:refer` with `source-graph/references`; index fully qualified definitions, every clause/arity and macro-expanded source. Track anonymous function captures and higher-order dispatch explicitly. Unknown call edges stay opaque. Feed the normalized facts to `codebase` and run `system.analyze` over the entire require closure, not one file.
2. **Make one client eligibility verdict.** On canonical BL-ANF, combine full transitive footprints, termination/work budget, resolved captures, value provenance (public/authorized vs secret), typed wire-safe input/output sorts, and the JS emitter's actual supported ABI/ANF operations. `:opaque-world`, missing information or unknown effect → server. A pure view reading a passed-in secret is *not* publishable merely because its footprint is empty. Do not duplicate the compiler's host allowlist.
3. **Generate one bridge contract.** Retain `live.socket`'s data-event vocabulary (`:assign`, `:intent`, `:navigate`) and server-side auth/commit. Compile a closed intent manifest and its versioned request/response codec from a single BL declaration. Refuse non-serializable captures, closures, unknown tags, cycles and values without exact numeric representation. Correlate requests; handle reconnect, cancellation, replay and stale-version semantics explicitly. Never treat client identity or a claimed effect as authority.
4. **Prove/check the seam.** Verify `(decode (encode x)) = x` and client-view/reference-view equivalence over declared domains with `system.smt`/Oracle where expressible, and Veritas finite or differential tests elsewhere. Check emitted-client behavior in a real browser and authorize intents at the backend independently. Produce a report naming `:proven`, finite exhaustion, sampled/witnessed, counterexample and unknown; only proved coverage may authorize automatic placement.
5. **Replace, don't fork.** A compiled client view eventually replaces the corresponding hand-written client behavior, while the backend remains the sole authority for shared facts. Preserve the server-rendered `live.socket` path for code that cannot be moved, without silently changing event semantics.

The editable quoted-view demo now checks the BL-advertised contract before a live button intent and waits for a server-confirmed Worker frame; its view still bypasses general automatic placement. The first `compiler.bl/portable-helper-verdict` admits only a closed nullary printable-ASCII helper chain, after qualified dependency-cone, all-clause analyzer and actual emitter ABI checks; no inputs, captures or wire values. This is a first build-time verdict, not an automatic Loom/Live cutover. The view evaluator remains an explicit closed grammar and the intent bridge remains explicit. This is a test fixture for the future gate and codec, **not** evidence that arbitrary `loom.ui` modules are client-emittable or that the JS actor runtime isolates untrusted BL source. `proc.fence` bounds a BEAM child computation; it is unrelated to compile-time frontend placement.

### Where the split showcase stands against this cutover

`research/js-actors/showcase.bl` + `compiler.bl/split-plan` implement a first end-to-end cut of steps 1–3 **for one self-contained app file**:

| Step | Implemented | Still open |
|---|---|---|
| 1. Call cone | Per-function closure over the emitter's own ANF references (calls and function values, incl. inside lambdas and vector literals); `codebase` cone for graph evidence; keyword lookups no longer count as dynamic calls | One file only: no cross-namespace app code, no macro-expanded user helpers beyond what the compiler expands |
| 2. Eligibility | Per function: graph ∧ all-clause `system.analyze` footprint `{}`, latent footprint `{}` (effects of the function values it creates/names) and path-guarded loop termination ∧ emitter ABI scan ∧ closure flow (0-CFA over the app with a derived runtime model; every call cycle admitted only by capture order or structural descent — higher-order code, combinators and structural recursion are client-eligible) ∧ not `:private`, closed under callees; a client-closure miss refuses the build with the root→offender path. Core value purity is program-aware (a `def`/`defn`/`declare` shadow voids it) | Value provenance of *arguments* (a secret passed into a pure view) is not tracked; the app's `:private` declaration and the snapshot projection are the only secrecy tools. No work budget beyond termination |
| 3. Contract | One `split/defapp` declaration → canonical JSON contract + SHA-256 digest carried by both halves; closed wire grammar; strict codec; BL re-check of digest, op, args, revision, shared check, server guard and snapshot invariant; stale-revision rebase via the shared check; unanswered intents dropped | No reconnect replay/cancellation protocol beyond SSE hello resync; no authentication |
| 4. Seam proof | Two apps on one shell (launch board, nested outline with a recursive wire type); 24 + 22 Node end-to-end checks, 13 build-refusal + 4 must-admit higher-order fixtures, BEAM↔JS differential (30 answers: ordering, sequential family, combinators, prelude), ~90-case independent probe of the termination gate, real two-tab browser run | No `system.smt`/Veritas equivalence of client vs reference view; codec round-trips are example-based |
| 5. Replace | — | Not wired into `loom`/`live` |

It is still a build-time partition of one declared app, not automatic Loom/Live placement.
