#+TITLE: Reproduce live evolution acceptance

Run from the source checkout. Use ./bin/bl rather than an installed SDK. Native Fjall and z3 must already be available. Read AGENTS.md before starting VMs, and do not overlap these scripts with other owned cold VMs.

* HTTP continuity
#+begin_src sh
python3 research/live-migration/measure.py --selection prepared
python3 research/live-migration/measure.py --selection serialized
#+end_src

Each invocation creates a private HOME/tmp/live-migration/http-* application root and production-policy env.bl, launches one memory-capped systemd user service, drives eight concurrent HTTP clients, validates matching durable writes and process identity, saves results.json, then stops its own service in finally. No public listener, remote app, or installed artifact is changed. The two modes select candidates outside/inside the writer respectively; prepared selection revalidates selected IDs inside the writer before commit. Completion checks run against the committing database.

The workload intentionally includes a full 500-row read and a durable write per request. Workload membership stays fixed during backfill; production producers must maintain expanded data or keep final checks open. max-step-ms is wall time including selection and queuing, not writer occupancy. Shared-host measurements establish continuity and latency costs; they do not establish a production SLA or a controlled cross-run speedup ratio.

* Abrupt VM restart
#+begin_src sh
python3 research/live-migration/restart.py
#+end_src

Two capped VMs run sequentially. The first halts abruptly after 60 durable rows with no completion stamp. The second opens the same store, refuses changed partial implementation bytes, completes 200 rows, and checks idempotent replay/digest conflicts. A nonzero first exit is required evidence, not a test failure. The driver requires exact exit 137 and the progress marker. This is process-crash recovery, not a power-loss test.

* Diagnostic selection probe
probe.bl records full negative-query work and individual migration steps. Supply a NEW private LIVE_MIGRATION_ROOT under HOME and TMPDIR under HOME. A reused root contains completed rows and is not a fresh measurement. This diagnostic is not the HTTP acceptance test.
