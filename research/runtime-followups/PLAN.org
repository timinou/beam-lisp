#+title: Seven runtime follow-up prototypes
#+status: in progress; research, not production integration

* Goal and pinned bases
Start with application AOT packaging; explore all seven remaining opportunities.
Beam base f90a9aa2; Knowledger base 5cbe58ad. Isolated research/runtime-followups
worktrees, home-directory scratch, one bounded BEAM job at a time. Concurrent
main edits are excluded. No stash/reset/revert/checkout. Semantic commits.

* Measurement contract
Use actual compiler/loader/store/OS mechanisms where available. Same workload,
result parity, negative controls, ABBA samples, time plus reductions/work/bytes.
Separate build, validation, initialization, source loading and process startup.
Record host pressure and source/SDK identity. Models are finite assurance, not
universal runtime proofs. Prototype policies and descriptors are not shipped APIs.

* TODO 1. Application AOT packaging
Build real BEAM modules with existing AOT; relocate output; run source-free strict
initialization in fresh VMs. Compare source and artifact startup, verify target-env
values/exactly-once initialization, tamper/stale-source refusal. Include real
Knowledger libraries and account for package size/build cost.
* TODO 2. Generated-definition tracking
Measure full-table filtering versus tracked-name projection with real Env tables,
including generated definitions, inherited entries and replacements. Identify
publication hooks needed to avoid lexical-only unsoundness.
* TODO 3. Broader realm admission
Use real realm AOT and effect/IR analysis; measure cold/cache/decline cases and
initializer replay. Compare safe macro expansion with effectful negative control;
measure validation cost and identify authority required for automatic admission.
* TODO 4. Executed dependency/result authority
Extend existing logic-backed datom projection adapter; benchmark relevant,
unrelated, negative-read and authorization invalidations with actual store counters.
* TODO 5. Adaptive index economics
Measure actual native rank construction, scans, indexed reads and writer latency
at multiple sizes/reuse levels. Calculate observed break-even; model conservative
admission and expose cases where fixed demand is uneconomic.
* TODO 6. Cancellation and code leases
Measure admitted/drained versus canceled queued work with real processes; exercise
actual BEAM old-code retirement and leases. Verify finite race models, owner death,
accepted initializer completion and generation pinning.
* TODO 7. Endpoint leases
Prototype OS-owned lock/socket lifetime, crash recovery and identity-safe cleanup.
Measure acquisition overhead/recovery and test live/paused owner refusal and stale
cleanup. No destructive changes to real endpoints.

* Deliverables
Reproducible scripts, raw evidence, machine-readable summaries, org conclusions
per area, implementation seams/risks and an ordered production integration plan.
