#+TITLE: Split cells — where does each cell run?

bl-ed asks the BEAM's analyzer (=system.place=) where every cell may run.
A cell that is pure and provably terminates is marked ● and evaluates
*here, in the page*, through Beam Lisp compiled to JavaScript. Anything else
is marked ◆ and evaluates on the BEAM. Hover a mark to see why.

* Pure cells run in the page

#+begin_src beam-lisp :id sq
(defn sq [x] (* x x))
#+end_src

#+begin_src beam-lisp :id squares
(mapv sq (range 1 8))
#+end_src

#+begin_src beam-lisp :id stats
(let [xs (map sq (range 1 101))]
  {:n (count xs) :sum (reduce + xs) :max (apply max xs)})
#+end_src

#+begin_src beam-lisp :id money
(* 19.99M 3)
#+end_src

* Effects run on the BEAM

#+begin_src beam-lisp :id readme
(count (File/read! "README.md"))
#+end_src

#+begin_src beam-lisp :id clock
(System/os_time :second)
#+end_src
