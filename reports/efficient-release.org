* One candidate, explicit consumer evidence
CI transfers the complete self-built drop and runs each ordinary test partition
through that exact executable. Checkout provisioning, compiler reproduction and
second-build qualification remain separate gates. Compiler reproduction and
independent-process lock checks precede SDK assembly in CI, so they fail before
the expensive artifact and test stages. Four duration-balanced shards
match the four available parallel runners; every conventional test is assigned
exactly once. Historical timings are estimates, not coverage exclusions.

scripts/qualify-candidate.py records per-file results immediately as JSONL,
including elapsed time, failed assertions and exception data. It uses Ward's
own monitored workers and source checks. Batch exit failure cannot be hidden by
successful per-file records. Every receipt is
bound to both the executable SHA-256 and the complete repository input digest.
Resume accepts only matching inputs. Failed files remain failed; an interrupted
last record never counts as completion. The driver isolates process dictionaries
per file, runs files serially, limits each file and continues after loading errors.
CI caps the whole process tree and uploads receipts even on failure. Private
checkout endpoints are stopped after the run.

* Compiler-owned server returns
The compiler and native runtime share one return-constructor vocabulary.
Ordinary callback return forms emit OTP data directly, preserving ordinary
argument order and exactly-once evaluation. First-class captures retain their
callable behavior and lexical shadowing remains ordinary local binding. This
removes native reflection/lookup from user callback return execution.

Source adaptation preserves the canonical compiler input guard and native actor
init prologue. Rewriting runs before reading its accumulated counters. Newly
constructed IR nodes always carry a map annotation. These changes cover the
actor, generated-class and HTTP body-carrier failures from the prior CI inventory.
Matching-floor and complete-candidate regression results are still required.
The same mutation/read ordering defect also existed in registration and
reconciliation adapters; both now finish rewriting before recording its evidence.

* Native cycle-collection tail
A threshold-triggered scan can observe a producer before its final roots drop.
With no subsequent allocation, another threshold may never be crossed. The
worker now performs one delayed settling sweep after demand-triggered activity;
an idle worker has no polling timer. Stop notifications interrupt the delay.
The existing real committed-growth regression remains unchanged. Native Rust
unit tests pass all 37 checks; real SDK regression qualification is pending.

* Executable startup must use its own compiler
The previous complete image passed its private harness but its packed entry
failed from the checkout: AOTCache used the caller's cwd to fingerprint native
compiler sources when BL_ROOT was absent. Edited checkout sources contaminated
the installed image's identity and triggered source bootstrap. Implicit source
selection now belongs to the running application; an explicitly supplied
checkout BL_ROOT remains authoritative. This is tested at the exported source
root boundary and must also pass the real executable from the checkout.
