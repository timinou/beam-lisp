#+TITLE: Native refresh trusts modification times and ignores the platform
#+DATE: 2026-10-07
* DONE Reuse the content-keyed native producer at boot
The combined gate exposed an older checkout JSON .so despite corrected Rust
source. vm.native/build-all! scanned only the current project's native directory,
and freshness accepted any .so timestamp newer than the Rust files. Consumer
commands therefore skipped engine changes; copied/newer binaries bypassed fixes.
Boot now discovers distinct source-backed consumer and BL_ROOT platform roots
and invokes the existing native build/cache producer. Its source/toolchain key,
claim coordination, artifact naming and installation have one owner. No caller
setup. Source-free releases perform no build work; absent cargo or a trimmed
producer is reported and does not kill the ordinary command. Public explicit
build! remains the existing one-crate operation; boot no longer trusts its mtime
shortcut. This refreshes artifacts; already loaded NIFs retain their VM lifetime.
