#+TITLE: Copied checkouts silently load another image's code
#+DATE: 2026-10-07
* DONE Verify the image links' exact targets
The checkout launcher only checked whether its .bl image links existed. A copied
checkout with valid absolute links therefore loaded the previous checkout's
host beams and priv sources, silently bypassing local fixes. Found when the
new CSS preview still executed the removed warm route renders. Discarded run.
The launcher now checks exact ebin and priv link targets before launching;
repairs missing/broken/stale links and refuses to replace ordinary directories.
No caller setup required. Correct existing links remain untouched.
* Validation
Seven shell checks execute the actual launcher helper without a BEAM: creation,
stable correct links, valid old targets, dangling targets, paths with spaces,
refusal of ordinary directories and preservation of their contents. sh -n passes.
