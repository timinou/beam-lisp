#+title: Avoid repeated CSS declaration formatting and unchanged sheet writes
* DONE Repeated styles pay work for immutable results
Loom formats and records the same declarations repeatedly within each page.
Cache scalar declaration maps per process after theme resolution, bound to
512 entries. Skip process sheet writes when the class already maps to identical
CSS. Custom value printers bypass caching. Cache hits register after sheet reset.
* Validation
147 assertions passed across token, box and ui. New checks cover fresh-sheet
registration, theme and breakpoint changes, canonical authoring order, memory
bound under 1,100 unique declarations.
Same VM, preserved HEAD namespace, three interleaved pairs of 2,000 sx calls:
original 11.64–11.66 million reductions / 76.2–102.5 ms;
cache 3.40 million reductions / 16.7–17.7 ms (71% fewer reductions).
Benchmark requires copying HEAD token namespace to loom.token-original on a
temporary search path, as used in /tmp/kn-token-baseline. No app configuration.
