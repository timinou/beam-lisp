* Initial Message

see how the feat/bb-compat branch works and how to merge it back to main

* Symptom

Post-merge fresh-toolchain run: `system.lsp-test / document-symbols-carry-growth` —
fib classified :linear O(n) instead of :exponential O(2^n), witness "2 self-call sites".

* Root cause

feat/bb-compat's decimal work introduced the numeric-tower dispatch: 2-arity core
arithmetic now compiles to `(let [a x] (let [b y] (if (is_map …) (Num/sub a b)
(erlang/- a b))))` (BeamLisp.Num decimal path + raw BIF fast path). The growth
classifier's `arithmetic-image` (priv/std/termination.bl:288) pattern-matched a bare
`{:op :remote :mod :erlang :fun :-}` — under the scaffold it sees an `:if` and returns
nil, so ≥2 arithmetic self-call sites were never counted and fib read :linear.

The canonical de-scaffolder already existed — `ir/arith-bif` (priv/lib/system/ir.bl:55,
"the one place that recognises the scaffold and hands back the BIF over the original
operands") — and `measure-dir` already used it (termination.bl:67); `arithmetic-image`
was the one recognizer that didn't. One-let fix.

* Why the merge suite didn't catch it

The first post-merge runs executed a STALE pre-merge toolchain (BUG-052): old
codegen emitted bare BIFs, so the classifier saw the shape it expected. Only a
fresh-toolchain run (post mix-cutover) exposed it. system.termination-anf-test stayed
green because its fixtures spell `erlang/-` explicitly (no dispatch scaffold).

* Fix + verification

`arithmetic-image` now unwraps via `ir/arith-bif` (priv/std/termination.bl:292-296).
Probe: fib → :exponential, witness "2 self-calls descend n_3 by arithmetic".
`bin/bl test test/bl/system/lsp_test.bl` → 35 passed; termination_anf 8 passed.

* Lesson (class-level)

Every ANF recognizer that pattern-matches arithmetic/order remotes must route through
`ir/arith-bif` first. Sibling sites audited: summary.bl:92, typecheck.bl:32,
smt.bl:112 key on BIF remotes — they are safe ONLY for sources that spell `erlang/+`
directly; core-spelled `(+ x y)` produces the scaffold. If those checkers ever run over
core-spelled arithmetic, they need the same unwrap — not verified needed today.
