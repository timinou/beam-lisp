#+TITLE: Compiler-generated scoped System calls were refused as Env reflection
#+STATE: FIXED — actual compiler ANF regression

System/get_env compiles to the native scoped Env.os_get_env bridge. The generation
checker rejected that exact compiler output as unmanaged-compiled-producer,
although the source had explicitly declared System native authority. This would
block ordinary product functions at compilation after source closure was fixed.
The failure is recorded in nested-boundaries.log before the fix.

Only the exact existing OS environment/command bridge methods and their supported
arities are now accepted in compiled ANF, and only with the System native grant.
Direct reflective host source remains forbidden. Effectful namespace initializers
still refuse before evaluation. No arbitrary Env/compiler API was authorized.

Eight assertions exercise scoped reads,fetch,local writes/delete,caller restoration,
missing System authority,raw host source refusal and initializer refusal. Included
in the258assertion native acceptance recorded alongside the nested-call benchmark.
The bridge reuses the existing committed native ABI; no bootstrap regeneration.
