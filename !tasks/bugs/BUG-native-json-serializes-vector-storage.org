#+title: Native JSON must encode logical persistent vectors
#+date: 2026-10-06
* DONE Persistent vector storage escaped the native encoder contract
Activity and Knowledge patches fell back to the Lisp JSON walk. A 50-row
Activity fixture spent 201.953 ms / 9,278,285 reductions serializing 74,840
bytes, whereas supported Library patches spent 2.146 ms / 5,445 reductions.
Native encoder treated Vector.items as a flat tuple even after persistent
vectors gained {:bl_vec,count,shift,root,tail} storage. This is also a
correctness defect: successful encoding must never expose trie internals.
* Implementation
Recognize the same tag/count boundary as host Vector. Walk validated 32-wide
branches and leaves in logical index order, append tail, preserve legacy flat
tuples. Storage depth is independent of JSON value depth. Invalid storage
fails closed and does not preallocate from an untrusted count.
* Validation
Build in /tmp/kn-json-native-target; load through isolated cwd
/tmp/kn-json-native-root/priv/native without overwriting shared native artifacts.
Tests require native-loaded status and compare exact expected JSON at small,
leaf, root-growth and deeper-trie boundaries; nested rows roundtrip as well.
First isolated test attempt refused BEAM_LISP_PATH repository root because
its env namespace shadows the library. Removed the unnecessary path entry.

196 assertions passed (33 native boundary / nesting assertions plus 163 JSON
fidelity assertions). Test-only initial nested map used keyword keys, while
default decode returns strings; corrected fixture to string keys.
