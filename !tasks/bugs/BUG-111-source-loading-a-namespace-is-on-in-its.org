* Initial Message

merge this branch onto main, then come back to me and explain the next steps (we'll keep working on this branch)

* Symptom
`bl run research/js-actors/compiler.bl` went from about 3 minutes to about 25 minutes warm (31 minutes cold) on 2026-10-03. Any large namespace that is evaluated from source, rather than loaded as AOT beams, slows down the same way.

* Measurement (2026-10-03, this host, js-actors worktree at 7f91b0e1, main's link.bl unchanged)
Fixture: a namespace of N one-line `defn`s, loaded with `BeamLisp/run_file`.

| N defs | wall | ms per def |
|---|---|---|
| 50 | 4.0 s | 80 |
| 100 | 10.6 s | 106 |
| 200 | 35.4 s | 177 |
| 400 | 157.4 s | 394 |

Going from 200 to 400 defs costs 4.45× the time, so the growth is quadratic. A sampling profile of a `JS_ACTORS_APP=groceries` build spends its largest share (~25%) in `compile:do_compile < Lower/module->beam < Emit/compile_descriptor < Link/defvar`.

* Cause
`priv/host/link.bl` `defvar` (lines ~95-117): every def compiles a fresh body module AND recompiles the namespace shim from `(Emit/shim_clauses all_defs)`, which has one forwarding clause per def in the namespace. Def k therefore compiles a module of k clauses, and a namespace of N defs compiles about N²/2 clauses in total. Since 6c077732, `defvar` also calls `Env/unlink_ns_defs` on each def.

* Fix directions (not yet chosen)
1. Batch: while a source file is being evaluated (`Loader/do_load` / `eval_string` of a whole file), defer shim regeneration and emit one shim at the end of the file. A live `defvar` (REPL/reload) keeps the per-def path.
2. Make the shim independent of the def set: one dispatch clause that looks up the body module per {fname, arity}. This trades a static direct call for a lookup.
3. Callers that only need ANF should compile it (`Ns.Compiler/compile`) and skip `eval`. The JS sync target (priv/lib/js/build.bl) already does this.

* Gate
The N=400 fixture must load in roughly linear time (≤ 2× the N=200 time), and `bl run research/js-actors/compiler.bl` must be back near its previous ~3 minutes.
