#+TITLE: Bound optional read caches by retained data and logical revision
#+DATE: 2026-10-07
* DONE Generic cache foundation
Count-only caches can accumulate historical revisions, retain native handles,
keep huge parent binaries via small slices, and disappear with the first reader.
Added data.cache-budget pure admission/replacement policy and data.bounded-cache
protected ETS owner independent of callers. Defaults: 32 MiB charged data,
2 MiB per entry, 4096 logical keys. Revisions replace instead of accumulate.
Typed keys encode local reference identity without retaining native handles.
Values reject resources, closures and opaque/deep data; parent binaries charged.
Cache failure bypasses caching; computation exceptions propagate. Function code
identity invalidates changed local computation bodies. Callers remain responsible
for expressing all semantic inputs; imported dependency hot reload is not tracked.
Limits describe conservative retained-data charges, not a total VM RSS guarantee.
* Validation
1962 assertions passed, 9.679 seconds, 229.6 MB peak, no swap. Includes generated
budget invariants, 10000 revisions, actual byte-pressure eviction, reader death,
reference isolation, nil values, parent binaries and computation code changes.
App integration and deployed runtime release are separate work.

* DONE Admit real models without blocking reads on optional cache writes
Real frozen Knowledge snapshot:1316 names,141 documents,3027466 charged bytes;
initial2MiB per-entry limit declined it and made a proposed projection migration
rebuild on every visit. Calibrated per-entry cap to8MiB, retaining32MiB total.
Oversized/opaque admission is now proven in the caller BEFORE starting an owner
or copying data into its mailbox. Immutable finite data carries that charge into
pure serialized publication; the owner does not repeat a large traversal.
Start/write/stat waits use25ms rather than OTP's5-second default. Suspended
owner test proves a successful computed answer returns before owner resumes.
Direct ETS reads keep working while owner is suspended. Publication may arrive
after timeout; reads still require the exact revision. Owner clear is test-only.
1969 cache +3017 FIFO +84 query-cost assertions passed,35.367s,355.7MB,no swap.
New charged-row sum check matches retained stats. Defaults require no caller
configuration. Per-entry calibration is backed by actual model footprint.
