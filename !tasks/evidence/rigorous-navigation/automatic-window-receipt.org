* Implementation

prefix traversal; scalar count q shares exact membership. Non-count q checks its
cheap shape before loading the rank controller. Background worker cap4 node-wide,
index cap4/store with bounded retirement: later scopes can enter and return.
Native/resource-bearing store handles remain in live connection-owned workers,
not node-wide slot keys. Rank traversal caps4092 node reads and7.5MiB node payload;
explicit caller budgets use ordered fallback. No cursor contract changed.
* Limits
Coarse global publication epoch may refuse after unrelated lazy loading. New VM
requires rebuilding. Crash/reopen fault injection, worker-owner cancellation and
write-drain races, schema/rebind/overflow proofs, write-cost and cheap-query
measurements are still required. No browser latency claim follows from these
assertions. Activity adoption is separately tested and measured in its repository.
