* Implementation and metric
Env/ns_definition selects the requested definition INSIDE ETS from a fully bound
namespace-table key. Own-table misses shadow parents, absent tables inherit and
lazy AOT descriptors resolve the immutable module literal. Publication snapshots
use this accessor rather than returning an entire namespace AST table first.
Actual64-entry fixture: whole67772 serialized bytes, selected1053 bytes,98.45%
less returned metadata. This is not a measured CPU or browser latency ratio.
The earlier v4 root receipt remains94 bytes at both1 and32 definitions. Compiler
Link.defvar still builds full ns_defs maps; eliminating that separate quadratic
copying path remains follow-up work, not a claim of this change.
