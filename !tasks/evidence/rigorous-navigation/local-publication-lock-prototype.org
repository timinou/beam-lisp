* Implementation constraints
Node-local scope ownership; ETS insert_new acquires one ticket, exact-object
removal releases/reclaims it. Never delete by key after observing a dead owner.
A private process marker preserves nested ownership and is not conveyed. No scope
lock is held while acquiring another scope or a namespace lock. Contention yields
one millisecond and does not promise FIFO fairness. Actual retirement, publisher
owner death, parent/child metadata and publication evidence gates are required.
The reserved lock key is outside environment prefixes, so scope destruction
cannot erase its own active lock. Ordinary scopes and applications configure
nothing. Official seed and packaged/browser checks remain required after source
integration; prototype acceptance does not complete that integration.
