Shared-host pressure makes elapsed time noisier than work counters.

* Byte interpretation
root-flat-bytes measures the returned lookup_own reply, including its wrapper,
not total ETS allocation. A64-byte reply replaces a root reply containing every
AST. The ASTs still exist in separately keyed rows, with additional row overhead;
this is not a claim that total metadata storage becomes64 bytes. The full-map
oracle is deliberately materialized outside the write timing. All new scopes
are destroyed; the temporary baseline native module and source directory are
unloaded/removed by the fixture's finally block.
