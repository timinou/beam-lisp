#+title: Connection-owned instrumentation retirement and truthful traces

* Changes and validation
Connection release drains the source writer and then removes its guard entry and
all registered profiler wrappers for the underlying store identity, before the
registry permits another lifetime. Old explicitly held wrappers remain usable.
Instrumentation registrations are capped at256. Totals carry a registration
epoch; delta declines across retirement/eviction instead of producing misleading
or negative request costs.
A query with an active clause trace bypasses result reuse and result admission.
This fixes missing trace evidence on warm hits; ordinary untraced queries retain
reuse. Existing trace tests exposed the defect before the change.
profile-closure-first-gate.log: profiler44, ownership9, connection-lifetime19
assertions passed (72 total). The independent draft dependency-closure suite
failed in the same VM and is still under investigation. Full run is NOT green.

* Limits
ETS owner-death cleanup is not implemented by these release hooks. The bound is
on instrumentation registrations, not total storage bytes owned by callers.
No application API changes are needed for ordinary connection release.
