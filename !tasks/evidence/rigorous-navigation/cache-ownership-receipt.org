* Mechanism and developer cost
Store/cache-key turns underlying store identities into typed resource-neutral
terms through the existing bounded-cache identity normalization. Local reference
resources become identity strings rather than retained native handles. Distinct
stores stay distinct; transparent wrappers share one key. Unsupported identities
return nil and bypass optional cache retention, never a shared fallback key.
Attribute marker hydration keeps real handles for durable I/O, uses neutral keys
only for memory state, and removes the duplicate full marker-map ETS return.
Owned Conn.release! retires this store's markers, including pre-upgrade raw keys,
before publishing the ended lifetime. Embedding corpus memory keys also become
resource-neutral; unsupported identities assemble without retained rows.
No application annotations, counters, explicit invalidation or cleanup calls added.

* Native lifetime oracle
Both named tables remain alive while a monitored child opens a unique Fjall
store, commits a vector, assembles its cached column, releases the connection,
syncs and exits. Parent reopens the same path and reads the durable vector marker.
Retained keys pass the existing resource-rejecting footprint validator. This
would fail if table deletion on writer death hid the ownership problem.
Unsupported Store records containing PIDs still read distinct durable markers and
return distinct column sizes with zero retained corpus entries.

* Limits and follow-ups
This fixes native store retention by newly written derived-cache keys. It is not
a general garbage collector or a measured browser latency reduction. Metadata
size limits, stable table ownership/recovery, fully concurrent corpus accounting
and retirement of legacy corpus rows in an already-running upgraded VM need
separate designs/gates. A fresh runtime uses neutral corpus keys; no live upgrade
migration of every old global corpus row is claimed. Generic bounded caches
already account independently; this does not put legacy corpus/marker tables
under their aggregate budget. No blanket native/vector resource reclamation claim.
