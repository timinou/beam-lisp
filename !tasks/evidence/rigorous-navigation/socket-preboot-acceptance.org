* Source changes

only their parent and close the socket on termination. Acceptors subscribe to
no worker DOWN messages. No application callback/configuration change.

controls read the process-local overlay directly, falling back to raw OS reads;
compiler source identity reads physical BL_ROOT. The standalone cache host has
no Env/Core dependency.
