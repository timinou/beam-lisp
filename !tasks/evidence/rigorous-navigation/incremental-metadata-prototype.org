#+TITLE: Incremental metadata storage representation prototype
#+STATE: ISOLATED PROTOTYPE; production Env/Link unchanged

* Accepted runtime evidence
22 assertions pass using a real isolated public ETS table. Tests cover inherited
full-table visibility, empty own-table shadowing, selected-definition miss,
incremental insertion, interrupted deletion/tombstone, reinsertion/count parity,
full replacement, independent parent retention and retired-scope rejection.
A writer killed while holding namespace/scope locks releases both; the previous
complete table survives, destruction then prevents late replacement/insertion.
The prior metadata-publication-protocol-test separately verifies atomic ETS batch
publication under kills before/after publication and Veritas counterexamples.
These bounded gates are evidence, not universal crash/concurrency proof.

* Chosen representation
One constant descriptor selects a generation and count. Definition entries are
separate rows. Full replacement publishes all rows plus descriptor in one ETS
insert. Normal insertion publishes only changed entry/count; deletion publishes
nil tombstone/count and one pending name. The next mutation removes that pending
row in constant work, then re-insertion correctly increases count. Full replacement
cleans nonvisible generations; incremental updates do not scan the table.
Lock order: namespace then short scope; destruction only scope. Scope liveness is
checked inside that short lock. Actual Env must use its existing authoritative
lifetime registry: this prototype's retained true/false rows are test-only.
Full-read tab2list is an intentionally simple semantic oracle, not a production
read algorithm or performance claim. No AOT module-literal descriptor is tested
here yet, and no source-load/navigation gain is claimed.

* Negative attempts and corrections
First failed fixture used an unavailable tuple_size var; qualified native BIF.
Subsequent fixtures passed language vectors to native ETS batch APIs and used
vector destructuring on native row tuples. Corrected to native Enum/list batch
and explicit tuple elements before acceptance. Failed logs retained; owned VMs
reaped. Accepted log: workspace incremental-metadata-probe-native-batch.log.

* Remaining adoption gates
Real Env lifetime and namespace lock helper; lazy AOT literals and detach across
multiple scopes; lock contention and selected-read overhead; concurrent readers,
replacement/destruction barriers and killed writers at each mutation boundary;
bounded orphan-generation cleanup; full Link/AOT/loader/reload suites. Then
metadata scale curves, official seed/SDK rebuild and real browser rerun.
