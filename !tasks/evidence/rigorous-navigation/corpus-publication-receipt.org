#+title: Bounded corpus ownership, publication and projected reads
* Accepted 2026-10-08
Corpus table creation is serialized in an unlinked owner; request departure
cannot destroy the VM-wide cache. Initialization restores its caller scope and
collects its retired callback heap once. Legacy optional9-field rows are
retired before readiness; an existing legacy table keeps its old owner until
owner death, then ordinary misses recreate it under the stable owner.
Hits select only the requested artifact inside ETS. Metadata operations select
key/time/price/stamp/count/dimension, with all artifact fields masked. Build
stamps remain immutable: unrelated writes require no whole-row overwrite.
A short publication fence merges compatible artifacts, prices the actual
winning row, adjusts totals and evicts together. Assembly, IO and native builds
stay outside. Older same-view builders return their result without displacing
newer slots. Empty entries carry256 bytes of metadata charge. Row-only mixed
vector dimensions are charged at their maximum, outside the fence, so the
first/smallest embedding cannot underprice later rows.

* Logic boundary
Z3 actual-winning-row tally and charged-slot count obligations are unsat under
explicit nonnegative premises; stale saved-size counterexample is sat. Veritas
seed23/250 histories refutes/shrinks stale interleaving readA/readB/publishB/

real APIs/backends and concurrent workers are the acceptance evidence.
* Remaining limits
Budget accounts estimated memory, not exact RSS. Existing soft-one-oversized-
column policy remains; the count theorem assumes entries fit the budget and
must allow that single oversize exception. Mixed dimensions conservatively
overcharge rows and add a build-only dimension pass. Publication serialization
has unmeasured contention/tail latency; cache hits do not take that fence.
Attribute marker table stable ownership/global bounds remain separate. Deliberate
external ETS destruction is recovered as optional misses; no guarantee against
concurrent legacy code writing an obsolete layout. No browser speedup or global
native-resource GC is claimed. No app annotations or invalidation calls added.
