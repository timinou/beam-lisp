* Result

Bulk validation is 22.9% faster at p50 than the initial automatic implementation
(1.30x), 20.8% faster at p95. Automatic validation still costs 4.9% more at p50
than this hand-supplied explicit baseline. This is a safety/authoring improvement
with small measured fixture overhead, not a speedup over every manual validator.
It does not establish navigation, startup, disk or final writer-turn latency.

* Method and implementation
One VM, one 1,000-row ETS fixture/basis, one attribute, equivalent uniqueness,
cardinality-one and string checks. Exact old sources are evaluated under fresh
namespaces using the same compiler/runtime. Two warmups per path, twelve measured
triples, all six order permutations repeated twice. Query reuse stays enabled;
this is warm preflight. Preview never advances the database basis.
Raw samples, source hashes, compiler identity and service limits are in
[[file:schema-benchmark.json][schema-benchmark.json]]. Quantiles select sorted floor((n-1)*p).

datom.schema/value-validator resolves attribute/type and captures the existing
transaction type predicate once. Migration reuses that validator for its rows.
The shared Datalog row query remains: a direct attribute scan measured worse on
this warm fixture, losing the query reuse benefit. No second type engine is added.

* Reproduce
From Beam main, put both immutable source baselines under HOME scratch:
#+begin_src sh
git show 2af85666:priv/lib/datom/migrate.bl > "$HOME/tmp/migrate-explicit.bl"
git show 481fb3c9:priv/lib/datom/migrate.bl > "$HOME/tmp/migrate-inferred.bl"
BL_MIGRATE_BASELINE="$HOME/tmp/migrate-explicit.bl" \
BL_MIGRATE_INFERRED_BASELINE="$HOME/tmp/migrate-inferred.bl" \
BL_CONTRACT_BENCH_OUTPUT="$HOME/tmp/schema-benchmark.json" \
TMPDIR="$HOME/tmp" BL_DAEMON=off ./bin/bl run research/reload-contracts/schema_check_bench.bl
#+end_src
Inspect scripts/bl-mem first and use the documented service caps for real runs.
Bounded large-data validation, changed derived tuples and writer economics remain
separate gates; no schema conflict policy or data deletion is guessed.
