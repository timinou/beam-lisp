* Contract
Use qualified literal calls to break execution relationships that would form
cold-loader require cycles:
#+begin_src clojure
(ns app.policy (:require [reload.binding :as binding]))
(defn worker-answer [db id]
  (binding/call! "app.worker/answer" [db id]))
#+end_src
Project discovery and sealed release preparation discover these targets from
source. No app manifest, generation pointer, process coordinator or callback
registration is required. Source identity includes all discovered target code.
Development lazily loads the named function. A managed call invokes only the
caller's exact graph; there is no ambient application fallback.

Declare the call with a namespace qualifier/alias; :refer call!/:refer :all,
borrowed call functions and dynamic target expressions refuse. Targets must be
packaged managed source and actual callable definitions. Ordinary require
cycles still refuse. This does not make arbitrary application macros pure.
