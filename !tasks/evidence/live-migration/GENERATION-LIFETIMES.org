* Validated reusable fixes
** Warm AOT replay and code publication
- Cached initializer replay is owned by the consuming environment and exact
  artifact/module identity. Replaying the same installed unit is a no-op;
  a separate environment initializes independently; changed bytes initialize.
- A partially failed initializer remains failed in that scope. Retrying cannot
  silently repeat already-performed side effects.
- Before third code publication, native module publication uses soft purge and
  refuses when unleased old code is still executing. It never implicitly kills
  the old worker to install the third version.

  fixed SDK framework code/assets as an explicit artifact boundary; admitting
  arbitrary computed product defs is not a safe substitute.

  been demonstrated by these foundation tests. No Hera changes were made.

  workflow-procedure-performer, and knowledge-intents invokes the two performers

- Final source audit also mirrors native reflection/global-resource hazards in

  Rt/invoke. ANF therefore permits that compiler scaffold while checking its
  global/module references. Explicit BeamLisp reflection in source or expanded

  refusal for ordinary sealed callback maps and runtime binding handlers.

* Product graph callback factories and fixed resources (2026-10-12)
This next batch addresses the actual Knowledger graph, rather than treating
its mutable namespaces as a fixed runtime escape. Native foundation validation is recorded below; actual product closure acceptance remains a separate gate.

The initializer proof indexes each emitted sealed defn clause incrementally,
including its namespace shim and immutable implementation module. A named
factory may run only when every matching arity clause has a finite immutable
construction path. Parameters are immutable inputs; returned closures delay
execution and their bodies still undergo the separate graph/native hazard audit.
Recursive factory calls, unknown/native effects, untracked fixed-runtime helper
calls and dynamic application refuse. Analysis has 8192 node visits and 32 depth;
it never invokes a callback to guess whether that callback is pure. This remains
a trusted-code accidental-effect guard, not a hostile-code sandbox.

project-plan's explicit :fixed-runtime true option discovers the fixed SDK
boundary from selected source locations under the executing SDK priv root.
Namespace spelling never grants stability. The release builder must independently
seal/authorize the SDK; this discovery helper does not attest mutable source or
make an arbitrary developer checkout an immutable runtime. Foundry already uses
this same runtime/source boundary after checking its runtime artifact digest.

resource-path resolves a relative path under a selected sealed absolute resource
root, refuses traversal/absolute input and reads no ambient cwd/environment.
Artifact manifest coverage remains the release builder's responsibility.
Anonymous fn reader prefixes preserve their original parameter syntax while
qualified symbols in their bodies receive the same graph rewrite as ordinary fn.

Knowledger's three schema-intent callbacks now use a literal map of pure factory
calls, eliminating a redundant lazy map/into during construction. Its page asset
directories use the selected artifact root, with legacy environment resolution
only outside managed execution. CSS construction and other actual product
owners/effects remain separate gates; this partial batch does not prove that the
complete product graph is sealed or authorize any Hera deployment.
