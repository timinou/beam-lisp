* Goal

Move five proven prototypes from =research/= into the shipped codebase as
first-class tooling. The intelligence already works and is measured; this plan
is therefore ~80% ORGANISATION + TESTING + DOCS, ~20% small glue. Each prototype
becomes a =priv/lib= module with a test suite, a CLI entry, and a doc.

The five, in dependency order (see build order in
docs/one-form/05-the-toolbelt-that-falls-out.bl.org):

1. Trivia-preserving structural rewrite (research/structural-rewrite/) ->
   folds into deodorant. Unblocks the blanket idiom sweep + LSP quick-fix.
2. First-party LSP (research/lsp/) -> priv/lib/lsp/, a CLI + JSON-RPC shim.
3. Model-checking over bl-ANF (research/model-anf/) -> into system.smt/system.core,
   deletes the surface delaborate translator.
4. Inter-procedural native eligibility (research/native-eligible/) -> memory.native,
   wired to the lowerers_spike pipeline.
5. Content-addressed incremental proofs (research/incremental/) -> the cache
   layer under system.analyze that makes the LSP instant.

* Non-goals

- No new proof theory. Every engine (footprint, termination, typed, smt, analyze)

- Not building the Cranelift backend anew — lowerers_spike already lowers +

- No editor plugins. Ship the compiler-side intelligence + a stdio shim; the
  VS Code/Neovim clients are downstream and out of scope here.

* The prototypes and their measured results (evidence)

All under research/, all run today:
- structural-rewrite: (if (not P) A nil)->(when P A) preserving a multi-line
  do-block AND its comment byte-identically; fix-source collapses both.
- lsp: hover/diagnostics/definition/references/document-symbols/completion/
  signature/inlay/highlight/code-actions from :ann+analyze; session.bl renders
  the compiler-as-IDE (native gutter, caret diagnostics, proof panel).
- model-anf: (safe? balance)->(>= balance 0) via pure-helper inlining; invariant
  proven through z3 (unsat), negative control (sat).
- native-eligible: step eligible ONLY because dist2 purity flows through the
  summary closure (whole call tree offloadable); impure/wrong-sort refused by
  named theorem.
- incremental: reindent+comment a fn -> cache HIT; change a constant -> MISS.

* Risks
