   atom-keyword; existing keyword tests still green. Update store-ets.bl to drop its BUG-004 note.

2. rt.ex struct?/associative? predicates + document the map? trichotomy
   Root: code branches on map?, which is false for foreign structs though is_map is true and
   Map/get works — wrong-branch silent bugs (relay upstream-error leaked a struct into a 500).
   Fix: add `struct?/1` (any %_{__struct__}) and `associative?/1` (structs OR bl maps OR vectors)
   to rt.ex + prim table (arity 1 in both the fn map @2174 and arity map @2401). Doc block at
   map?/1 stating the trichotomy: map? ⊊ associative?; struct? for foreign.
   Accept: `(struct?  <foreign-struct>)` => true; `(map? <foreign-struct>)` => false (unchanged);
   `(associative? <foreign-struct>)` => true; `(associative? [1 2])` => true. bl test in core-additions.
