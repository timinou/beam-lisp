** Corrections to the plan above

1. There is NO scripts/spell_live.exs. The driver is the module
   `BeamLisp.Spell.Live`; `scripts/demo.exs` is what runs it.

2. `extract-turn` returns kind-bearing maps, not tuples:
   {:kind :content :content s :tool-calls []} |
   {:kind :tool-calls :content "" :tool-calls [{:id :name :arguments}…]} |
   {:kind :error :reason …}.  `extract-content` keeps its text-only contract.

3. The live loop uses `spell.provider/ask-turn` (synchronous, bounded retries),
   NOT `stream-async`. Streaming exists in the provider and is exercised by
   live_chat.exs, but the tool loop does not assemble SSE deltas. Calling the
   MVP "streaming end to end" would overstate it.

4. Auto-reload polls `report.json`'s VERSION with cache-busting, not the
   bundle's Last-Modified (a rebuild moves mtime even when nothing changed).
   There is no seed.json: `report.json` carries version, transcript, machine
   report, build status and timestamp — it is the repl state, and peek.sh,
   the browser and a human all read the same file.

5. There is NO cassette layer. `scripts/demo.exs` in scripted mode supplies the
   tool-call arguments verbatim and never touches the network; `--live` calls
   the real model. Provider decoding is covered separately by
   test/bl/spell/provider_tools_test.bl (recorded payloads) and
   scripts/live_tool_probe.exs (a real request). Record/replay remains unbuilt.

6. There is NO `inspect_machine` tool. `define` is the only tool offered. The
   machine's report reaches the model in every tool RESULT, and reaches a human
   through report.json and `BeamLisp.Spell.Live.state/0`. A read-only tool
   remains a reasonable later addition.

** What the four rungs actually check

  1 schema   proposal shape; ALSO refuses any key that is not a plain
             lowercase name — the injection boundary (see below)
  2 machine  orphan-binding and unhandled-fire are ERRORS; unrendered-assign
             and dead-template are WARNINGS. Page-locals are DERIVED
             (st/value writes, @each loop vars), never supplied by the caller
  3 compile  spacetime check --deny-warnings; W0201 exempted for exactly three
             named sources (draft/status/send) that verse cannot trace through
             @on/@view; a non-zero exit with no diagnostic is a REFUSAL
  4 selectors styled-but-unrendered AND bound-but-unrendered, joined against
             the compiler's own emit layers, with the left side taken from the
             machine's own declarations

  Rung 5 (DOM verification) is still not in the ladder. It lives in the demo,
  which asserts on `class="clock" … data-key` — an attribute only the renderer
  writes.

** Defects found by building this, all fixed

  - a model's JSON KEY could execute beam-lisp (P0, reproduced: `pwned` = 99)
  - a crashing compiler read as a clean page (rung 3's default was inverted)
  - a blanket W0201 exemption hid an unconsumed $fx stream: streamed tokens
    reached the browser and rendered nothing. seed.bl now has &streaming
  - st/view arms were emitted double-nested; verse refused the model's correct
    proposal twice
  - the merge truncated on an escaped quote in template HTML
  - CSS cascade followed map order, not registration order
  - the published report contradicted the ladder (locals shown as errors)
  - a bind selector must match an element that ALREADY exists; a view binding
