* Goal
A =gen= namespace (priv/lib/gen/) whose =gen.code= generates VALID beam-lisp code via an LLM, constrained by a battery of formal checks built from the existing =codebase= / =system= / =typed= / =oracle= modules. Free-text in, verified+interned code out; spec-map is the internal representation and is exposed for inspection.

* Design decisions (user, 2026-09-18)
- Entry: free-text first; =(gen/spec text)= exposes the derived spec-map (quote-able).
- Acceptance: auto-intern + auto-execute. First run generates → battery → intern → execute; memo cache makes subsequent runs fast and offline-capable.
- Home: priv/lib/gen/ (library tier, like priv/lib/system/; depends on priv/std codebase/typed).
- Reader macro #gen: REJECTED — compile-time LLM calls make builds non-deterministic. A macro that expands to a pre-generated form is the approved ergonomic door.

* Architecture
Loop: spec → context → prompt → LLM → candidate → battery → verdicts; failure feeds repair context (witnesses) into the next attempt. Follows the bl.ask pattern: one descriptor table, every front door (repl fn, macro, MCP tool, CLI) projects it.

Internal hierarchy (priv/lib/gen/):
- code.bl — the door: call · f · defn! · candidate · spec; one descriptor table
- spec.bl — spec shape {:name :args :ret :doc :props :effects}; text → spec-map derivation (LLM), normalization
- context.bl — codebase facts + code.semantic neighbors + :instr facts → prompt sections
- llm.bl — ReqLLM seam (see playbook PB-calling-reqllm-from-beam-lisp--gen-llm-s), model cfg from env (PROVIDER/KIMI_*/DEEPSEEK_*), pluggable ask-fn for tests, cost ledger
- battery.bl — ordered check descriptors; each returns an oracle-shaped verdict {:status :why :cost}
- repair.bl — verdicts → next-prompt text (rendered warnings + witness values)
- memo.bl — content-addressed cache keyed {normalized-spec, model, battery-version}; stores SOURCE; on hit re-runs cheap tiers (parse+typecheck) then interns
- emit.bl — form → source text (pr-str round-trip first, pretty later), file append

Battery, cheap → dear:
1. parse — BeamLisp.Reader/read_string, exactly one top-level form
2. compile — macroexpand/compile in scratch ns
3. types — system.typecheck/check-source + sig conformance vs :args/:ret (typed)
4. codebase — transact-source! into scratch conn → unknown-callees, arity-mismatches
5. dup — code.semantic nearest neighbors within ε → warn/offer existing fn
6. proofs — :props via system.smt/of-source* + oracle/verdict; :sat → oracle/witness → concrete failing inputs → repair prompt
system.decide/tier-for picks how far down a spec warrants.

Public surface (repl):
  (gen/call \"clamp x to [lo hi]\" 5 0 10)  ; generate-or-memo, intern, execute
  (gen/f \"…\")                             ; → the fn itself
  (gen/defn! \"…\")                         ; intern into current ns
  (gen/candidate \"…\")                     ; → {:form :source :verdicts :attempts :cost}, no intern
  (gen/spec \"…\")                          ; → derived spec-map

Risk register:
- auto-execute runs LLM-written code in the VM. Default :effects :pure (footprint rung checked in battery); impure requires explicit opt-in; sandbox (priv/lib/auth/sandbox.bl precedent) as fallback gate.
- generated ns interning: deterministic name from spec-hash to avoid reload hazards.
