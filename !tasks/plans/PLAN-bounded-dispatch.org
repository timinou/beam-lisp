* Implemented SDK mechanism
=proc.dispatch= owns finite preparing/queued/running/settlement slots over an
initializer-owned table. Reserve slot and native code-row budget before retaining
callbacks; unadmitted durable backlog stays with the caller. One event registration
groups run/wait/failure callbacks instead of three whole-graph registrations.

Index the exact inactive target ticket before handoff. Native target insertion
precedes old-row deletion, so producer death at either native fault point leaves
accepted work discoverable. Before handoff it is safely cancelled. Capacity needs
transient duplicate rows; it can refuse before acceptance rather than exceed the
native bound. Accepted effects are independent of the replaceable dispatcher.

Start workers through the retained event's exact context. A newer job cannot
inherit a dispatcher's older graph. The recorded run boundary occurs inside the
retained invocation, after native lease admission. Unknown started worker outcomes
fail; only explicit =:replay-safe? true= opts into at most three retries.

=proc.callback/try-invoke!= distinguishes before-entry retention refusal from
provider exceptions after entry. Before-entry pressure waits on one 250ms drain
timer; failure settlement keeps its indexed slot until durable publication.
No spin, per-job sleeping process or inferred provider replay is introduced.

* Remaining framework owner gate
Native Server currently registers app actors only when their physical module is
in the selected graph. A fixed SDK dispatcher is outside that set. It needs an
explicit application lifecycle/index role and an initializer-owner death monitor,
independent of application code retention.

Authentication must positively attest the actual SDK class/source image and its
definition-owning context. Global/unmanaged class spelling and physical source
location alone are insufficient. A globally loaded application actor claiming
framework status must fail before context change or registry publication.

Existing AOT provenance stamps namespace shims; generated actor classes lack an
equivalent source/code stamp. A generic authoritative SDK code inventory is being
designed; no permissive global binding, fake generation, app wrapper, or whitelist
has been installed to hide that missing evidence.
