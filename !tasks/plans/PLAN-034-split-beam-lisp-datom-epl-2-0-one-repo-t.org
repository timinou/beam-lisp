** Two hex packages from one repo: verified mechanism

=mix hex.build= REJECTS path deps: "Dependencies excluded from the package

Corrected and verified end-to-end:

#+begin_src elixir
defp beam_lisp_req do
  # Path when the sibling checkout is present (monorepo dev); Hex otherwise
  # (published tarball -- the sibling is not there). HEX_RELEASE forces the
  # Hex form so `mix hex.build` sees a publishable requirement.
  if is_nil(System.get_env("HEX_RELEASE")) and File.dir?(Path.expand("..", __DIR__)),
    do: [path: "..", override: true],
    else: "~> 0.1"
end
#+end_src

- =HEX_RELEASE=1 mix hex.build= -> metadata carries
  ={<<"requirement">>,<<"~> 0.1">>}=, ={<<"repository">>,<<"hexpm">>}=
- consumer of the unpacked tarball -> "sub (Hex package)"

** Spell: AGPL-3.0-or-later + EPL linking exception  <-- BLOCKER IF SKIPPED

* Mechanism changes the split REQUIRES

** M1. Package discovery -- the ecosystem-enabling change

Today =BeamLisp.Loader.search_dirs/0=:

#+begin_src elixir
Env.load_paths() ++ [File.cwd!()] ++ extra_dirs() ++ [Application.app_dir(:beam_lisp, "priv")]
#+end_src

The library root is a HARD-CODED SINGLE APP. A =:datom= package's .bl files
are unreachable except via =--path= / =BEAM_LISP_PATH=. Fine for one repo,
fatal for an ecosystem -- and datom is the proof-of-work that the mechanism
functions.

Convention: *a beam-lisp package is an OTP app shipping =priv/bl/**.bl=.*

#+begin_src elixir
defp search_dirs do
  Env.load_paths() ++ [File.cwd!()] ++ extra_dirs() ++ package_dirs()
end

# Every app on the code path shipping priv/bl. Memoized in :persistent_term,
# invalidated when the code path changes. beam_lisp's OWN priv/bl is found by
# the same rule, so core stops being a special case.
defp package_dirs do
  :code.get_path()
  |> Stream.map(&List.to_string/1)
  |> Stream.filter(&String.ends_with?(&1, "/ebin"))
  |> Stream.map(&Path.join(Path.dirname(&1), "priv/bl"))
  |> Enum.filter(&File.dir?/1)
end
#+end_src

Verified in /tmp/cfgprobe: a code-path scan DOES surface every dep's priv/
(returned beam_lisp, phoenix, phoenix_live_view, rustler, crypto, asn1).

Ordering stays =pushed > cwd > extra > packages= -- the property
=loader_path_test.exs= already pins.
