* Why

A user of beam-lisp asks the language whether a machine's invariant holds. The language
answers through *its oracle*. Which SMT solver backs that oracle is an implementation
detail — today z3, tomorrow maybe cvc5 or a native rung — and it currently leaks into
three user-facing surfaces: the CLI verb (`bl z3 stats`), the MCP tool description
(`code/verify … (z3)`), and the result contract (`:tier :z3`). The plan removes the name
from everything a user reads or matches on. The Elixir port driver, `priv/z3/bin`,
`mix bl.z3.fetch`, `priv/lib/z3.bl`, `z3pool.bl` are NOT user surfaces and keep their names
(they *are* z3; renaming them would lie).

Decision (user, 2026-09-14): the word is **oracle**. `bl oracle stats`; MCP tools
`code/verify` + `code/verify-stats`.
