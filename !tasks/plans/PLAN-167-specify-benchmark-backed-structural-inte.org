* Integration contracts and suggested public syntax
The following API sketches are proposals, not existing APIs or approved runtime changes. Existing executable spike APIs are documented in research/structural/*.bl. No prototype declaration flags may become production proof authority.

** Dependency projections
Proposed syntax:
#+begin_src clojure
(def source-plan
  (projection/columns
    {:names  [:library :source/name]
     :scores [:library :source/score]}))

(projection/read source-plan
  {:library library-db :control control-db :sync sync-db}
  {:principal principal})
#+end_src
The closed plan is executable and its read dependencies come from the same representation. One facility owns cache lookup, validation and storage using attr-basis/derived; callers do not supply :complete? or manually attest dependencies. Initial scope is closed column/query plans, not arbitrary functions. Include empty reads, exact plan/store/input identity, pinned snapshots, provider/schema/definition generations and permission expiry. Extend the canonical query IR rather than introducing a competing analyzer. Certified live skipping needs sticky batch relevance and scheduled expiry; unknown dependencies still render.

** Bounded and authorized reads
Proposed syntax:
#+begin_src clojure
(query/page search-plan world
  {:allow  allowed-plan
   :limit  20
   :cursor cursor
   :budget {:rows 500 :bytes 1048576 :seeks 1000}})
#+end_src
Budget numbers are illustrative. The current spike bounds posting rows, not total bytes/seeks/native work. These options may only be accepted once the corresponding substrate/provider capabilities enforce them.

The DB layer owns semantic visibility and data/order/basis cursor provenance; the query engine owns admission; a policy provider supplies an allowed relation/descriptor and principal/permission context. Consume that relation during ranking. Datom must not embed Knowledger ACL rules or require a socket: retrieval and background callers need the same contract. Live is an authenticated consumer, not the sole policy owner.

Return :exact, :incomplete or :refused. Never present partial rankings as exact, fabricate totals, or expose denied-candidate counters. Maintain the rank projection atomically/version it and reject stale generations. General multi-term ranking requires a checked threshold merge or budget refusal. Bind store, basis, query/order version, principal, permissions and expiry to opaque cursors. Account for assertion/retraction pairing and all extra visibility reads. Never advance past unexamined candidates or lose accumulated results on retry.

** Central compiler fusion
User syntax remains ordinary:
#+begin_src clojure
(first (filter (fn [x] (> x 3)) (lists/seq 0 1000)))
#+end_src
Add strict-first-filter beside strict-map-fold. Internally derive domain, predicate totality/effects, private ownership and materialization facts; respect analysis/output budgets. Do not freeze live globals. Callee authority must come from lexical proof or a before-work guard on once-evaluated callee values, preserving original callee/argument evaluation order. A failed guard must neither repeat effects nor reread a different binding as the fallback.

Pure strict boolean BIFs still require operand type proof. optimize/explain remains the diagnostic API, not a way to supply author facts. Verify enabled/disabled equivalence for values, raised-ness, callback/forcing prefixes, shadowing/rebinding, shared values, resources/cycle edges, and compile/output budgets. Then measure real admission coverage and application performance.
