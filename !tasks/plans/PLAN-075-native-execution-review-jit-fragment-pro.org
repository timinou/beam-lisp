* P0 — JIT fragment probe (this prototype)

Standalone Rust (research/j1_probe), no bl plumbing. Defines the bl-ANF node vocabulary as a Rust enum and lowers through cranelift, so when bl-ANF (PLAN-074) lands the lowering plugs in.

Kernels, chosen from the named beneficiaries:
- checksum over 64 MiB (doc 05's own dirty-cpu example): acc = acc*31 + byte
- const-alpha blend over two 16 MiB buffers (loom-shell glyph composite): d[i] = (s*a + d*(255-a))/255

Measured: (a) compile ms (median of 31 fresh module builds) = the REPL-pace claim; (b) exec JIT vs handwritten Rust (median of 21) = codegen-quality claim.

Acceptance gates: compile <= ~50 ms median per kernel; exec <= 1.5x hand Rust. Pass => JIT backend is viable for the doc-05 fragment (vs gen.rs+cargo AOT). Fail => cargo AOT at def-time wins for static defns; JIT only earns its complexity for query-shaped programs.
