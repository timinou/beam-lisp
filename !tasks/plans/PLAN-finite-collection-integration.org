in one interpreter, retaining the old three-argument helper's literal budgets
and explicit refusal kind. Actual ANF, exact SDK routes, trusted first-order raw

callees/captures, recursion, latent values and escaping closures/recipes refuse.

and no caller/global cache of purported proof. Generations cannot supply evidence.

exemption: forcing constructors require bounded first-order arguments. Ordinary
inert callback maps and delayed executable values keep existing code ownership.
