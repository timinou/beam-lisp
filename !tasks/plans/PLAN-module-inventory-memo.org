unstable/in-flight evidence refuses. No cache survives the preparation. Owned

owned-module inventory and loaded-code checks remain exact. Actor-only tables
still create no phantom namespace bridge and missing real modules still refuse.

registration specializer before native-call specialization/evaluation. That
feature's capture/contract/transaction validation belongs to the executable
catalogue work; this hook does not itself execute registration callbacks.
