* Change
Each preparation now memoizes only stable SDK inventories. Reads carry exact
Env.namespace_generations certificates before/after discovery and before/after
cache reuse. Lazy loading or publication invalidates old evidence; repeatedly
unstable/in-flight evidence refuses. No cache survives the preparation. Owned
namespaces remain freshly inventoried as definitions are emitted; final whole
owned-module inventory and loaded-code checks remain exact. Actor-only tables
still create no phantom namespace bridge and missing real modules still refuse.
The graph exposes bounded :preparation-metrics {:hits :scans} for measurement.

The same compiler integration now hands actual ANF to the SDK declaration
registration specializer before native-call specialization/evaluation. That
feature's capture/contract/transaction validation belongs to the executable
catalogue work; this hook does not itself execute registration callbacks.
