* What this is

The MVP of the self-evolving chat interface, reframed. The unit is not "a chat
app" but a CONTRACT: one beam-lisp term that emits both halves of a
frontend/backend seam — BEAM code for the server, Spacetime EDN for the client —
so the two cannot disagree by construction.

RREVL (read · reason · emit · validate · load) operates on that term.

* Settled design decisions

** `@` = crossing the seam

`@count` is ONE name resolved per target: BEAM `socket.assigns.count`,
Spacetime `$count` (`CapturedValue::Binding`). How it resolves is the framework
builder's concern, never the end user's.

Mechanism (verified): `(reader-macro! "@" (quote deref))` in `priv/core.bl` is a
one-line ETS insert, explicitly rebindable — `reader.ex` documents the `@ → deref`
mapping as living in the table, not the reader. A `defcontract` binds `deref` to
the seam resolver.

Note the alignment: SPEC §7 banished `@` from the EDN surface precisely because
`@count` derefs naturally on the BEAM. That decision pays off here — `@` means
deref in both languages, so there is no translation to remember.

*Page-locals are bindings NOT declared in `defcontract`.* Not a special rule —
the definition. Shared → `@`. Unshared → plain local.

** Two channels, not one (do not collapse)

A handler has a correlated one-shot reply AND a broadcast assign diff:
- `{:reply, %{tag: "ok", reply: v}, socket}` — decoded by the page's `receive to
  IncResult` arms, correlated to one fire
- assign diff via `st-set` — reaches every subscriber

Different routes, timing, audiences. Merging them repeats *BUG-091* (collapsing
`:` and `<-` silently rerouted a binding between `style.setProperty` and
`setAttribute`).

∴ assignment is implicit and reads naturally; reply is EXPLICIT via `(ok …)` /
`(err …)`. A handler with no `(ok …)` declares itself fire-and-forget — checkable,
so a page correlating on a reply that never comes is a compile error.

** Implicit assign (user decision, revisitable)

`(set! @count (inc @count))` implies the diff. Emitter MUST batch per handler so
one handler = one `st-set` push; without that guarantee the hiding is dishonest.
Easy to change to explicit `(assign! …)` later.

** Invoking a `%form`: `st/` namespace, no sigil

The wire already says "call this macro": `(drag :group "…")` IS a `%form`
invocation (`:st/form ↔ FormMatch.macro_name`, 415 registered forms, zero
hand-written mapping table).

Rejected `%drag{…}`: `%` is beam-lisp's anonymous-fn param inside `#(+ % 1)`
(`fn_arg_index`), so reusing it invites confusion for a marker that buys nothing.
`st/drag` is a namespace — unregistered names error at emit against the registry.

** Markup: JSX-style braces (user decision)

`<article data-id={@c.id}>` — NOT Spacetime's backtick form. Backtick is
beam-lisp's `syntax-quote` (reader.ex:216), so `` `$c.id` `` inside a `defview`
would read as a quoted form. A different sigil between the two languages is
acceptable when it buys an easier reader.

Holes land in `:st/html` as `[:st/hole N]` after BUG-369 (799c3689), so optics
reaches any node. No hiccup layer, no second markup language.

** Three planes, bound by selector

`StFile` has three (`html_blocks`, `scopes`, `matches`), attached by SELECTOR —
which is why `.card` legitimately appears in more than one. An earlier
"one element, one place" proposal would have destroyed the many-to-many.

`markup` nests (DOM is a tree); `style` and `binds` are flat selector lists
(attachment is many-to-many). `binds` is Spacetime's own word (`%binds`) and
spells identically in UK/US English.

`(inject @x)` keeps `<-` distinct from `:` (BUG-091).

* Why it validates for free

`defview` emits an `EdnDocument`, which enters at `to_st_file` — the SAME parse
step `.st` uses (W5's correction: EDN reaches the compiler as `FormMatch`, never
as text). So E0928, the corpus round-trip gate, and every `%form` validator apply
unchanged.

*The generated half cannot be less checked than the hand-written half.* That is
why `defview` can be deferred without risk: `defcontract` ships first, emitting
against a hand-written `.st`, and `defview` later replaces the authoring surface
without touching the pipeline.
