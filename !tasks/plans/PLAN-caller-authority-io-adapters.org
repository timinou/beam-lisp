Knowledger's actual model-cell harness on source28584f17/SDKb6bd22d2 inherits
core/slurp and core/spit after an unrelated parent dependency loads clojure.io.
An empty compile-time capability set does not revoke the native authority of

* Implementation
env/require-cap! admits an effect against the caller's current module/operation
grant. Unknown module or operation names fail closed without creating atoms.
clojure.io checks File/read before reading and File/write before writing; line
helpers share the checked reader. Ordinary unrestricted scripts retain behavior.
Borrowed adapters and installed core aliases use the same check automatically.
No app-specific filesystem denylist or application code change is necessary.

The native compiler remains a compile-time gate. This does not attempt to change
every compiled application function's authority semantics. Approved trusted host
functions and the larger closed evaluator remain separate, explicit designs.
