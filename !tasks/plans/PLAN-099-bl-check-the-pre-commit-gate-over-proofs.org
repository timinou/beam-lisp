* What this is, from zero

beam-lisp is a Lisp on the Erlang VM whose compiler PROVES things about your
code: whether a function is pure (touches no state), whether it terminates,
what type it returns, whether an SMT solver (z3) can reason about it, and
whether it is eligible to be compiled to native machine code. It also has a
linter called =deodorant= that finds "smells" (non-idiomatic code) and can
rewrite them without disturbing formatting.

All of that intelligence exists today as library functions. What does NOT
exist is ONE command a developer runs before committing that says "this change
is safe" or "this change regressed something". That command is =bl check=.

The goal of this plan: a developer types =bl check= (or git runs it as a
pre-commit hook) and in under ~30 seconds for a typical change gets:

- every proof diagnostic (type errors the inter-procedural checker finds),
- every deodorant smell,
- a metrics line: how many functions are pure / terminating / SMT-translatable
  / native-eligible, compared against a committed baseline,
- exit 0 if nothing regressed, exit 1 if something did, with the reason.

"Regressed" means: a NEW diagnostic or smell appeared, OR a metric got worse
(fewer pure/terminating/translatable/eligible functions than the baseline, or
more failures). Improvements are allowed and update the baseline when asked.

* Vocabulary (read this once)

- =.bl= file: a beam-lisp source file. Namespaces mirror paths:
  =priv/lib/system/analyze.bl= is namespace =system.analyze=.
- =priv/std/bl/cli.bl=: the =bl= command-line tool. Every subcommand is a
  function =cmd-NAME [args st]= returning an exit code (0 ok, 1 failure, 2
  usage), registered in the =commands= map near the bottom of the file. The
  existing =cmd-lsp= (around line 393) is the template to copy: it resolves a
  path, reads the file, loads a library namespace with
  =(BeamLisp.Loader/ensure_loaded "NS")=, fetches a function with
  =(BeamLisp.Env/fetch! "NS" "fn-name")=, calls it, maps to an exit code.
- =priv/lib/lsp.bl= (namespace =lsp=): the analysis functions. The ones this
  plan uses:
  - =(lsp/diagnostics src ns)= → list of ={:msg :line :col :end-col …}=
  - =(lsp/document-symbols src)= → list of ={:name :returns :terminates :pure :calls}=
  - =(lsp/native-eligible src fn-name)= → ={:eligible bool :reason …}=
- =priv/std/deodorant.bl= (namespace =deodorant=):
  - =(deodorant/report-source src)= → the smells in a source string
  - =(deodorant/all-rules)= default rule set (safe + idiomatic tiers)
  - =(deodorant/fix-file-preserving! path)= rewrites a file in place, keeping
    formatting (this is the "trivia-preserving" rewriter; it was hardened in
    a prior sweep and its invariants are listed in FUP-027).
- =priv/lib/system/smt.bl= (namespace =system.smt=): =(smt/translatable? src)=
  says whether a predicate can be handed to z3.
- =priv/lib/system/incr.bl= (namespace =system.incr=): content-addressed
  incremental analysis. =(incr/analyze-incremental cache src)= re-analyzes only
  functions whose body hash changed and their dependents; =(incr/dirty-set
  summaries misses)= names them. It currently has NO consumers — this plan is
  its first.
- =priv/lib/lsp/cli.bl= (namespace =lsp.cli=): =(report src ns)= renders
  diagnostics + a proof summary per definition to the terminal and returns the
  diagnostic count. =bl check= reuses its rendering style.
- Tests are =.bl= files under =test/bl/= using =deftest= / =testing= / =is=.
  Run one with =mix beam_lisp.test test/bl/system/FILE_test.bl=.
- z3 lives at =priv/z3/bin/z3= in the main tree
  (=/home/user/code/undefine/beam-lisp/priv/z3/bin/z3=); set
  =BEAM_LISP_Z3= to that path when a run needs it.
- =!tasks/= is the org tracker. =docs/tools/NN-*.bl.org= are runnable
  walkthroughs ("livebooks"): code cells with =#+RESULTS= that must replay
  identically (run the doc, =git diff --stat= must be empty).

* The deliverable, precisely

** 1. =bl check [PATH…] [flags]= subcommand

Add =cmd-check= to =priv/std/bl/cli.bl=, register ="check" cmd-check= in the
=commands= map, and add a usage line to the =command-help= map. Default PATH is
the current directory. Directories are walked for =**/*.bl= excluding
=_build/=, =deps/=, =research/=, =test/fixtures/=.

Flags:
- =--baseline FILE= (default =.bl-check.edn= at the repo root)
- =--update= write the new metrics as the baseline (only allowed when exit
  would be 0, or with =--force=)
- =--changed= only check files that =git diff --name-only HEAD= (plus
  untracked =.bl= files) reports, then use =system.incr= to also re-check
  their dependents. Everything else reads from the incr cache.
- =--fix= apply deodorant's safe-tier rewrites in place (per-file OS
  isolation; see §4) and re-check.
- =--json= emit the report as one JSON object on stdout (for CI); the human
  render otherwise.
- =--no-smt= skip the z3-backed metric (fast mode; the metric shows =skipped=)

Per file, the command computes:
- =diagnostics= via =(lsp/diagnostics src ns)=; ns from the leading =(ns …)=
  form (copy =lsp-ns-of= in cli.bl)
- =smells= via =(deodorant/report-source src)= with =(deodorant/all-rules)=
- for each top-level fn from =(lsp/document-symbols src)=: pure?, terminates?,
  native-eligible? (via =lsp/native-eligible=); and =translatable?= of its
  guards when =--no-smt= is not set
- if a file cannot be READ (the reader raises a =SyntaxError= that is NOT
  catchable with =try= — see §4), the file is reported as =:unreadable= and
  counts as a failure

Aggregate =metrics= map (all integers):
={:files N :fns N :pure N :terminates N :eligible N :translatable N
 :diagnostics N :smells N :unreadable N :wall-ms N}=

** 2. Baseline + regression rule

=.bl-check.edn= is a committed file holding the last accepted =metrics= plus a
per-file map of ={"path" {:diagnostics N :smells N}}= so a regression can be
named by file.

Regression (exit 1) iff ANY of:
- =diagnostics=, =smells=, or =unreadable= increased (globally or per file)
- =pure=, =terminates=, =eligible=, or =translatable= DEcreased
- =wall-ms= > 1.5 × baseline AND > 10 s (a slowdown guard; do not fail on
  noise for tiny runs)

Output on regression names each cause on its own line, e.g.
=✗ smells 3 → 5 (priv/lib/foo.bl +2)= and =✗ eligible 41 → 40 (lost: system.foo/bar)=.
To name the lost function, the baseline also stores the SET of eligible fn
names (=:eligible-fns=) and pure fn names (=:pure-fns=), so the diff is exact.

No baseline file yet → print the metrics, write nothing, exit 0, and say
=no baseline: run bl check --update to create .bl-check.edn=.

** 3. Speed: =--changed= via =system.incr=

Without =--changed=, every file is analyzed. With it:
1. changed = git-modified + untracked =.bl= files under PATH
2. analyze the changed files with =(incr/analyze-incremental cache src)= where
   =cache= is loaded from =_build/bl-check-cache.edn= (create if absent) and
   written back after the run
3. dependents = =(incr/dependents (incr/reverse-graph call-graph) changed-fns)=;
   analyze their files too
4. all other metrics come from the cache

Acceptance for this section is a TEST that proves the incremental result
equals the full result: analyze a small program, mutate one function's body,
run both paths, assert equal =metrics=.

** 4. =--fix= safety

The trivia-preserving rewriter has one known hazard: the reader raises an
uncatchable =SyntaxError= on malformed source, and a rewrite of a file that
DEFINES a primitive the rewriter itself uses can corrupt that file mid-run
(these are the two lessons that motivated FUP-027). Therefore =--fix=:
- runs each file's fix in a SEPARATE OS process:
  =mix beam_lisp.run --path priv /tmp/fix-one.bl= with the path as an
  environment variable (the run task does NOT forward extra argv to the
  program; use =System/get_env=). A crash isolates to that file, reported as
  =:fix-failed=.
- skips the rewriter's own files: =priv/std/span-rewrite.bl=,
  =priv/std/deodorant.bl=, =priv/std/rewrite.bl=, =priv/boot/**= (the
  self-reference guard).
- after fixing, re-reads and re-checks the file; if the smell count did not
  drop, reports =:no-convergence= (do not loop).

** 5. Git pre-commit hook

Add =scripts/pre-commit= (bash, executable):
#+begin_src bash
#!/usr/bin/env bash
# beam-lisp pre-commit: proofs + smells must not regress.
set -e
exec bl check --changed
#+end_src
and a =bl check --install-hook= flag that symlinks it into
=.git/hooks/pre-commit= (refuse to overwrite a non-symlink hook; print what to
do instead). Document in the walkthrough.

** 6. Tests (all under =test/bl/system/=)

- =check_metrics_test.bl= — over an inline 5-fn program (copy the =prog=
  pattern from =lsp_cli_test.bl=): metrics counts are exact; one impure fn is
  counted out of =pure= and =eligible=; a program with a type error yields
  =diagnostics 1=.
- =check_regression_test.bl= — given a baseline map and a metrics map, the
  regression rule returns the exact list of causes; improvements return =[]=;
  the slowdown guard ignores small runs.
- =check_incremental_test.bl= — full == incremental after a one-fn edit (§3).
- =check_cli_test.bl= — call the =cmd-check= function directly (like
  =lsp_cli_test= calls =report=) on a temp dir with two files: exit 0 with no
  baseline, then =--update= creates the file, then injecting a smell into one
  file returns exit 1 and the cause names that file.
- =check_fix_isolation_test.bl= — a directory containing one malformed =.bl=
  file and one fixable file: =--fix= fixes the good file, reports the bad one
  as =:fix-failed=, and the process running the test survives.

Put the pure logic (walk, metrics, regression rule, baseline read/write) in a
new library namespace =priv/lib/check.bl= (ns =check=) so tests call it
without the CLI; =cmd-check= is a thin adapter over it, exactly as =cmd-lsp=
is over =lsp.cli/report=.

* Gotchas already known

- The reader's =SyntaxError= cannot be caught with =try= in beam-lisp — hence
  OS isolation for =--fix= and an =:unreadable= verdict rather than a crash.
- Hyphenated namespaces need hyphenated filenames (=span-rewrite.bl=); the
  loader maps =.= → =/= only.
- =mix beam_lisp.run FILE extra= does NOT pass =extra= to the program.
- The =bl= binary routes commands through a warm daemon; =cmd-check= must not
  call =halt= — return the exit code (every =cmd-*= does).
- =priv/std/bl/cli.bl= is AOT-compiled; after editing it, =mix compile= is
  needed before =bl= sees the change (the mix tasks recompile automatically).
