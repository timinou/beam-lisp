* Batch 1: actual Source proof and generation integration
proc.input-domain reads the ACTUAL checked actor descriptor, system.ir/call-site,
and actual system.publication helper snapshots. It never compiles source to guess
behavior, runs a handler, trusts an author annotation, or uses name-only SMT
translation. Exact primitive MFAs carry fixed argument-shape requirements;
String.trim requires valid UTF-8, not any binary. Num arithmetic certificates
cover argument shapes, not overflow, arithmetic refinements, successful provider
outcomes, termination, authorization, business equivalence or state/reply laws.
Unknown calls, recursive/guarded helpers, branch-sensitive computation, latent
functions, opaque literals and unsupported protocols decline automatic proof.

Generation captures canonical descriptors at the existing defserver compiler
review, then builds body certificates after every helper is published. It stores
them privately as :actor-inputs. Known requirements and actual guard coverage are
separate: uncovered wildcard actors are NOT silently narrowed. Unknown/uncovered
and old-compiler actors retain their ordinary behavior and retained-drain status.
One namespace/module context is built per preparation, not per actor clause.
Unknown native operations decline without scanning every application namespace.

Certificates bind class MD5, complete helper shim/body identities, actual global
providers and negative lookup namespaces. Private native scope epochs cover
intern/rebind, definition changes, bulk publication and in-flight writes. They
are opaque VM observations, never journal/JSON authority. Pure IR retention is
separately bounded:16,384 analyzed nodes,32helpers; each retained proof/class
metadata view is capped at65,536raw nodes,128depth,1MiB. Native tuple descriptors
are validated by CompilerData with an EMPTY constructor witness, so no Fn,
private lazy capsule or opaque resource is admitted. Public first-order business
data remains unchanged; literal operands still use that stricter boundary. No local
letfn/Atom table is used. Runtime validation checks epochs and exact code IDs;
it does not rebuild function objects or walk retained IR on every message.

proc.contract/adoption-check is a necessary shape-preservation decision. Its
four-arity form retains both actual graphs and checks each private scope. The
exact-unchanged route compares complete actor/transitive evidence. Changed
bodies require equal alpha-normalized actual heads/guards and proved coverage of
all candidate requirements. Unknown refuses. This function DOES NOT install a
head, migrate state, adopt resources, update mailbox messages or release old G.
