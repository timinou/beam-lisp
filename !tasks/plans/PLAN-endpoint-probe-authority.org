#+title: Preserve endpoints when liveness is uncertain
#+state: ACCEPTED SOURCE — packaged integration remains a separate gate

* Defect
vm.net/answering? returns false for all connect errors. Both listener admission
and inventory pruning used false as authority to delete endpoint files. A
permission error, timeout, process descriptor exhaustion or invalid path cannot
prove a listener dead.

* Implementation
vm.net/probe returns :live, :dead, or {:unknown reason}. Only enoent and
econnrefused authorize dead-endpoint reclamation. Exceptions are unknown.
answering? retains its boolean observation API for compatibility, but destructive
callers use probe directly. listen returns endpoint-probe-unknown without
rewriting the socket, token or metadata. Inventory retains uncertain groups.
No application developer configuration or API change is required.

* Validation
Real AF_UNIX ENOTDIR via a socket symlink through a regular file exercises the
unknown branch without mocks. Tests check missing endpoints, exceptions,
admission preservation and dry-run/real inventory preservation. Existing live,
refused, concurrent-start, stale-socket, owner-death and retirement tests remain
required. Test inventory scratch now lives under the user's home directory.
Python independent kernel check confirmed ENOTDIR for both direct and symlink
paths, and ENOENT for absence. This is fixture evidence, not Beam acceptance.

* Remaining boundary
The age-recovered start-file lock still does not prove serialization under an
unbounded live-holder pause. OS-owned advisory lease integration and pruning's
probe-to-unlink race require the separate endpoint admission plan. This patch
removes one unsafe authorization rule; it does not establish global exclusivity.

* Acceptance queue
Run source/packaged focused gates after the current immutable producer build
releases the shared runtime lock. Do not merge this branch or adopt its SDK
before passing those tests. Retain failing output and correct fixtures/production
as needed; no skip or success-by-exit-status-only acceptance.
