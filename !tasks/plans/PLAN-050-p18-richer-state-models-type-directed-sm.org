of hardcoding Int). Design doc: docs/typing/richer-state-models.typ (7pp).

** p18-records — Rung 2: record / mixed-sort state  [blocked: p18-multivar]
State is a product of typed fields {:balance int :frozen bool}. Route: PROJECTION
— each field its own z3 var of its own SORT (Int, Bool), pulled from the tag
lattice (typed/walk / sigs-from-env infer the field types). smt.bl stops assuming
Int: a declare-sort helper maps :int->Int, :bool->Bool. Invariant like
(or (not frozen) (= balance 0)). A field access (:balance state) reads as that
field's projection var.
Accept: mode machine — frozen ⇒ balance=0 proven; a pay-out-while-frozen caught.
Demo: examples/system/11_record_state.bl. Test added.

** p18-collections — Rung 3: collection state (bounded)  [blocked: p18-records]
z3 theory of arrays/sequences/sets for queue/set/map state. Crosses the
decidability line: some invariants become BOUNDED not exact. Register results in
the guarantee-catalog as :approximate with :bound (machinery already ships:
register-guarantee! / approximate-guarantees / exact-guarantees). Translator maps
(conj q x) -> seq append, (count q) -> seq length, (contains? s x) -> set member.
Accept: bounded work queue — "pending never exceeds capacity" as a bounded
guarantee, honestly catalogued.
Demo: examples/system/12_collection_state.bl. Test added.

** p18-sumtypes — Rung 4: sum-typed protocol state  [blocked: p18-records]
State is a tagged variant :idle | (:running job) | :closed. z3 algebraic datatype
with a discriminant; translator reads the variant tag. Invariants about LEGAL
transitions (can't :send from :closed). Recruits all four engines; connects to
existing simulates? / migration-preserves? (session types / protocol conformance).
Accept: connection FSM — illegal :send-while-:closed caught.
Demo: examples/system/13_protocol_state.bl. Test added.

** p18-discover — invariant discovery (no annotation)  [blocked: p18-multivar]
