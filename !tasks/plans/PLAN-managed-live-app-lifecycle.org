#+DATE: 2026-10-14
#+STATE: SOURCE CHECKPOINT — coherent ordinary SDK/native and sandbox product acceptance pending

* Installed scope
- reload.generation/with-selected! factors exact existing call! admission,
  executing a trusted SDK action under one atomically selected whole graph lease.
  An ordinary app factory and its HTTP/WS router cannot observe different graph
  versions halfway through a concurrent publication. Exceptions release leases.
- live.lifecycle adapts ordinary zero-argument live.app factory + domain
  initializer into a managed lifecycle without an app deployment coordinator.
  Borrowed control options refer to existing native handles, request map values
  remain inside the selected lease, and routing uses unchanged live.app/router.
- datom.conn/owned-connections observes the existing fenced native registry only.
  Authority is the exact executing graph application-id, immutable native store
  creator proof, and explicit borrowed handles/lifetimes. Paths constrain that
  authority; filesystem paths never grant it. No second writer/reopening or guard
  adoption. Closed unrelated old entries are not live inventory obligations.
- Producer ownership uses actual native retained-owner evidence and OTP creator
  parentage. Graceful stop prevalidates all captured direct source server records,
  waits on at most one live child per bounded turn, never kills an accepted pass.
  Source supervisors require an explicit safe drain contract and currently refuse.

* Native acceptance gates
Root runs test/bl/reload/generation_selected_test.bl and
 test/bl/live/lifecycle_test.bl on the coherent newly installed native floor.
Selected action tests concurrent publication while blocked, new request routing,
old graph retirement waiting, and exception release. Real tick actor test has a
nonzero1ms interval and blocked accepted pass; timeout must preserve its PID/code,
finish occurs once, no overlapping/new pass follows, and graph retirement resumes.
Borrowed native Fjall handle/router tests cover actual writer observation, exact
control use, missing scope/handle and foreign application identity. More live
product owners/queues may expose additional refusal gates; do not exempt them.

* Explicit limits
No packaged/browser acceptance has run for these sources. SDK runtime/OS handover,
automatic WebSocket state/message adoption, external provider idempotency, durable
cross-VM background constructor recovery and source supervisor drain are separate
obligations. Foundry and Knowledger source-pending adapters/harnesses are tracked in
 their PLAN-live-app-managed-product.org / PLAN-managed-product-rehearsal.org.
Native application IDs are hashed instance identities, not human project names.

* 2026-10-15 source audit and bounded failure controls
The ordinary factory/router, borrowed control-store and nonzero recurring
producer adapter are checkpointed upstream. The fixture now also rejects a
forged owner ticket before sending any stop, and checks that a constructor which
starts a real blocked child then throws returns =:uncertain= with the exact native
child receipt. Graceful stop cannot convert a timeout to cancellation or a
replayable provider result; graph retirement remains waiting until actual exit.

These new controls have static delimiter/try-shape acceptance only. Earlier
validation40 refused undeclared fixed SDK dependencies before executing the
fixture; its subsequent project-plan/fixed-runtime correction is incorporated.
Run selected-generation and live lifecycle files together on the ordinary SDK
floor before using this adapter as packaged product evidence.

** Still a mandatory failed-initializer gate
The direct actor inventory is not an initializer-attempt ledger. Native Conn
creator graph evidence cannot distinguish a failed initializer's newly created
connections or observers from pre-existing same-app resources. A thrown ordinary
initializer may therefore have accepted effects even when the adapter cannot
return a complete child receipt. Do not close borrowed/shared writers, replay
that initializer, or claim no effects from an absent row. The existing HOME
initializer-attempt/quarantine prototype requires coherent Env/Server/Conn
observer capture before it can replace this limitation. It is not integrated.

Source supervisors without a proved graceful drain contract still refuse. Raw
user spawns, SDK/native runtime handover, cross-VM unknown provider outcomes and
automatic old WebSocket adoption remain separate explicit obligations.
