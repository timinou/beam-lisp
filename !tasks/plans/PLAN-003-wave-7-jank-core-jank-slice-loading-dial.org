The thesis proof: beam-lisp claims "jank's language, BEAM's runtime". jank ships its stdlib as core.jank (~260KB Clojure-in-jank, vendored at vendor/jank/… or fetchable from jank-lang.org repo). Loading slices of it unmodified converts "is it faithful?" from opinion to test suite.

Approach: incremental slice loading. Start with leaf sections of jank's core.jank that only need what beam-lisp already has (fn, let, if, loop/recur, defmacro, seq fns). For each slice: attempt load → collect failing forms → each failure is a concrete gap (missing special form, missing prim, semantic difference) → either fix the gap or defer with a reason. Track in this item: a checklist of jank core sections × {loads, skipped: reason}.

Known gaps going in: lazy sequences (core.jank's map/filter are lazy — see wave-10), transducers, ratios, char literals, metadata, protocols. Do NOT try to load the whole file at once; slice by defn groups.

Acceptance: a jank_compat_test.exs that loads the accepted slices and runs jank's own docstring examples where portable; the gap list in this item is exhaustive for the attempted slices.

- Wave 15 (13→21): loop*/let*/fn*, &form/&env, form metadata (BeamLisp.FormMeta — forms are compiler-controlled, so unlike runtime values they CAN carry metadata), clojure.core alias, assert-macro-args. Unlocked ->, ->>, if-let, when-let, dotimes, doseq, doto, memoize. Surfaced three runtime bugs, each fixed at the root: (1) ~@ spliced with ++ so splicing a VECTOR crashed — Clojure splices any seqable, now RT.splice; (2) a vector is a struct hence a map, so RT.get matched the map clause and index access silently returned the default; (3) vectors were not callable as functions of their index. Fixing these let a self-hosted `get` shim in core.bl and a defensive re-assert in the wave-15 test both be DELETED.

ALSO FOUND: examples/multimethods.bl and protocols.bl both defined `area` in ns `user`, so whichever loaded last won — an order-dependent failure that looked like flakiness and was really the examples misusing the namespace system. Each now has its own ns.
