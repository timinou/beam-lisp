* Wave A — independent compiler and diagnostics work
** FEAT-055: numeric choice at ANF→JS emission
Construct canonical ANF regardless of proof verdict. Propagate numeric category and trusted type/range facts in ANF `:ann` using existing typed/system/codebase evidence rather than caller-controlled maps. At each `research/js-actors/compiler.bl::emit-arith`, permit raw JS Number only with a proof witness for every operand and intermediate result plus discharged input obligations. `:unknown` retains checked `H.arith`; `:no` chooses an exact backend only after FUP-124 validates it, otherwise emits a diagnostic. Untrusted messages/foreign values need an establishing runtime guard or cannot authorize the fast path. Post-compiled fuzzing is a backstop, not the authorization; ANF construction is NEVER blocked by this proof. Keep integer/float/decimal identity, hashing, division and arbitrary precision separate from safe-integer range proof.
Proof: extend `research/js-actors/number_rule_test.bl` and `research/js-actors/test.bl` (or dedicated emitter test) for malicious bounds, intermediate overflow, joins/loops, unknown calls, foreign input and ±(2^53−1); inspect emitted fast/checked/refused paths and compare generated outputs/errors to native BEAM with a lossless tagged codec. Preserve the existing tests and runtime guards until trusted proof is demonstrated.
** FEAT-048: logical BL source frames
Preserve reader spans at `compiler.bl::defn->fn-form`/`::compile-source`; carry source/module/function/arity and call-site data through ANF `:ann`, `::step-call`/`::emit-fn`. `host.mjs::runTurn` stores minimal immutable typed frame metadata alongside managed generator frames and captures a bounded logical stack at first raise. BL exception policy in `runtime.bl` keeps the original trace on rethrow and supersedes it if a finalizer raises. Document tail-call elision/marker and cap memory; unknown positions stay unknown. Follow `errors.bl::render` location conventions for human output, but a runtime trace is a distinct value, NOT new undeclared fields in closed `diag.bl`. A target BL trace formatter may use the diagnostic location contract; do not require wholesale compilation of `errors.bl` before module linking supports it.
Proof: f→g, higher-order call, receive parking/timed wake, typed catch/rethrow, finalizer replacement, 50k tail iterations with bounded memory, visible browser BL source location; `research/js-actors/test.bl` and `verify.mjs`, plus selected native BEAM logical call comparisons. Never present JS Error.stack as BEAM frames.

* Wave B — FEAT-049 atomic lifecycle (critical path)
Define typed pid/ref identity including runtime incarnation/generation; replace the plain integer public identity without making host JS a registry. Centralize one BL death transition across `runtime.bl::rt-drop-proc`, `::rt-run-pid`, `::rt-spawn` and `::rt-send` under existing host critical-enter/leave: close proc, clear sink/timer/runnable state, remove both ends of links/monitors, enqueue exactly-once `[:DOWN …]` and `[:EXIT …]` via the same mailbox ordering path, and retain reason. Specify normal/abnormal/kill, trap_exit, dead-pid send, demonitor flush, link cycles, monitor/death race and finalizer vs kill. Generic `start`/`link`/`monitor`/`exit` verbs belong in runtime/prelude BELOW `proc`, which is a process-pattern layer above these primitives.
Proof: deterministic fake-clock tests, death while sending, double death, link/monitor races, 17/41-step adversarial budgets, no leaked frames/timers/sinks, selected BEAM differential traces and explicit deviations. Wave B is complete only when send/death can no longer expose a half-updated registry.
