## The fix, and how to recover it

- `d05862cd` — "fix(build): install natives by rename, never over a file the VM
  has mapped". One file: `priv/build/build.bl`, +40/-4.
- Recover with `git cherry-pick d05862cd`, or `git format-patch -1 d05862cd`
  (patch content-hash `ab74dca34a357aad`, 6355 bytes).
- Present in the reflog at `HEAD@{2}`.

Root cause, causality, and the corrected mechanism are recorded on
BUG-074-bug-071-bl-build-segfaults-a-null-call-i. The short version: copying
different bytes over a file the running VM has `mmap`ed makes the VM read the
new file's bytes, and a `.got` slot on disk is zero because relocations exist
only in memory — so the next indirect call jumps to address 0. `rename` over
the path installs the new file without touching the mapped one.
