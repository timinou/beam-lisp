** Standing lesson (read before starting)
Every wave of this programme has found runtime bugs that beam-lisp's own tests missed — eight so far, two silent and one a hang. The recurring root cause is that **a struct is a map on the BEAM**, so any `when is_map(x)` clause silently swallows `%Vector{}`, `%LazySeq{}`, `%Set{}` and `%Transient{}`. When adding any new collection type, audit every `is_map` guard in `lib/beam_lisp/rt.ex` and put the struct clause first.
