* Initial Message

(from knowledger, 2026-09-22) "look at the credentials and the connections thing in
beam-lisp (recent work), and show me how we can have auto-sync of libraries with
Google Drive folders. Let's design the sync model together. It needs to be
beam-lisp maximalist."

Decisions given: (1) drive.readonly; (2) one person's grant for now, firm-level
must be easily implementable ON TOP; (3) only into the library; (4) tombstone,
and a synced library is factual-only and sync-only; (5) generic work first.
"We implemented =defrelation= for computed relations, but if it needs some
equivalent in some other part of the datalog, you can propose that."

* Design of record

=docs/connectors/mirror-and-reconcile.md= — read it in full; this plan is its §7
with gates. Consumer: knowledger =docs/16-drive-synced-libraries.md=, PLAN-030.

The thesis in one line: sync is a standing datalog query whose answer should be
empty, and a server that empties it.

Datalog additions proposed (the answer to "does it need a defrelation equivalent
elsewhere"):
- relation axis 8 =:reads= — what a relation's answer depends on (watch prefilter,
  attr-basis, derived validity);
- =:~file/under= — the folder closure as a DERIVED relation, same shape as =:~reaches=;
- the =(reconcile {…})= defserver clause — a query as a job PRODUCER, the active
  form of =foundry.reconcile='s report.

* Waves (each gate is a command or a file state)

** W0 — BUG-100: datom/watch sees every attribute a query reads   [no network]
- =priv/lib/datom/watch.bl= =query-attrs= walks rules/negation/or/and; relation
  =:reads= honoured; unknown → always relevant.
- =priv/lib/datom/query/relation.bl=: =:reads= accepted by =register-relation!=,
  emitted by =catalog-datoms= as =:relation/reads=; header gains axis 8.
- Gate: =bl test test/bl/datom/watch_test.bl= and =watch_rls_test.bl= green with
  the five BUG-100 cases added.

** W1 — files.bl: the file domain schema + :~file/under   [no network]
- =:file/*= T2 attrs of design §1.2 (check =datom.file= for any name it already owns
  — =files.bl= says =:file/*= is owned there; extend, do not duplicate).
- =register-under!= with =:modes #{:bf :fb :bb}=, =:extension :derived=,
  =:reads #{:file/parents}=, provider seeding the fixpoint from the bound side
  (copy the =codebase/reaches-provider= shape).
- Gate: =test/bl/files_test.bl= — probe tree (root/sub/a, root/c, outside/b):
  =:fb= root → {sub a c}; =:bb= [a root] → hit; [b root] → miss; a T2a watch on
  =[?f :~file/under ?r]= fires on a parent-only move (depends on W0).

** W2 — connector/keep.bl + Drive changes spec   [injected transport]
- =keep= declares =:db= and =:roots=; M1: out-of-root changes dropped before
  write; folder moved in → subtree seeded (=files.list q="'<id>' in parents"=,
  BFS); cursor FIRST, seed pages never write it; commit only on
  =newStartPageToken=; =removed= → =:file/gone=, =trashed= → =:file/trashed=.
- The cursor is a datom per (account, aspect) (=accounts-and-credentials.md= §1);
  FUP-122's lease rule applies: one walker per (account, scope-set).
- A shared-drive root is refused by name.
- One =proc.queue= job per account (=:unique [:conn/account]=).
- Gate: =test/bl/connector/keep_test.bl= with a fake =get!= scripting pages:
  (a) initial sync commits start token before seed; (b) kill after page 2 of 3 →
  re-run commits the same end state, no duplicate datoms; (c) out-of-root change
  writes nothing; (d) folder moved in brings its 3 children; (e) mid-walk
  =invalid_grant= → keep paused, cursor untouched.

** W3 — connector.http get-bytes / export-bytes   [injected transport]
- Caps decided from =Content-Length= before reading the body; export 10 MB limit
  surfaced as =:export-too-large=; both behind =proc.fence=.
- Gate: tests with a local =:inets= httpd serving fixed bodies (no Google).

** W4 — proc/reconcile.bl: the (reconcile {…}) clause   [no network]
- =:query :inputs :conn :job :level=; level run at init + every =:level=; edge via
  =datom/watch= (W0); =:removed= rows cancel still-=:queued= jobs; =stats= gains
  =:owed=. Registered with =extend-clause!=; required from =priv/std/proc.bl=.
- Gate: =test/bl/reconcile_test.bl=: (a) three owed rows → three jobs → perform
  records → owed empty; (b) a row owed twice while queued → one job; (c) watch
  killed, row added, level tick enqueues it; (d) perform crashes once → retried
  → converges; (e) row stops being owed while queued → job cancelled.

** W5 — store-datom (sealed) + flow begin-web / finish-web!   [no network]
- =credential.store= =StoreDatom= over a connection, AES-256-GCM (=:crypto=)
  with a caller-supplied 32-byte key; no key → refusal by name; key never written.
- =credential.flow= web halves; state checked; shared decode/classify path.
- Gate: =test/bl/credential/store_datom_test.bl= (the store contract suite +
  "grant bytes not findable as plaintext in any datom"); =flow_test.bl= gains web
  cases (state mismatch is a value; exchange via injected =post!=).

** W6 — examples/connectors/03-keep-folder.bl   [one live consent]
- Keep one real folder; add, rename, move in, move out, trash a file in Drive;
  print the mirror after each poll. Record the transcript in =!tasks/evidence/=.
