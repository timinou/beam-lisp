* The contradiction to settle first (design decision)

docs/livebook-maximalist.md §9.2 says "the file on disk stays the truth";
priv/std/reload.bl's header says the RUNNING IMAGE is the source of truth.
Both are half-right and an append-only ledger dissolves it:

  LOG  ⊐  FILE  ⊐  IMAGE
  - The datom log (session/claim/edit facts) is the truth.
  - The .bl.org file is a FOLD of the log: append-only; the tool owns
    result spans and edit-verdict spans; humans/LLM append cells + prose.
  - The image is the fold of the file's cells through reload's gate.
  - Undo = a basis pointer, never a file rewrite (live/09-undo-redo).

Consequence: structural edits do not "edit the file in place"; they APPEND
a cell whose content is the new form + a verdict span, AND splice the
canonical source file (the .bl the ns lives in) at the form's span. Two
writes, one transaction, one fact. The ledger stays a readable narrative.

* The vision — Spell as the governing image

One object, the LEDGER: an append-only .bl.org per session and per agent.
Four verbs over it, every one a fact:

  SEE      the observatory — image, sources, dbs, usage as ONE datom db
  TOUCH    edit by symbol, through reload's gate, verdict as a fact
  TELL     append a span (prose | cell | result | verdict) to a ledger
  DELEGATE spawn an agent = env fork + sandbox + its own ledger; await or
           subscribe; its org headings ARE task facts the governor queries

Why .bl.org is preferred: headings + PROPERTIES are entities + fields
natively (org's own data model), RESULTS are owned spans already, and
datalog over heading facts is org-ql. .bl.md keeps cell/result parity only.

* Linchpins
1. LOG ⊐ FILE ⊐ IMAGE written into docs/live-architecture.md and the
   reload.bl header BEFORE W2 (else two truths again).
2. Spans come from the text scanner, never the reader; splices are TEXT,
   never pr-str (formatting + comments survive byte-for-byte).
3. Every edit is a whole-ns stage through reload — no parallel "form
   eval" path. Held ⇒ nothing written anywhere.
4. One parser: doc.bl. Fence aliases (clojure/bl/beam-lisp) are a doc.bl
   table; interface.blmd stays retired.
5. Agents are env forks with sandbox quotas from day one; a scratch .bl.org
   per agent is mandatory, so the org-datom pack is never optional.

* Landmines
- trace_pattern call_count is VM-global: scope to app modules; document.
- Whole-ns re-eval per form edit is by design (atomicity); ns-interface
  keys keep it cheap; do not optimize to form-level eval.
- .bl.org watcher path lacks a real-fs test — add one in W3.
- doc.bl org headings: keep the babel subset; headings + properties only.
- cassette replay raises on missing digest by design; W4 must record first.
