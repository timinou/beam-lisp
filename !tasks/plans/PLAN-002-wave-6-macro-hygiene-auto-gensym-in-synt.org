Problem: syntax-quote is unhygienic. Prelude macros (case, and, or in priv/core.bl) bind FIXED temporaries (e.g. `and` binds a literal `x` — see case-pairs / and expansion). User code with colliding names breaks silently.

Design: auto-gensym in syntax-quote — a symbol ending in `#` inside syntax-quote maps to a stable generated symbol (same name → same gensym within one syntax-quote form), e.g. Clojure's `x#`. Implementation: compiler's syntax-quote expansion tracks a per-form map {name → gensym}; gensym counter from a :counters or unique_integer. Also `(gensym)` / `(gensym "prefix")` prim for macro authors.

Migration: rewrite core.bl macros (case-pairs, and, or) to use `#` temporaries; their current fixed names (`x`, `v`) are the proof cases — write a test that shadows the temp name from user code and asserts correct behavior before/after.

Files: lib/beam_lisp/compiler.ex (syntax-quote), priv/core.bl, rt.ex (gensym prim), test/beam_lisp/wave_hygiene_test.exs.

Edge: unquote inside syntax-quote must NOT gensym; nested syntax-quotes get independent maps. Acceptance: shadowing tests green, all existing tests unchanged.
