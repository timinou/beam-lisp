* Goal (user, 2026-10-03)
"We don't need both approaches; we just want the best and most beam-lispy one in the end. Unified. Self-hosted."

Today there are two BL→JS targets:
- *actor target* (research/js-actors): every fn is a generator stepping in a trampoline. It has its own value model (host.mjs, copy-on-write maps, Vector as a struct) and its own 130-function BL prelude re-deriving core.
- *sync target* (priv/lib/js): plain JS functions, persistent HAMT/vectors, exact numbers. Its core is a HAND-WRITTEN JS port (core.mjs, 212 functions) kept honest by a BEAM↔JS differential.

Neither is self-hosted: both re-implement core instead of compiling it. The end state is one target where core is the SAME BL source the BEAM runs.

* End state
1. *One emitter*: priv/lib/js/emit.bl (direct style: plain JS functions, `while` for loop/recur). It is the fast, readable one, and 1/10th the actor emitter's size.
2. *Core is compiled, not ported.* priv/boot/core.bl and priv/boot/rt.bl compile through that emitter to core.mjs/rt.mjs. core.mjs and the actor prelude are deleted. A core fix lands once, in BL, for both targets.
3. *One host-leaf ABI*: the irreducible JS the compiled core calls, i.e. today's BEAM primitives (erlang bifs, LazySeq, Vector/Set/Sorted, String, ExInfo, Refs). Measured below at 168 leaves. Leaves are the only hand-written JS, each one small and differential-tested.
4. *Actors are a BL library on that target, not a second compiler.* Preemptive processes need a way to suspend; direct-style JS cannot yield mid-function. Use a *selective CPS/generator transform* applied only to functions that can reach `receive` (the analyzer already computes this footprint: system.analyze effects). Pure code, which is ~all of core and all of bl-ed, stays plain functions. receive/spawn/link/monitor/supervision move over as BL (most of research/js-actors/runtime.bl §2-6 already is BL), on top of the one value model.
5. *Split (PLAN-157) builds on 4*: client = the pure + actor subset, placed by the analyzer.

* Evidence gathered (2026-10-03)
- *Self-host feasibility*: compiling priv/boot/core.bl and priv/boot/rt.bl with the sync emitter, in a probe mode that records instead of refusing missing remotes (now reverted), succeeded for every def: core 156 defs, rt 455 defs, *0 emit failures*. Every ANF shape the core uses is already supported. The host surface is *168 distinct leaves* (list: research/bl-ed/core-host-leaves.txt):
  - 53 erlang bifs;
  - 17 LazySeq, 14 Sorted, 7 Vector, 6 Set (the collection primitives);
  - 14 String;
  - 7 Env (fetch!/intern/lookup, which become a build-time link table);
  - 5 ExInfo, 5 Refs, 3 FormMeta, 3 Decimal, 3 Record;
  - ~20 misc (lists/maps folds, inspect, io/format, Trace).
  The rest (268) are rt.bl calling itself through its module name, which the build-time linker resolves internally.
- *core.mjs coverage of the actor ABI*: 90/95 names, so the actor target CAN switch to the unified core.
- *Blocker found, needs fixing first*: BUG-112. Loading a namespace from source is O(N²) in its defs, because Link/defvar recompiles the whole shim per def: 50 defs 4 s, 400 defs 157 s. This is why the actor compiler went from ~3 to ~25 min. Any self-host build that EVALUATES core-sized namespaces hits it. The sync build already avoids eval (it compiles ANF only), and must keep doing so.
- js.build fix (in this change): placeholder interning skips names already bound, so compiling `core` itself no longer clobbers the live compiler (`identity: cannot call nil`).

* Decisions
- D1: the direct-style emitter is the base, because it is faster, smaller and readable. The generator emitter's one unique capability, suspension, is re-added selectively (U4), not globally.
- D2: core is compiled from priv/boot, never re-ported. A target that needs different behaviour gets a host leaf, not a JS fork of a core fn.
- D3: no ns is evaluated to build JS. The build compiles ANF only (BUG-112 makes eval O(N²), and eval runs top-level effects).

* Risks
- Performance of compiled core vs the hand port, especially string and seq functions: measure in U2. Lever: inline hints and leaf fast paths.
- Laziness: rt.bl's LazySeq protocol (claim/complete/fail attempts) is 17 leaves with real state. Mirror it faithfully or simplify for a single-threaded host, deciding with tests.
- Map/set ORDER: BEAM small-map order follows the atom table (FUP-141). Compiled core inherits whatever rt.mjs orders by; the differential canonicalizes today.
- BUG-112 is in the shared host tier, owned by main's sessions.
