* Initial Message

how do I run the examples?

* Intent
P16 graduated model.bl (extracts transitions from source) and system.bl (proves
guarantees) as TWO disconnected libraries — every test/demo hand-writes the
{:label :guard :next} maps and the SMT strings. P17 closes the seam so you point
the checker at an ordinary defserver/loop/defn and it verifies, cleanly
integrated into beam-lisp.

* The gap (audited 2026-08-29)
- NOTHING feeds model/transitions output into system/prove-box.
- No ^{:invariant}/^{:refines} reading — demos pass hand-written SMT-emitting fns.
- No source→SMT translator — only bare arithmetic works by accident (bl prefix
  ≈ SMT-LIB); real guards (and/or/nil?/compound) don't translate.
- Message coverage + dispatch determinism (two scorecard rows) are prose, not code.
- Guarantee failures return data maps, not errors/render'd file:line:col warnings.

* Work
** priv/smt.bl — source→SMT-LIB translator
Translate a reader node (guard/next expr) to an SMT-LIB string over declared
state vars. Handle: arithmetic (+ - * comparisons), boolean (and/or/not),
predicates (nil?/pos?/zero? → the tag/int encoding), literals. Unknown forms →
:untranslatable (sound: skip the proof, warn, never a false proof).

** system/verify-process — the seam
(system/verify-process node) → extracts transitions (model), reads ^{:invariant}
off the name meta, translates guards/next via smt.bl, proves □Inv, returns
{:name :holds :warnings [{:msg :line :col}]}. Annotation-driven, matching the
vision: annotate a defserver, it gets proven.

** message coverage + dispatch determinism (system.bl)
- coverage: datalog join of :call/* senders × handled patterns → unhandled-msg
  warnings (the "TLA+ can't do this" headline; MVP-B facts exist).
- determinism: z3 pairwise guard-disjointness over a clause set.

** errors/render integration
Route guarantee failures through P11 errors/render → file:line:col + caret +
delaborated form, like every other beam-lisp checker warning. Native feel.

** :~step as a full defrelation over datom
The computed step relation registered via defrelation; :~reachable a derived
fixpoint. The model as a queryable view (elegance/queryability, lower priority).

* Acceptance
- (system/verify-process node) works end-to-end on a defserver with ^{:invariant}
  — no hand-written SMT, no hand-written transition maps.
- message-coverage + determinism return warnings on real clause sets.
- guarantee failures render as file:line:col caret'd warnings.
- tests (test/bl/system/) + demos (examples/system/) for the integrated checker.
- full non-auth suite green; numbers measured; docs updated.
