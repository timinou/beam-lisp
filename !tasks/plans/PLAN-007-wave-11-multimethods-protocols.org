Clojure's polymorphism, BEAM-flavored.

Multimethods first (simpler): `defmulti` (name dispatch-fn), `defmethod` (name dispatch-val [args] body). Registry: ETS {:multi, ns, name} → %{dispatch_fn, methods: %{dispatch_val => fn}, default: fn|nil}. Call: apply dispatch-fn to args → lookup method → apply. `derive`/isa? hierarchy: defer unless cheap (parents ETS table).

Protocols (bigger): `defprotocol` + `extend-protocol`/`extend-type`. Two implementation routes: (a) Elixir Protocols under the hood (dispatch on struct — but beam-lisp fns aren't structs; need a wrapper type or any→Any impl with per-type fn map lookup), (b) pure ETS dispatch table keyed by (protocol, type-tag) — slower but uniform and redefinable at runtime, matching beam-lisp's dynamic var model. Route (b) fits the runtime-redefinition story; route (a) fits AOT (wave 9). Decide at pickup; prototype (b).

deftype/defrecord: likely out of scope — Elixir structs already cover the need via interop; document the position instead.

Acceptance: examples/multimethods.bl (area of shapes with defmulti/defmethod + :default), tests including method redefinition; protocol PoC only if multimethods land cleanly.
