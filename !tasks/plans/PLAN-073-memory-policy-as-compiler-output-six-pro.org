* Initial Message

would `veritas`, `codebase`, and `system` enable us to compile directly to BEAM and manage garbage collection and other concerns through formal proof? I am open to ideas

* Goal

Turn six BEAM memory decisions — heap flags, leak lints, sub-binary detach,
value representation, native offload, atom interning — from human guesses into
theorems that the compiler consumes. Design: docs/memory-policy/README.md and
docs/memory-policy/0N-*.bl.md (one per policy). This plan builds them.

* Waves (value ÷ cost order: 2, 6, 3, 1, 4, 5)

** W1 — lints, zero annotation: leak (doc 02) + atoms (doc 06)
- system.facts: add :touch/clause :touch/field :touch/mode projection
  (footprint per state field per clause). Needs footprint/state-field-footprint
  — footprint currently keys resources by the op's first-arg SYMBOL; extend to
  recognise (assoc state :f …)/(update state :f …)/(:f state) as field
  resources of `state`.
- memory.leak: unbounded-field rule (:A ∧ ¬:W, minus fields bounded by the
  invariant); orphan sends reuse knowledge/unhandled-sends. report.
- memory.atoms: interning-ops · entry-points · reachable-interning over
  codebase reaches; exclude literal-arg calls via typed.
- Gate: tests on examples/system/*.bl servers (plant one unbounded :log field,
  one orphan send, one (keyword req-key) under a web handler → each reported,
  clean servers silent). Full mix beam_lisp.test green.

** W2 — refc-binary (doc 03)
- typed: split :string → :string (charlist/str) + :binary; update guard-tags,
  lit-type, sort-of-tags (:binary → "String"). Regression: smt_fragment_test,
  smt_symmetry_test, veritas theories_test must stay green.
- system.facts/state-binds: (assoc/update state :f expr) → {:field :op :source
  :line}; source ∈ :message | :state | :literal from the clause's param names.
- memory.binary: retained-sub-binary query; rewrite rule ::detach-sub-binary
  wrapping in (binary/copy …); fullsweep_after 0 when the field is a
  collection of sub-binaries.
- Gate: planted (assoc state :hdr (subs msg 0 8)) reported + rewritten; a
  literal-source bind not reported.

** W3 — heap bound (doc 01)
- system.core/length-bounds: the per-field K the invariant proved (already
  derived inside verify-process via translate-len — surface it).
- memory.heap: words-of · heap-bound · flags (min = 2·bound, max = 4·min,
  kill true). ^{:heap :default} opt-out.
- compiler.bl compile-defserver: when (memory.heap/flags node) → prepend
  process_flag calls to init. NB compiler.bl is boot tier and must NOT require
  memory.heap; do it as a compile-time hook the loader registers (same seam
  verify-process uses: annotate → checker), or emit the flags from a
  post-compile pass in std. Decide in the spike; record the choice here.
- Gate: process_info(pid, :garbage_collection) min_heap_size equals the
  theorem on examples/system/01_counter; :minor_gcs = 0 after 10k casts
  within the invariant; growth past bound kills + restarts under supervisor.

** W4 — representation (doc 04) — depends on PLAN-074 (Core backend) for the
   tuple/iolist lowering; persistent_term and hibernate do NOT
- memory.repr: fixed-shape? · write-never-after-init? (gfp/safe-region over
  codebase call graph) · idle-shape? (gfp/af) · append-only-string?.
- persistent_term: emit at read sites for vars proven :R-everywhere; gate on
  no interop crossing (codebase :call/callee interop-name?).
- hibernate: tail of clauses entering an idle phase, only with ^{:rate :low}.
- tuple state + iolist strings: consume from self.cerl once the Core backend
  lands (blocked on PLAN-074 W7); until then record the decision only.
- Gate: memory/words per state before/after; persistent_term/get at 0 copies
  (erlang:process_info binary/heap unchanged across 1k reads).

** W5 — native offload (doc 05) — depends on self.anf from PLAN-074 W1
- memory.native/eligible: footprint ∅ ∧ termination ok ∧ sorts ⊆ nif-sorts ∧
  work bound; refusal names the failed theorem.
- work-bound: ops-per-iteration × measure₀ from termination's measure;
  threshold 1 ms → :normal else :dirty-cpu.
- obligations via system.smt: in-bounds index for every nth; overflow → checked
  arithmetic with fallback to the bl impl.
- lower: bl-ANF fragment → Rust (scalars, binaries, tuples, let, if/case,
  tail loop → loop{}); rustler encode/decode; crate under native/<ns>/.
- certify: veritas.property for-all over gen(sig): (f-bl x) = (f-nif x).
- Gate: one numeric loop (dot-product) and one binary loop (checksum) offloaded,
  certified, ≥5× faster at 1 MB input; impure/diverging examples refused with
  the named reason.
