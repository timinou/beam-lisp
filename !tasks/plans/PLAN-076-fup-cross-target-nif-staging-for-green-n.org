Deferred scope-C from PLAN-075. `make-drops.sh` builds cross-target drops
(linux/aarch64, macos/universal, windows/x64) but they boot only the
pure-language surface: the Rust NIFs (datom crates, Explorer/Polars) and z3 must
be built for the TARGET libc, not the host's.

The libc rule (drop doc §11): beam-machine linux bundles are static-musl. A
glibc-built NIF cannot load into them. Grafting the bundle's OTP libs fixes
crypto/ssl, but our NIFs need `cargo zigbuild --target
x86_64-unknown-linux-musl` (+ aarch64, darwin, windows triples) and per-target
z3 binaries staged into the release's priv before `drop pack --target`.

Acceptance: `make-drops.sh` produces a linux/aarch64 + macos/universal drop that
passes the doc §9 acceptance INCLUDING the z3 + explorer NIF smokes, not just
