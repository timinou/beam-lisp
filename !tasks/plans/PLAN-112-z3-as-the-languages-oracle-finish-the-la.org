** P2 — S4/S17: the candidate loops hold a session; then k-induction.

Target: `core.bl` `discover-invariant` (:1210), `synthesize-capacity` (:1419),
and the `:holds-at-init?` / `:inductive-under?` / `:len-bound-inductive?`
helpers they call (:1177 :1207 :1405 :1415).

Change: each loop opens ONE `oracle/session` with the declarations and the
transition relation asserted once, then asks each candidate through
`oracle/scoped` (push/pop). The candidate-independent prefix is asserted once;
only the candidate is scoped. This is exactly the prove-box pattern S4 already
shipped for `verify-process`. Then k-induction: `verify-process` gets a `:k`
option (default 1 — today's behaviour); for k>1 the step obligation unrolls k
copies of the transition and asks whether the invariant at step k follows from
it holding at steps 0..k-1. A machine that is safe but not 1-inductive (the
classic two-phase counter) is then verified with k=2 where today it is refused.

Example `examples/z3/07-sessions.bl` — "why a conversation beats a question".
Run `discover-invariant` on `examples/system/14_discover_invariant.bl`'s machine
twice: once with sessions off (env `BL_ORACLE_SESSIONS=off`, kept for exactly
this comparison), once on. Print candidates tried, solver calls, total µs, and
the same discovered invariant both ways (the point: same answer, 30× cheaper).
Then the BEAM angle: the session is a lease on a gen_server; print
`(z3pool/current)` inside and `nil` outside. Trailer: measured ratio.

Example `examples/z3/08-k-induction.bl` — "a proof that needs to remember".
The two-phase counter: `phase` toggles 0/1, `x` increments only in phase 1,
invariant `x >= 0`... no — use the one that genuinely needs k=2: `(= (mod x 2) phase)`
is 1-inductive, but "x never equals 3 when phase is 0" is NOT provable from one
step and IS from two. Print: k=1 → `holds: false` + counterexample
(S16's witness shows the spurious state), k=2 → `holds: true`, calls and µs
for each. The reader sees the counterexample vanish. Trailer: the honest limit —
k-induction finds proofs, not invariants; a refusal at k=3 says nothing.
