* Result (2026-08-18)
Delivered at projects/fundamental/ (own git repo, commit 8e7ebf0) — scaffolded from samadhi_phone.

App: mic → AAudio C NIF (ring buffer on audio thread; YIN on worker thread) → {:fundamental, :pitch, json} ~23fps → PitchStream debounce → Exercise chart engine → beam-lisp bass.ui render trees. Exercises: Tune Up (cents gauge, in-tune bloom + haptic) and Pitch Highway (falling-note targets, grades by cents, combo multiplier, results panel).

Sonic Pi/Tau5 transfers applied: BEAM never in the audio callback; timestamped judgment vs t_mono_ms (audio clock), never message arrival; native owns scheduling. Verified via primary sources (Sam Aaron in-thread post; FARM'14 paper): BEAM = soft-realtime event scheduler (~1ms OSC forwarding), audio stays native.

Verified: 58 host tests green incl. C↔Elixir detector parity over identical synthetic PCM (-DFUNDAMENTAL_HOST_TEST harness compiles the real plugin C); credo --strict clean; NIF compile-checked against NDK 27.2 aarch64 headers; fundamental_audio_nif_nif_init symbol exported for driver_tab.

NOT verified: on-device deploy (just phone) and real-mic behavior — next session's gate.
