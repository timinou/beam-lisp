* Goal
One BL source (`research/js-actors/showcase.bl`) declares an app with `(split/defapp NAME {...})`. The build (`compiler.bl`) proves where each function may run and emits three artifacts:
- `out/showcase-client.mjs` — runtime + generic client shell + ONLY the client closure (view, local reducer, shared checks) + generated glue. Runs in a browser Worker.
- `out/showcase-server.mjs` — runtime + generic server shell + ONLY the server closure (init, intent handlers, shared checks, private data) + glue. Runs in Node behind `split-server.mjs`.
- `out/showcase.contract.json` — wire contract (snapshot type, intent param types, sha256 digest) derived from the same declaration; `out/showcase.split.json` — placement map with evidence per function.
Showcase page `showcase.html`: live task board (local filter, add/toggle/clear intents, multi-tab live via SSE, pending ghosts, client-vs-server refusals) beside a "what the compiler decided" panel (placement map, contract, event timeline).

* Placement verdict (fail closed, per function; every app defn gets one)
Client closure = ANF global refs from client roots (view, local, on, checks). A fn is client-portable only when ALL hold:
1. codebase qualified cone: no `<dynamic>` call; every edge :defined or a bare unqualified (core/local) name;
2. system.analyze: footprint {} and terminates (needs core pure globals fix in system.footprint);
3. emitter: ANF scan finds no effect leaf (RT_HOST leaves, process verbs, receive, dynamic invoke of a local) anywhere, incl. lambdas; ABI audit passes;
4. not declared `:private`, and reaches nothing private.
Any client-root closure member failing → BUILD REFUSED with fn → callee path + line. Server closure = ANF refs from init/apply/check/snapshot. Unreached defns reported as unused.

* Wire
Spec grammar: `[:text min max]` (UTF-16 length), `[:int min max]` (safe ints), `:bool`, `[:enum :a :b]` (keywords), `[:list max T]` (vector), `[:record {k T}]` (exact keys, keyword keys), named refs to `:wire` entries. JS `split-codec.mjs` decodes JSON→BL data by contract (shape only); BL shells re-check with `split-wire-ok?` (authority) and encode JSON by spec (projection: undeclared fields never leave the server).
