substrate (W3) → AOT waves (W1/W2) → `assemble` (W4) → `pack` (W5), writing

  finds its launcher prefix without a Rust tool.

** W8 — the build session + its claim (no `_build` lock)

Two concurrent builds must not corrupt a tree, without Mix's `_build` lock: a
claim with an owner and a liveness check, so a stale claim from a killed build
does not wedge the tree. The fact log (W2) already makes an interrupted build
resumable, so the claim only has to stop two WRITERS.

** W9 — env.bl: `:app` `:build` `:release` `:deps`; `bl seed`; `doctor --deep`
