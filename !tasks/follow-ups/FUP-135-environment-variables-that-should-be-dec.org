* Initial Message

can you tell me what else we could do to improve the timing?

** Rule
Less ambient state, more discoverable. A preference belongs in env.bl, ~/.config/bl/config.bl, or a flag. An environment variable is acceptable only as a process-level override, a launcher-to-VM protocol handoff, a test seam, or a standard variable (HOME, XDG_*). Where a variable exists as a WORKAROUND, fix the cause.

** Classification (from a read-only sweep; regenerate with: grep -rn 'System/get_env|env::var' priv tooling)
- BL_CACHE_DIR, BL_CACHE_MAX_MB, BLANALYSIS_DIR: config. env.bl :cache {:dir :max-mb}. BLANALYSIS_DIR duplicates BL_CACHE_DIR: delete the alias.
- BL_BUILD, BL_AUTOBUILD, BL_ALLOW_UNPUSHED_LATEST: config. env.bl :build and a hooks key. ALLOW_UNPUSHED is a one-shot at the push site: make it a hook flag.
- BL_DROP_KEEP_DAYS, BL_DROP_GRACE_HOURS, BL_BUILD_TIMEOUT_MIN: config. :drop {:keep-days :grace-hours}, :build {:timeout-min}. Defaults are already named consts.
- BEAM_LISP_PATH, BEAM_LISP_CODE_PATH: duplicate the -p and --code-path flags. Express in env.bl :paths; flags override.
- BL_USE: config. config.bl :use. (It also made the launcher's own tests environment-dependent; fixed in PLAN-158.)
- BL_INSTALL_BIN: undocumented. A flag on self-install, or document it.
- BEAM_LISP_AOT_STRICT, _AOT_CACHE, _AOT_CACHE_DIR, _AOT_REPAIR: config. env.bl :aot.
- BEAM_LISP_DEV, _RELOAD, _IMAGE: declarations a tree makes about itself. env.bl :image.
- BL_HOTPATCH, BL_INDEX_WORKERS, BL_NAMES_SUFFIXES, BL_ORACLE_SESSIONS, BL_CATALOG_LIB, BL_CATALOG_DIR: undocumented config. Move to env.bl keys; document.
- BEAM_LISP_Z3, BEAM_LISP_Z3_FORCE: WORKAROUND for z3 provisioning. Fix provisioning, then delete.
- LIBRARIUM_XBERG: WORKAROUND / feature switch. Make it config or delete.
- BL_SEED_EBIN, BL_SEED_EBIN_FALLBACK: keep the --ebin flag; fold or delete the fallback.
- BL_BIN: protocol (launcher identity), plus a second meaning in xberg. Keep as protocol; give xberg its own key.
- BL_ROOT, BL_BUILD_ID, XBERG_*: protocol. Keep; document as internal.
- BL_TEST_UID, BL_TEST_TIMES, BL_TEST_TIMEOUT, BL_SELFBUILD_GATE, BEAM_LISP_NIF_TRACE: test seams. List as test-only; pass the timeout through runner options.

** Acceptance
Each non-protocol variable has a declaration key or is deleted. The CLI reference documents ONE list of what remains. A test diffs that list against what the code reads.
