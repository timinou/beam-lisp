* Initial Message

Please look at the various modules available and tell me what `bl` should ship with to be a complete interface to programming in beam-lisp

* Symptom

`mix bl check priv` reports `priv/compat/clojure/set.bl` as `:unreadable`, so the clojure-compat `set` namespace is outside the proof gate.

The failing pass raises:

#+begin_example
mix bl eval "(lsp/document-symbols (BeamLisp.Loader/read_source \"priv/compat/clojure/set.bl\"))"
=> unsupported binding pattern: expected a symbol, vector, or map
#+end_example

So this one dies in the ANALYSIS (symbol) pass, not the diagnostics pass (contrast FUP-033, where symbols succeed).

* What to look for

A binding slot holding something other than a symbol / vector / map — a *nested* pattern, a keyword, or a destructuring form the analyzer has no clause for. The file is 5.5 KB of clojure-compat surface (`clojure.set`-style `union`/`intersection`/`difference` built on `reduce`, `fn`, and set ops), so the culprit is most likely a `fn` parameter list or a `let`/`loop` binding written in a shape Clojure accepts.

* How to pin it (cheap)

Re-run the failing pass while walking the file's top-level forms one at a time (e.g. eval each `(nth (BeamLisp.Compiler/read_all_data src) i)` through `lsp/document-symbols` as a one-form program) and report the index of the form that raises. That form IS the repro; the fix is either a missing binding-pattern clause in the ANF/analysis compiler or a source spelling that beam-lisp does not accept (in which case the file is not loadable either — check `BeamLisp.Loader.ensure_loaded "clojure.set"` — and the honest fix is to spell the file in a shape the language implements).

* Why it matters

Two of the shipped library files are invisible to `bl check`, and one of them (`priv/boot/core.bl`) is the core itself. `:unreadable` is supposed to mean "the analysis could not run on this text", which is a fact worth knowing; it must not become a permanent blind spot for the two files most worth watching. Until both are readable, `bl check` documents them in `.bl-check.edn` with `:unreadable true` and measures nothing.

* Acceptance

- `bl check priv/compat/clojure/set.bl` measures the file (`:unreadable false`, non-zero `:fns`).
- A test pins the distilled source shape that raised before the fix.
