** Context

The transact pipeline was profiled and its big allocation hogs fixed (commit
65f7641: validate 2037->62ms, current-values/realize-op ~600ms saved,
resolve-tempids 789->502ms; total transact 6.4s->4.1s, degradation eliminated).
Two smaller costs remain, both interpreted-bl lazy-seq / map-set allocation, both
diminishing returns relative to the persistent-reopen cache (which makes the cold
path a one-time cost). Filed so they are not lost.

** Remaining costs (measured, compiler.bl 11039-datom load)

*** net-datoms pass-2 (~1.5s) — priv/datom/tx.bl
`net-datoms` builds a `held` map by calling `current-values` for every distinct
`[e a]` (~11k), each wrapped in `(set …)`. On a FRESH store every result is empty,
so the map is 11k empty-set entries \u2014 pure allocation. current-values already
has an empty fast-path (returns []), so the residual cost is the map/set building
itself. Options:
- skip the `held` entry entirely when current-values returns [] (a missing key
  already means \u201cheld nothing\u201d in pass-3's `(contains? (get held [e a]) v)`,
  which is false for both a missing key and an empty set \u2014 verify this holds).
- use a transient/eager accumulator for the pass-1 `last-at`/`eas` maps (11k
  assoc's each).
Acceptance: net-datoms alone on 11039 datoms (empty store) measurably < 1.5s;
conformance + cardinality/upsert semantics unchanged (net-datoms is correctness-
critical \u2014 it collapses intra-transaction assert/retract; the tiny-graph and
cardinality tests are the oracle).

*** index-source (~2.9s) — priv/codebase.bl + the reader/form-walk
`index-source` = `BeamLisp.Reader/read_string` + `index-forms` (walk every form
to extract fn/call facts). Different subsystem from tx; likely the same
into/mapv/mapcat pattern in the form walk. LOWER priority: with the persistent
`.blanalysis` cache, index-source runs ONLY on a content-hash MISS (a changed
file), so it is off the warm path entirely. Worth a profile pass only if cold
indexing of large files becomes a felt cost.
Acceptance: profile index-forms; if a single-pass reduce or transient cuts it
meaningfully without changing the emitted facts (codebase tests as oracle),
apply; else record that it is reader-bound and leave it.
