* Leftovers after PLAN-158 steps 1-10 (each observed, none fixed)

1. *Self-build staging root is one fixed path per machine* (/tmp/bl-selfbuild-src). Two self-builds of different trees race on it. claim/clear! now keeps the claim so a second build is refused instead of wiping the first. NOT changed in PLAN-163, deliberately: the fixed path is load-bearing (a beam embeds the path of the source it was compiled from; before it was fixed, gen-2 and gen-3 differed in 438 beams, all by extraction path; priv/build/selfbuild.bl ~staging-root~). A per-build path must therefore be a FUNCTION OF THE BUILD'S IDENTITY, not a counter: the same tree at the same commit always stages at the same path, so the fixpoint holds per build, and two different builds stop colliding. The identity to hash is the source provenance the build already computes (priv/build/provenance.bl). Needs the fixpoint gate (test/bl/self_build_gate_test.bl with BL_SELFBUILD_GATE=1) to prove two generations of one build still produce identical beams; do it on a quiet machine.
