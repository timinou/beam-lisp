* What is already there (do not re-derive)

`hotel.bl` exposes exactly what a page needs, so the page is a renderer and not a
second hotel:

    hotel/start-desk!            idempotent; starts the desk with {:name :desk}
    hotel/start-housekeeping!    idempotent; NO {:name …} (see below)
    hotel/rooms                  the desk's rooms — a map of room → {:state :guest}
    hotel/charges                the ledger, off the table the heir holds
    (proc/schedules)             the declarations and their outcomes, off the store
    (proc/op! server id op)      the write path: pause · resume · run-now, BY NAME

`hotel.bl` runs its WALKTHROUGH at load (module-level code), so requiring it from
a page prints the walkthrough and leaves the audit paused. A page needs the
definitions without the walking: split the file (`hotel.bl` = the hotel,
`walkthrough.bl` = the walk), or guard the walk behind a flag the runner sets —
the gallery precedent is `(when (not (Process/get :loom.catalog/indexing)) …)`,
where the flag is set by the tool that REQUIRES the file, which only works
because nothing else requires it.

* Measured API facts (each cost a run)

  * `loom.token/with-sheet` takes a THUNK, not a tree. Passing the tree gives
    `ArgumentError: a vector called with 0 arguments — a vector is a function of
    its index` from `with-sheet/1`. Call it as `(t/with-sheet (fn [] (b/col …)))`,
    and render `(:style result)` and `(:tree result)`.
  * `loom.ui/button` merges the CALLER's opts last, so `{:as :a :href "…"}`
    renders an anchor with the button's skin — which is how a click becomes a
    link without any client state.
  * `web/route conn [:get "/"] (web/html conn page) :else (web/text conn 404 "…")`
    is the router shape; the query string arrives as `(:query_string conn)` (a
    raw string, so parse it — three fields is a `split` on "&" and "=").
  * a `sched` server must not be started with `{:name …}` (FUP-104).
  * port 4048 is free; `bl serve FILE` prints the listener line and blocks.
