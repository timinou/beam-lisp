* Goal

`defregistry`, `defbus` (and the shape `defsupervisor` already has) are
hand-copied `defserver` bodies. They become CLAUSES over one shared expander
(`priv/std/server.bl`, PLAN-126 §4.6), and the macro spellings go away.

This item is the CONSUMER half: the deprecation is recorded now, the smells that
migrate consumer code are written here, and they are applied when the clause
forms exist.

* What is deprecated, and what is NOT

| form | becomes | module |
|---|---|---|
| `reg/defregistry` | the `(registry …)` clause | `reg` STAYS — `register`/`unregister`/`whereis`/`where` are plain fns over a pid or name and never needed the macro |
| `bus/defbus` | the `(bus …)` clause | `bus` STAYS — `bus/publish`, and `flow/subscribe` for the demand side |
| `super/defsupervisor` | **unchanged, NOT deprecated** | `super` GROWS — `pool-spec`/`pool-dispatcher` are a real server |

`defsupervisor` is not a clause and must not be sheared into one: a supervisor
is a different PROCESS TYPE (`Supervisor`, not `gen_server`). It is the *second
client* of the same expander — it already IS a clause-DSL over a data
descriptor (`{:__supervisor__ true :strategy … :children (list …)}`,
`priv/std/super.bl:95-134`), which is the evidence that the §4.6 design is the
one the language already wanted.

Deprecated in the source now (docstring + `^:deprecated` meta, which nothing
reads yet — so it is honest documentation, not a tooling gate):
`reg/defregistry`, `bus/defbus`.

* NOT YET — the blocker

The clause forms do not exist until `priv/std/server.bl` lands, and that waits
on the boot rename (`defserver` → `defgen`) in PLAN-088. **Do not register these
smells before then**: `bl fix` would rewrite consumer code into a form the
compiler cannot read.

* The smells (ready to paste into `priv/std/deodorant.bl`)

Tier `:reinvention` — opt-in via `--tier every`, which is exactly right for a
migration: exact, but it restructures the form.

```clojure
; The bundle macros become CLAUSES on one server form. Opt-in, because the
; rewrite also needs `srv` on the file's :require line, which a smell cannot
; edit. Both arities of defbus are covered: the config clause is optional.

(defsmell defregistry→registry-clause :reinvention
  (reg/defregistry ?name ?keys) => (srv/defserver ?name (registry ?keys))
  :when (fn [b] (let [k (get b '?keys)]
                  (and (list? k) (= 'keys (first k))))))

(defsmell defbus→bus-clause :reinvention
  (bus/defbus ?name ?cfg) => (srv/defserver ?name (bus ?cfg)))

(defsmell defbus→bus-clause-default :reinvention
  (bus/defbus ?name) => (srv/defserver ?name (bus)))
```

Pinned constraints, learned by reading the engine rather than guessing:

- **The matcher is EXACT ARITY, no variadics** (`priv/std/rewrite.bl:141-145`:
  `(= (count pattern) (count form))`). So a rule may not say `(keys ?k…)`; bind
  the WHOLE sub-form — `?keys` holds `(keys :id)` — and let the guard check its
  shape. That is why the registry rule has a `:when`.
- **A smell cannot edit the `ns` form.** Every consumer needs
  `[srv :as srv]` on its require line, which is a one-line human edit per file.
  Say so in the migration note; do not pretend the fix is complete.
- **A rule may only rewrite to a word that resolves** (deodorant's own rule,
  from the `ffirst` note). `srv/defserver` resolves only once `server.bl` is on
  the path, which is the gating condition.

* The follow-on smell (lands with the boot rename)

When boot's special form is renamed to `defgen`, std's `defserver` can finally be
referred unqualified, and the interim qualifier drops off mechanically:

```clojure
(defsmell srv-defserver→defserver :safe
  (srv/defserver ?name ?*clauses) => (defserver ?name ?*clauses))
```

NB this rule needs the same rest-pattern the engine does not have. Either
express it as exact-arity rules for the clause counts actually seen, or add a
rest-pattern to `match*` — a `?*x` convention that binds the remaining seq and
splices on `subst*`. **That is its own item**: it is the one thing standing
between deodorant and every "this form became that form" migration.
