* Existing syntax / contracts
- priv/lib/datom.bl q(query, db, inputs...) returns exact sets/tuples according to :find; from compiles into q. Do not silently change q to a result envelope or truncate its answers.
- datom/attribute-page(db, attr, after-eid, limit) is AEVT complete entity-group pagination. Keep its existing valid semantics/callers; it is not AVET rank paging.
- priv/lib/datom/query/analytic.bl similar-to takes attr/query/k/[rerank]. Current bound-entity path restricts candidates but still traverses the cached corpus. Do not relabel this as bounded native filtered search or treat an approximate vector result as exact.
- auth/guard, auth/scope and auth/scope-all are existing policy composition. Scope clause relations are preferable to per-row large allowed-set predicates, but arbitrary policy providers still need admitted costs and full snapshots/generations/expiry.
- Current query map parser keeps find/in/where/with only. A proposed :budget/:page/:order key is NOT an existing API and cannot be silently accepted/dropped.
