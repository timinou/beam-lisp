* Shape

- key = =<prefix>/<sha-hex>=; no sharding needed on S3.
- =-blob-put= = PUT (idempotent by construction; optional HEAD-first to skip re-upload).
- =-blob-has?= = HEAD. =-blob-get= = GET. =-blob-shas= = paginated LIST under prefix.
- =BlobStream= = GET with streaming body (Req =:into=).
- =BlobUrl= = presigned GET/PUT via =aws_signature= — the browser talks to S3 directly;
  the BEAM never proxies bytes. A presigned PUT + =put-file!='s descriptor form is the
  upload flow for clients.
- Distributed-store guard: =store-hobbes= extends =DefaultBlobs= to THROW with a clear
  message when no S3 cfg is supplied (local blobs + distributed db = wrong).

* Resolution (implemented, commit b7496c4, 2026-09-02)

- =priv/lib/datom/blob-s3.bl= — the full BlobStore port over any
  S3-compatible server: SigV4 header auth (aws_signature =sign_v4=) for
  PUT/GET/HEAD/DELETE/ListObjectsV2; presigned GET urls via
  =sign_v4_query_params= (this is =BlobUrl=, what =datom/file-url= hands to
  a client); =BlobStream= yields 64 KiB chunks (whole-GET then chunk; the
  byte-range upgrade is named in the header comment).

- Deps: =req= and =aws_signature= promoted to DIRECT deps in mix.exs.

- Two protocol subtleties found against a real server, now comments in the
  file: (1) query values must be pre-encoded RFC3986 — aws_signature's
  canonical query passes raw bytes through, and a raw =/= in =prefix=/
  =continuation-token= breaks the signature; (2) presigned urls must sign
  =UNSIGNED-PAYLOAD=, not the lib's default empty-body hash — every S3
  server rejects the latter with Invalid signature.

- Tests: blob_test.bl runs the ENTIRE conformance body against blob-s3 when
  =BL_S3_ENDPOINT/BUCKET/REGION/ACCESS_KEY_ID/SECRET_ACCESS_KEY= name an
  endpoint (fresh prefix per run — the bucket persists, the suite assumes an
  empty substrate), plus a presigned-url-fetched-by-unsigned-client test.
  Without env, the substrate is skipped cleanly (17 tests/70 assertions;
  with S3: 17/90). Verified against Garage 2.3.0 (pacman, single node at
  127.0.0.1:3900, region =garage=, bucket =bl-blobs=), including an unsigned
  =curl= fetch of a presigned url.
