* Shape

#+begin_src clojure
(datom.blob-s3/open {:bucket "b" :prefix "app/blobs" :region "eu-west-1"
                     :endpoint nil            ; MinIO / R2 override
                     :credentials :env})      ; or {:access-key … :secret …}
#+end_src
- key = =<prefix>/<sha-hex>=; no sharding needed on S3.
- =-blob-put= = PUT (idempotent by construction; optional HEAD-first to skip re-upload).
- =-blob-has?= = HEAD. =-blob-get= = GET. =-blob-shas= = paginated LIST under prefix.
- =BlobStream= = GET with streaming body (Req =:into=).
- =BlobUrl= = presigned GET/PUT via =aws_signature= — the browser talks to S3 directly;
  the BEAM never proxies bytes. A presigned PUT + =put-file!='s descriptor form is the
  upload flow for clients.
- Distributed-store guard: =store-hobbes= extends =DefaultBlobs= to THROW with a clear
  message when no S3 cfg is supplied (local blobs + distributed db = wrong).

* Deps

=req= and =aws_signature= are in =mix.lock= only transitively (explorer, req_llm). Promote
both to DIRECT deps in =mix.exs= — a transitive dep vanishing must not be a silent S3 outage.

* Tests

- =blob_test.bl= conformance suite run against blob-s3 via =Req.Test= stub adapter
  (no network); MinIO run behind an env flag for a real round-trip.
- presigned URL shape test (signature present, expiry honoured).
