* What

veritas (=priv/veritas.bl=, PLAN-064) unifies the four tools it generalises:
- =priv/mock.bl=        → =veritas/exists= over a contract-as-spec
- =priv/mock/fault.bl=  → =veritas/faults= (exists-not, now with a modality)
- =priv/fuzz.bl=        → =veritas/covers= (∀ over a function's own guards)

All three still run and are green today. This follow-up is the CUTOVER: make
each a thin wrapper (or re-point its callers/tests at veritas) so there is one
implementation, not two — the harmony rule (one need, one impl).

* Why it is a separate item, not done inline

The four tools have PASSING demos and tests right now. Rewriting them in the same
session that built veritas risks breaking working, tested code for a cleanup.
Land veritas first (done), then cut over deliberately with the existing tests as
the safety net — re-point them, never delete them.
