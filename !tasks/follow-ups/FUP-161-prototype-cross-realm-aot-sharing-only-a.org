* Prototype
Compare canonical module relocation/rewrite against compile-to-resolved-segment content addressing and safe sharing only for already identical segment/module identities. Reuse AOTCache and Emit/Link naming; do not add a cache registry, public :aot/:segment knobs or developer annotations. Resolve all source/shadow/uses/macro/provider dependencies in the target environment. A closure alone is insufficient when ambient compile-time effects are not captured.

Inventory every baked reference: namespace and companion modules, function-body modules, remote calls, literal callable descriptors, initializer references and recursive/mutual links. Cache replay after reset_body_sequence must reserve/recover allocated names rather than alias different bodies. Test module identity against manifests as well as beam hashes. Source fallback must never execute initialization twice after a failed partial load.

* Isolation/lifetime gate
Two concurrently open realms with identical bytes may share immutable cache payloads, not mutable vars, initialization effects or code lifetime without leases. Independently edit/close/reopen each realm; exercise shadow/provider changes, concurrent/failed initialization and live callers during unload. Delete current code before purging old code only when manager-owned leases permit it. Bound retained artifacts/modules and atom growth during project churn; purging alone does not reclaim atoms.
