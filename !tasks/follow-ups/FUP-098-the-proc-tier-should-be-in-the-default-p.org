* The ask

`proc`'s surface should be part of the default prelude, so a program writes

```clojure
(proc.server/defserver workers
  (registry (keys :id))                 ; a clause: already free
  (tick 15 :minutes [st] (reap!)))
```

with **no require at all** — and, in the end, `(defserver …)` bare.

* Why the ask is RIGHT, and for a sharper reason than ergonomics

`defserver` is a compiler SPECIAL FORM today, so it is already ambient: no
program has ever needed to require it. Moving the vocabulary to std and making
the form require-able would be a **regression** — the new spelling available
only to those who ask. Whatever the mechanism, the tier's one macro must not be
LESS available than what it replaces.

* What the prelude actually is (verified)

Bare-name resolution falls back through two namespaces, in order
(`lib/beam_lisp/env.ex:825`):

```elixir
[{ns, name}] ++ refer_candidate(ns, name) ++ [{"core", name}, {"sugar", name}]
```

`core` and `sugar` ARE the prelude, and both are BOOT tier
(`priv/boot/core.bl`, `priv/boot/sugar.bl`).

**∴ the prelude cannot simply `:require` proc**: boot is compiled first, so a
boot-tier file requiring std is a compiler cycle. (And `tiers.ex` is explicit
that boot is "the ambient prelude every namespace resolves against".)

* The two gates, in order

**(1) The rename must land first (PLAN-088 → PLAN-126 §4.6).** A bare
`defserver` is matched by `special-forms` BEFORE macro lookup
(`priv/boot/compiler.bl:4014`), so no ambient `defserver` can win while the
special form holds the name. Rename the special form to `defgen` and the name
`defserver` becomes an ordinary name that the ambient chain can serve.

**(2) The ambient list must gain a third entry, lazily.** Not a `:require` —
a third fallback in that resolution chain:

```
during boot   [core, sugar]
after std      [core, sugar, proc…]        ← populated once the tier is up
```

That is an Elixir-side change (`env.ex`) plus a guarantee that the proc tier is
loaded before user code runs. It is the same shape as `core`/`sugar`; it just
arrives a phase later.

* The cost, and the cheaper middle

Cost: every program then loads the proc tier (flow, bus, reg, super, fence,
tick, sched, server), and `:refer :all` of the verbs puts ~40 names in every
namespace — shadowable by a local `def` (the ns is searched first), but still
surface. **Measure the load cost before committing**; it is an AOT-memoized
tier, so it may well be free.

Middle option, much smaller blast radius: **ambient `defserver` + an implicit
`proc` alias**. One ambient name, zero pollution, and verbs stay qualified:

```clojure
(defserver workers            ; ambient
  (registry (keys :id))       ; a clause: no var, and none needed
  (tick 15 :minutes [st] (proc/tick-reset 200 {:name 'workers})))
```

* Measured spellings today (so the target is stated against reality)

```
(proc/tick-delay …)          ✓  a qualified VERB through the umbrella's re-export
(tick 15 :minutes [st] …)    ✓  an unqualified CLAUSE — a clause head is a symbol
                                the expander looks up, so it needs no var at all
(proc.server/defserver …)    ✓  a fully-qualified MACRO, by namespace name
(:require [proc :as p]) (p/defserver …)          ✗  a referred macro does not
                                                    resolve through a qualifier
(:require [proc :refer :all]) (tick-delay …)     ✗  a two-level refer does not
                                                    chain unqualified
```

The last two are why the umbrella (FUP-097) covers verbs only, and why the
clause surface is already ambient *today* — which is worth noticing: **the
things that need the prelude are exactly one macro and the verbs.**

* Acceptance

- `(defserver workers (tick 1 :s [st] (noreply st)))` in a file with NO
  `:require` loads and fires.
- A program that requires nothing new still resolves `defgen` (the boot floor).
- Boot time for a trivial program is not measurably worse than today; if it is,
  the middle option is the answer and `:refer :all` is dropped.
- `env.bl`'s `:paths` story is unchanged: the ambient entry is a FALLBACK, so a
  project file of the same name still shadows it.
