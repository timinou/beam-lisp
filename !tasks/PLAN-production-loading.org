#+TITLE: General production loading policy
#+STATE: ACTIVE

* Contract
bl serve reads :loading from env.bl. Development stays lazy; production loads
static library dependencies before executing the entry program. Derive roots
from its namespace declaration; do not load the entry program during discovery.
Use source-graph and normal AOT loader; no regex dependency parser or bespoke
application preloader. Support explicit additional roots for dynamic dispatch.

* Batches
- [ ] Normalize and validate configuration; implement cycle-safe dependency pass.
- [ ] Gate bl serve before run_file; test failures prevent entry execution.
- [ ] Focused source gates, sealed SDK build and packaged gate.
- [ ] Adopt ordinary pinned SDK in Knowledger; remove duplicated loader logic.
- [ ] Development/production startup and populated navigation acceptance.

* Deferred
Async development warm-up requires reload-aware publication coordination and is
not promised here. Dynamic execution/effect certificates, code leases and index
admission economics remain follow-ups, not prerequisites for this policy.
