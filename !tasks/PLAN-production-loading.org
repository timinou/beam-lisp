#+TITLE: General production loading policy
#+STATE: DONE

* Contract
bl serve reads :loading from env.bl. Development stays lazy; production loads
static library dependencies before executing the entry program. Derive roots
from its namespace declaration; do not load the entry program during discovery.
Use source-graph and normal AOT loader; no regex dependency parser or bespoke
application preloader. Support explicit additional roots for dynamic dispatch.
