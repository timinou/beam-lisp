## Root cause
niri (XDG_CURRENT_DESKTOP=niri) honors wlr-layer-shell for docked/always-on-top
surfaces (how waybar pins). gtk-layer-shell-0 0.10.1 is installed; the Rust
crate gtk-layer-shell 0.8.2 wraps it and pins to gtk 0.18 (matches our crate).

## Fix: layer-shell + transparency in native/wry_webview
1. Add dep gtk-layer-shell = "0.8" (+ its v0_6 feature for exclusive-zone auto).
2. webview_open gains: layer_shell(bool), anchor flags (top/bottom/left/right),
   exclusive_zone(i32), transparent(bool).
3. When layer_shell: on window.gtk_window(), BEFORE first map:
   init_layer_shell(); set_layer(Layer::Top); set_anchor(edge,true) per flags;
   set_exclusive_zone(n). This is what niri obeys → real top dock, on top.
4. Transparency for glassmorphism: window with_transparent(true) + gtk rgba
   visual + app_paintable on the gtk window; webview with_transparent(true).
