* Initial Message

look at tinyjs (whatever fabrice bellard did), and squint. especially squint. could we use bl-ANF to convert beam lisp to Js?

* Why
The JS actor target now supports catch/finally across receives, but host.mjs::emptyTrace returns a two-tuple whose frame list is empty. Native BEAM stacktrace frames cannot be copied from JS Error.stack: generated functions and host trampolines are not BL source frames. Empty traces make a suspended actor failure hard to debug and obscure call sites.

* Outcome and contract
Add a target-defined **logical BL trace**, not a claim of bit-for-bit BEAM traces. Preserve source/module/function/arity and location annotations from canonical ANF into generated resumable frame metadata where present; mark missing locations explicitly rather than invent them. Maintain call-site provenance across direct, dynamic/higher-order, tail calls, scheduler yields, receive parking and resumption. Catch normalization and `:erlang/element(2, rawtrace)` see a stable BL frame list; rethrow with raw trace preserves the original raise site. A finalizer that raises supersedes the old trace; a finalizer that completes leaves pending trace unchanged. Include actor identity where available without exposing host object addresses. Opt for capped trace length/cost and explain tail-call representation (elision or explicit tail marker) as a deliberate policy.

* Design touch points
priv/boot/anf.bl annotations and compiler.bl source locations; research/js-actors/compiler.bl emitter metadata, host.mjs machine frame records and exception envelope, runtime.bl normalization/output. Keep trace construction incremental at managed call boundaries, not by parsing JS Error.stack. The BL formatter is in BL where feasible; JS adapter only stores typed metadata. Do not break bounded-frame invariant or leak continuation frame stacks after process exit. Stable ordering (innermost to outermost) and line/column origin require a specification plus the native BEAM comparison caveat.

* Proof gates
Raise from f→g, higher-order callback, timed receive wake, parked finalizer, typed catch fallthrough, nested finalizer replacement, tail-loop 50k iterations with bounded memory; inspect the reported source names/locations and original-vs-new trace. Differential tests compare call identities/ordering where BEAM and BL logically overlap, not raw VM formatting. Browser demo surface shows a human-readable BL source location for a deliberately failing actor; the healthy inbox demo remains unaffected. Build/Node/adverse-budget/browser suites remain green. Document compatibility as target-defined logical frames only.

* Dependencies
After FEAT-046 host inbox and existing resumable exception backend; independent of numeric tower and OTP semantics. Part of the work list in research/js-actors-future/README.md. This FEAT is not implemented by the current empty-trace placeholder.
