* Architecture
Define tagged exact integers backed by a minimal host BigInt leaf, float values preserving IEEE bits/category, and decimals carrying unscaled BigInt + nonnegative scale. Preserve typed source literals through `priv/boot/anf.bl` and `research/js-actors/compiler.bl::lit-js`; never round a BL value through JSON Number or `Number.isInteger` to infer its type. BL-written numeric dispatch owns promotions, decimal alignment/rounding, exact division policy, equality vs numeric comparison, printing and map-key hash. The host may only perform irreducible BigInt construction and primitive operations/storage. FEAT-055's proof witnesses may lower the *same* contract to raw Number for safe paths. Unknown bounds use exact tagged fallback once available; no silent coercion. Respect `lib/beam_lisp/decimal.ex` and `priv/lib/decimal.bl` as semantic sources, not as target-callable native modules. On MicroQuickJS without BigInt, refuse the exact profile unless an independently proved polyfill/WASM representation is implemented.
