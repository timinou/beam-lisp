* Initial Message

look at the most efficient ways that we can implement semantic similarity within redb and therefore give a fast native way for consumer apps to user this whole class of things. Show examples of that usefulness

Native semantic similarity + graph ML on the datom store, built as an EXTENSION of PLAN-042's columnar engine (typed value lanes + resolve NIF + Scan capability), not a bolt-on vector DB.

## Core insight
Vectors cannot be a 5th sorted index (no order-preserving 1-D key for high-dim metric space). Similarity is a new ACCESS METHOD beside the ordered ones. A vector is stored as an ordinary datom (float array in a new LANE-VECTOR), so it is durable, time-travelable, transactional. A derived vector index accelerates search; Rust does the math (resolve.rs sibling).

## Why PLAN-042 makes this lean
- typed packed value slot already exists (value-codec.bl LANE-FLOAT) → add ONE lane (LANE-VECTOR = packed f32).
- resolve.rs already scans a range + decodes packed values in one crossing → COPY its skeleton for a distance-scan NIF.
- Scan protocol = capability dispatch (satisfies? Scan) → add VectorScan the same way, no if-redb branch.
- datom/from pipeline macro → add a `similar` step.
- Result: ~400-line feature, not ~2000.

## Method (proven in Prototype A)
Binary quantization (sign bits, XOR+popcount coarse pass) + exact f32 rerank. Measured on Ryzen AI 7 350, 768-dim, k=10:
- 100k: 0.49ms quant vs 53ms flat (~100x), recall tunable 50-80% by rerank width
- 1M: ~5-8ms quant vs ~575ms flat (~75-100x)
- rerank is a cheap monotonic knob (sweep: 50→80% recall, all <1.5ms @100k)
- search_flat kept as the EXACT path (53ms@100k, exact) for accuracy-critical use
Caveat: synthetic data; real-embedding recall proof deferred to Prototype D.

## Syntax surface
- `[(similar-to :attr ?q k) [?e ?score]]` — generating clause; free ?e → kNN, bound ?e → prefiltered score (exact, cheap; the thing HNSW can't do).
- `[(cluster :attr {:method :k-means :k 5}) [?e ?cluster]]` — k-means/k-medoids/hierarchical/dbscan/hdbscan.
- `[(project-2d :attr pca) [?e ?x ?y]]` — PCA/UMAP dimensionality reduction for plotting.
- `[(community :ref-attr {:method :label-propagation}) [?e ?community]]` — connected-components/label-prop/Louvain over the ref graph.
All bind each entity to a computed group/coord/score → joins with facts + aggregation (agg.bl).

## Prior art (datalog ML)
- Zaniolo et al. 2019 "BigData Applications from Graph Analytics to ML by Aggregates in Recursion" — kNN, k-means as recursive datalog rules; PreM (pre-mappability) pushes aggregates into recursion.
- SociaLite, BigDatalog, RaSQL, LogicBlox — connected components, PageRank, shortest paths as canonical recursive-datalog.
- Community detection / label propagation = recursive rule to fixpoint; leans on existing recursive-rule + agg machinery.
