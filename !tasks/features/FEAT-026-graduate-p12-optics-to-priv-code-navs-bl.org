* Design
** priv/code_navs.bl
Reify specter.engine/RichNavigator with select*/transform*:
  - (codewalk*)        — descend every child, tagged composites and bare leaves
  - (within* #{kinds}) — descend, but cut at nodes whose head ∈ kinds (the cut
                          applies to CHILDREN, never the root — a descent decision)
  - (head* "sym")      — select nodes whose list-head symbol = "sym"
transform* throws deliberately: code navs are SELECTION-ONLY; rewriting stays
rewrite's job. Multi-result via specter.navs/doseqres-fn NONE coll afn.

Mechanics the spike already discovered (carry them in a comment, they cost a
debugging round each): literal children are UNTAGGED bare values (0, "s", :kw
inside :list/:vector items) → leaf branch (next-fn vals node); composites are
{:tag items} tuples; read_string returns a bare LIST of nodes (descend without
visiting); LazySeq handled by RT.seq.

** typed/walk :visit hook
typed/walk already threads an env (guard narrowing: single-pred + and-chain).
Add an optional :visit callback invoked per node with (node, env). Then:
  - promote/report      → :visit that runs deodorant/smell-match against the env
  - effects/infer       → :visit that joins the node's effect into an accumulator
  - termination/find-recurs → (within* #{"loop" "fn"}) + (head* "recur")
One walker, one guard-narrowing implementation, three consumers.

* Cool example
#+begin_src clojure
;; BEFORE: three files each walk the tree their own way.
;; AFTER: one nav language selects, the hook visits.

;; "every recur inside THIS loop, not an inner fn's loop"
(select [(within* #{"loop" "fn"}) (head* "recur")] (read-defn src))
;; => the two recurs that belong to the outer loop; the nested fn's recur is cut.

;; promotion and effects now ride the SAME descent:
(typed/walk defn-node env
  :visit (fn [node env]
           (when-let [b (deodorant/smell-match smell (form-data node))]
             (record-promotion! node env b))))
#+end_src
