* Goal
Run a real, unmodified Clojure library on beam-lisp, and prove it by running
replikativ/kontor's kernel — not by porting it. Compatibility is the deliverable;
kontor is the conformance suite.

`#'`, `ns :import`, `:refer-clojure`), the java tier (java-like shims that
translate to native beam-lisp), and the datahike tier (a `datahike.api` projection
over datom).

* W1 — the loader tier (DONE, commit 163ad94)
Three independent reasons a Clojure file was unreachable, all fixed:
1. **Extension.** `@doc_extensions` gains `.clj` and `.cljc`, after the beam-lisp
   extensions, so `.bl` still shadows. `.cljc` is raw source, not a document:
   `doc_content` tests `@plain_extensions` instead of `ends_with?(".bl")`, or a
   `.cljc` file would be parsed for literate code cells and arrive empty. `.cljs`
   deliberately absent (its contents are ClojureScript; this platform presents as
   `:clj`).
2. **Name.** Clojure munges `-` to `_` in the file name. One rule, one place:
   `Loader.source_relatives/1` (literal spelling first, then munged) with
   `Loader.source_path/1` for callers that need to READ the file.
3. **Docstring.** `(ns app "doc" (:require …))` reached the clause walker as a
   scalar node, was walked as a list, and died inside the host with
   "1st argument: not a tuple". `ns-clauses` drops it — EAGERLY, because a
   compiler collection must be finite data and `remove` returns a lazy seq.

Required:
- `defonce` — needs a "is this var already bound?" primitive; `resolve` does not
  exist in bl, so find the var-registry call first (`BeamLisp.Env`).
- `#"…"` reader literal and `#'` var-quote — reader dispatch branches
  (`priv/boot/reader.bl`, `read-dispatch` at ~683-712 handles `(`, `{`, `_`, `?`,
  else `read-tag`).
- `(:import [pkg Cls …])` in `ns` — becomes "require the shim namespace for
  `pkg`" (W3) plus an alias of each class name. This is the door to the java tier.
- `:refer-clojure` — accept `:exclude` / `:rename` (4 kontor nses).
- a cljs-only `#?(:cljs …)` with no `:default` — Clojure SKIPS it (`clojure -M -e
  '(read-string {:read-cond :allow} "[1 #?(:cljs :x) 2]")'` → `[1 2]`, verified);
  bl raises "no matching reader-conditional branch" (`reader.bl:575`). Match Clojure.

* W3 — the java tier (NOT STARTED)
Design reference: andreasronge/ptc_runner (Elixir, 0.15.0) — a CLOSED manifest +
closed dispatch, no reflection:
- `priv/java_interop.exs` is the manifest: `classes` (each with `spellings`,
  `receiver_profile`), `overloads` (arity + argument types + `route:
  {:dispatch, key}`), `references`; validated at compile time.
- Symbol spelling carries the interop: `BigDecimal/valueOf` is just a namespaced
  symbol (`ast.ex:30-53`); `.contains` resolves to a "member family" grouped by
  member name (`surface.ex:42`).
- `Dispatch.invoke/4` → `select_overload` → `apply(module, function, [args])` from
  a static atom→MFA table (`implementations.ex:4`). No protocols, no behaviours.
- It covers 12 classes (java.lang Math/String/System/Integer/Long/Double/Float/
  Boolean, java.time LocalDate/Instant/Duration, java.util Date) and **explicitly
  does not implement `java.math.*`** — `decimal?` is always false there and `1.0M`
  is a parse error (their DIV-20).
So: copy the manifest/dispatch shape, but **BigDecimal is ours to build**.

What kontor needs from this tier (measured): `java.math.BigDecimal` +
`RoundingMode` (923 refs; 39 schema attrs; `M` literal in 102 lines/25 kernel
files — `0M` is the very first failure inside `:progressive-bracket`),
`java.util.Date` (290 refs), `java.time.*` (~150), `UUID`, `MessageDigest`,
`java.io`. The kernel's first need is BigDecimal only.

A decimal belongs in the LANGUAGE, not just the compat tier: it must print,
compare, order in an AVET index (`datom`) and lift arithmetic. Blueprint for the
semantics: kontor's own cljs lane, `modules/substrate/src/kontor/money.cljc:34-125`
(a complete js/BigInt fixed-point decimal with the same HALF_EVEN rounding policy).

* W4 — the datahike tier (NOT STARTED)
kontor requires `datahike.api` in 56/71 kernel namespaces. A projection over
datom, not a second engine: `q`, `transact!`, `db`, `entity`, `pull`, `as-of`,
`history`, `datoms`, `schema`, `connect`, `create-database`, `db-with`,
`with`. Six real gaps stand between the projection and kontor (each measured):

4. Datalog: scalar `[:find ?x .]` (64 sites/29 nses), collection `[?x …]` (64/29),

5. `:db.type/tuple` + `:db/tupleAttrs` (23 attrs).
6. `:db.fn/call`, `:db/isComponent`, purge/excision, `branch!`, crypto-hash.
