* Purpose
One runtime per Worker uses integer local pid handles. `postMessage` structured clone does not serialize BL closures/prototypes or preserve arbitrary actor ownership; a remote pid is not a local integer. No node identity, remote send, monitor node-down semantics or codec is implemented. Calling this 'distributed OTP' would be wrong. Research baseline: research/js-actors-future/03-boundaries-ets-ports-distribution.md, distribution section.

* Design deliverable
Choose node/runtime identity, incarnation epochs, pid and ref wire representation, safe lossless BL value codec including large numeric/decimal types (coordinate FUP-124), closure policy (deny or code-id plus environment schema), mailbox ordering by sender and queue bounds, remote spawn policy, link/monitor propagation, node-down, reconnect/fencing and target security. Compare multiple Workers on one origin versus network transport; separate their failure domains and capabilities. Keep actor addressing/routing policy in BL; host only transports validated frames with explicit version/type tags. Do not implicitly transfer buffers and detach senders. Specify where exactly-once cannot be guaranteed without durable storage and state that limitation.

* Acceptance
A design decision artifact and a narrow two-Worker BL demo: source send/receive with typed value round trip, remote failure/monitor notification, stale incarnation rejection, ordering under interleaving, malformed payload rejection and bounded backpressure. Property/adversarial tests plus BEAM differential traces for supported message/monitor semantics, acknowledging intentional network/VM differences. Browser visibly shows sender Worker, receiver Worker, unique node/pid identities and node-down result. No production distribution claim until this gate passes.

* Dependencies
FEAT-049 identity/links/monitors, FEAT-050 names and FEAT-051 lifecycle resilience. FUP-124 numeric codec shapes and FEAT-053 host capability design inform wire types. Can be separately researched now, but implementation waits for these contracts. Full research questions in the distribution sheet.
