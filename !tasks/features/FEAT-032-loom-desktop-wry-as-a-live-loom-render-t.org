## The new primitive: loom.desktop (priv/loom/desktop.bl)
wry becomes a LIVE LOOM RENDER TARGET — the same one-commit/N-viewers-converge
loop as `live`, but the viewer is a native window and the transport is
`wry/eval` (full #root innerHTML swap) instead of a WebSocket.

Grammar:
  (desktop/app {:title :width :height
                :state  <initial value>
                :view   (fn [state] <loom hiccup>)
                :on-event (fn [state ev] <new state>)   ; ev = parsed bl.send
                :tick   {:every-ms N :event [:tick]}})   ; optional periodic
  → returns a handle; runs a driver process: render(state)→HTML→window,
    each event → on-event → new state → re-render → eval-swap #root.

Events: view emits data-ev markers OR the page calls bl.send(json). desktop
parses the IPC body (interop/json->) and hands on-event a bl value.

## Statusbar preset: desktop/bar
