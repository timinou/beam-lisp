how do i turn spell (the one in spell/) into an actual program I can use?

The contract term is the single source of truth and already contains the server half as beam-lisp code-as-data ((on :send …) bodies with set!/push!/ask!/ok/err, on-info clauses for streaming). Today nothing executes them: the emitted page declares @host $chat : live("SpellWeb.ChatLive") and the runtime's doLiveRequest needs window.__stLiveBridge, which only a Phoenix LiveView provides. In static-serve mode Send is stuck by construction.

Design (agreed with user): ONE app. Phoenix + LiveView as library deps in beam-lisp's mix.exs, endpoint in the same supervision tree as Spell.Live. The seam .st stays byte-identical — live transport over the LV channel carries all three directions (signal→reply, assign diffs, streams). No SSE, no http host, no second app.

Pieces:
1. spell/src/spell/contract.bl — new `elixir-module` emitter: contract term → LiveView .ex source (use Spacetime.LiveView with bundle/root from contract opts; events/assigns/pushes blocks; literal handle_event/handle_info heads — required by E0928 compile check — delegating to spell.server).
2. spell/src/spell/server.bl — NEW ns: interpreter for contract bodies. Closed vocabulary (if/do/set!/push!/ask!/ok/err + pure fns), walked not eval'd. handle/4 → {:reply {:tag value} :assigns' :pushes}; handle-info/3 for on-info clauses. ask! runs the provider turn (spell.provider), streaming deltas as messages to the LV pid.
3. spell/src/spell/seed.bl + lib/beam_lisp/spell/page.ex — module prefix SpacetimeLvWeb → SpellWeb.
4. lib/spacetime/live_view.ex — port of verse's spacetime_lv bridge macro (375 lines), with the hand-mirrored skeleton cond REPLACED by the &shell lifted from the emitted page (spell already does this in serve_chat.sh). Jason → OTP :json.
5. lib/spell_web/ — endpoint, router, minimal root layout (csrf meta + phoenix.js + phoenix_live_view.js from deps priv/static + bridge hook).
6. Generated SpellWeb.ChatLive written to spell/gen/chat_live.ex, Code.compile_file'd at boot by the driver.
7. lib/beam_lisp/spell/server.ex — shim: socket assigns ↔ .bl values, calls spell.server.
8. scripts/serve_live.exs — boot: Spell.init → generate ChatLive → compile → emit page + bundle → endpoint on :4000.

Verification: puppeteer drives http://127.0.0.1:4000 — type, Send → user bubble renders, thinking indicator, streamed tokens, model reply joins @messages. Also scripted (no-network) path with a fake provider. Tests for spell.server interpreter + contract.bl elixir-module emitter.
